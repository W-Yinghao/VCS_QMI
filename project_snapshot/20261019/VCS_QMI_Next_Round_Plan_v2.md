## 0. 这一轮要回答什么

论文的中心从"一个更好的 SSL 目标"改为"一个更好的依赖估计器"。上一轮的结果把可以主张的范围收窄了：

- 等预算调参后，SimCLR 和 VICReg 在每个算力点上都超过 VCS（P41）。SSL 撑不起精度主张。
- 四个性质预检中，B 的闭式测量和 D 的条件检验是仅有的明确正面结果，而且都还没有和公平的对照比过。
- oracle 分析（附录 A）显示：在统计效率上，VCS 明显优于只用一个打乱负样本的 KL 类估计器，但与 JS 判别器持平或更差；在使用批内负样本时，只有当依赖远超 log N 时才优于 InfoNCE。有界性让 VCS 在干净数据上付出效率，换来的是影响有界和尾部风险低。

本轮要回答的是：**这个估计器在什么意义上优于同类，这种优越性能否在受控实验中被确认或推翻。** 这里的同类特指所有由 critic 区分联合分布与乘积分布的估计器，其中 JS 是决定性的对照：它和 VCS 共享等权混合的结构，两者只在评分规则上不同。

## 1. 执行方需要知道的事实

### 1.1 上一轮结论

| 项目 | 结论 | 关键数字 |
|---|---|---|
| P41 等预算调参 | 两个对照在每个预算都赢 | SimCLR 在 1×、2×、4×、8× 分别领先 3.5、3.3、2.4、1.3 |
| 预检 A 标定 | 有条件 | 精确配对时原生 ECE 比 Platt 差 0.04–0.05；中等依赖下持平；SigLIP 式原生概率的 ECE 为 0.34–0.49 |
| 预检 B 闭式 critic | 测量成立，配准不成立 | 与神经 critic 相差不超过 0.012；三个真实配准源的成功率都低于 MI |
| 预检 C batch 解耦 | 不成立 | batch 降到 32 时，VCS 保留 0.979，SimCLR 保留 0.977 |
| 预检 D 依赖检验 | 有条件 | 置换检验与 HSIC 持平；条件检验功效 0.98 对 0.18；Hoeffding 界要多 20 到 50 倍样本 |

### 1.2 SSL 目标端的调优已经穷尽

critic 族（拼接 MLP、余弦、对角度量、单调样条）、尺度初始化、K、投影头变体、EMA 和预测头，全部中性或更差。单调样条会重新学出一个比余弦更尖的阈值（P29）。原因是结构性的：增强配对几乎是确定性的，S 约为 0.97，最优 critic 取 ±1，任何足够灵活的 critic 都会退化成阈值。**本轮不再在 SSL 目标端做调优。**

### 1.3 冻结项不变

参考测度 M=(P+Q)/2；目标 S；J 的精确形式，正负两项分别平均；critic 输出必须经过 tanh；不称其为 Shannon MI；负样本来自乘积边缘采样，不按难度挑选。以下改动需先与合作者讨论，本轮不做：辅助损失、改变参考测度、去掉 tanh、对配对内部加权、hard negative。

### 1.4 本轮新增的三条纪律

- **跨目标比较只用与目标无关的指标。** 各估计器相对各自真值的误差可以报告，但不同估计器之间的优劣只在与目标无关的轴上比较：阶梯可分度（附录 B）、检验功效、尾部风险、学习值与 oracle 值的差距。
- **重尾估计器不能只报标准差。** 对 NWJ、DV 和 MINE，必须报告分位数、最大偏差和发散次数。它们的方差由罕见事件主导，短跑得到的样本标准差会系统性地偏小。
- **JS 必须出现在每一条主张的对照里。** 如果某条优势在 JS 面前消失，这条优势就属于"用 critic 区分联合与乘积"这整个家族，不属于 VCS。

## 2. 四条线

每条主张按同一结构写：主张、预测、推翻条件、必须控制的变量、留给执行方的部分。

### E 线：受控估计器基准（论文主干）

合作者原计划中的高斯、混合、非线性信道实验，以及与 MINE、NWJ、InfoNCE、SMILE 的稳定性对比，仓库里至今一项都没有。这是估计器论文不可缺的部分。

**E1 尾部风险。**
- 主张：在所有依赖强度、batch 和学习率设定下，VCS 都没有发散和尖峰，其估计的尾部分位数有界。
- 预测：MINE、NWJ、DV 在高依赖台阶上出现尖峰或发散；VCS、JS、InfoNCE 没有。
- 推翻条件：VCS 出现发散；或者 JS 与 InfoNCE 的尾部表现同样好，且阶梯可分度也同样好。后一种情况下，这条主张只对 KL 类估计器成立，报告时要如实写明。

**E2 小 batch、高依赖下的分辨率。**
- 主张：当互信息明显超过 log N 时，VCS 分辨相邻台阶的能力优于 InfoNCE、SMILE 和 JS。
- 预测：oracle 分析给出，N=64 时互信息约 6.5 nats 以上 VCS 开始优于 InfoNCE；只用一个打乱负样本时，VCS 对 NWJ 的优势在约 2、4.3、6.6 nats 处分别约为 3 倍、11 倍、38 倍（附录 A）。学习型 critic 的结果应当保持这个排序。
- 推翻条件：在学习型 critic 下排序反转，或者优势完全消失。

**E3 可训练性。**
- 主张：VCS 学习值与 oracle 值之间的差距，小于 JS、InfoNCE 各自学习值与 oracle 值的差距。
- 预测：在高斯和三次变换设定下，VCS 的学习值与 oracle 值之比最接近 1，而且对学习率最不敏感。
- 推翻条件：JS 的差距同样小或更小。

**E4 同目标对比。**
- 背景：当 α 取二分之一时，RuLSIF 估计的量与 S 只差一个常数因子（草稿附录 C.2），是唯一与 VCS 完全同目标的已有方法。
- 主张：用相同特征时，闭式 VCS 与 RuLSIF 数值一致；在维度较高时，神经 VCS 对 S 的误差低于核方法 RuLSIF。
- 推翻条件：在执行方设定的维度网格上 RuLSIF 始终持平；或者在相同特征下两者数值不一致，这说明实现有问题，需要先查实现。

**E 线的共同控制。** 所有估计器使用同一 critic 类、同一优化器预算和同一学习率网格；负样本的构造方式必须在每张表里写明，单个打乱负样本和全部批内负样本要分开报告；每个估计器的真值用解析式或高精度蒙特卡洛得到；oracle critic 的值与学习值在同一批样本上计算。

**留给执行方：** 维度、依赖阶梯、batch 网格、critic 结构、步数、可分度门槛。建议起点：Song 与 Ermon 的 20 维高斯及其三次变换版本、逐步升高的互信息阶梯，外加一个非高斯的混合或非线性信道设定。

### R 线：鲁棒性（最可能成为优越性主张的一条）

**理论依据（草稿，需合作者核对）。** 在最优 critic 处，S 对单个联合样本的影响函数只由 a₊ 和 a₋ 在该样本及其边缘上的取值组成。之所以涉及边缘，是因为一个联合样本同时改变乘积分布。a₊ 和 a₋ 都在 [−1.5, 0.5] 内取值，所以影响有界。KL、JS 和 InfoNCE 的对应项在联合样本看起来像独立样本时，下侧无界。作为训练目标，VCS 对 logit 的梯度 (c−T)(1−T²) 在 critic 自信地判错时趋于零，这是一种回降型损失；logistic 损失在同样情况下梯度保持最大。

**R1 估计器层面的污染。**
- 主张：把一部分联合样本替换为独立样本或离群对后，VCS 的估计偏移不超过常数乘以污染比例；JS、InfoNCE、NWJ 的偏移随离群程度增长。
- 度量：偏移用各估计器自己的"分辨率单位"来量，即偏移除以附录 B 中该估计器的相邻台阶间距。这样比较与目标无关。
- 推翻条件：学习型 JS 的偏移同样有界，而且幅度相当。

**R2 训练层面的噪声配对。**
- 主张：在冻结双塔加 adapter 的图文设定里，随着错配比例升高，VCS 训练的 adapter 在干净测试集上的检索损失小于 InfoNCE 和 logistic。
- 推翻条件：三者的退化曲线重合，或者 VCS 更差。
- 必须控制：各方法有相同的调参预算；logistic 同时报告原生版本和加了 log K 截距校正的版本；再加一个平衡 logistic，也就是 JS。
- 说明：这里训练会改变嵌入，所以可以用检索排序作指标。

**R3 错配识别。**
- 主张：不借助干净校准集，VCS 的原生分数识别训练集中错配对的 AUROC，高于 InfoNCE 的余弦分数和 logistic 的 logit。
- 推翻条件：AUROC 持平。

**留给执行方：** 错配的构造方式、错配比例网格、离群对的构造、数据集。建议起点：复用预检 A 的 COCO 加 CLIP 冻结塔基础设施；带噪配对的已有工作 NCR 可作为方法层面的参照。

### T 线：条件依赖检验，换上公平对照

**T1 条件检验的功效。**
- 背景：预检 D 的 0.98 对 0.18，诊断为 HSIC 的全局带宽与类内尺度不匹配。
- 主张：在类内精确置换、每次重复都重新抽取 N 的设计下，VCS 的功效不低于以下所有对照：按类设带宽的 HSIC、学习核的 HSIC、用 logit 作统计量的 C2ST、用同一 critic 类训练的 JS 统计量。
- 推翻条件：JS 统计量追平。此时优势归因于"学习型 critic"，不归因于 VCS，报告时照实写。
- 必须控制：所有检验使用相同的样本拆分（拟合、选择、评估），相同的置换次数；检验水平的验证沿用 P45 附录 6 的做法：每次重复都重新抽取 N。

### S 线：SSL 只做收尾和文献对齐

**S1 官方测试集。** 等 VICReg 8× 的两个种子完成后，按 P67 对全部冻结单元只评一次。依赖关系：先完成 VICReg 种子。

**S2 标准协议下的位置。**
- 目的：把 VCS 放进标准 CIFAR 协议，让数字能与文献表格直接对照。文献表格指 solo-learn 基准，以及引用它的显式 MI 论文 arXiv 2409.04747。
- 做法：可以把 VCS 作为一个方法移植进 solo-learn，也可以在本仓库中复现它的配方：ResNet-18、1000 epoch、LARS、较大的投影头、按方法的增强、官方测试集。同时复现至少一个对照，用来确认配方复现正确。
- 主张：由于 VCS 每翻倍算力的增益大于 SimCLR，在标准协议下它与 SimCLR 的差距小于 P41 在 8× 时的 1.3 个点。
- 推翻条件：差距不小于 1.3 个点。
- 说明：这条只决定 SSL 一节怎么写，不决定论文主张。

**S3 不再调 SSL 目标。** 理由见 1.2 节，写进技术说明作为结论。

## 3. 结果怎么读

- **只对 KL 类估计器成立。** 若 E1 到 E3 相对 MINE、NWJ、DV 成立，但相对 JS 和 InfoNCE 不成立，论文主张收窄为：一个有界、带 CS 解释、有精确变分形式和闭式对偶的分类器型估计器，其稳定性在 KL 类之上，效率不在 JS 之上。
- **鲁棒性成立。** 若 R1 或 R2 相对 JS 和 InfoNCE 成立，鲁棒性就是论文的优越性主张，E 线作为支撑。
- **条件检验成立。** 若 T1 相对 JS 统计量仍成立，条件检验可以作为主要应用。
- **在 JS 面前都不成立。** 若所有主张在 JS 面前都不成立，就不写"优越"。VCS 的独立贡献是 CS 参考测度的构造、tanh(PMI/2) 的有界最优 critic，以及闭式与神经 critic 的对偶。是否改投和如何定位，由作者决定。

四条线都只完成预检到正式实验之间的判断。每一种结果都是有效结论，都要完整报告。

## 附录 B：与目标无关的阶梯可分度

对于相邻两个依赖台阶 k 和 k+1：

```
可分度_k = |均值_{k+1} − 均值_k| / 合并标准差
```

均值和标准差按种子或按台阶内的末段迭代计算，具体口径由执行方在预注册中冻结。对任何单调变换，这个量都不变，因此可以在 S、JS 和 Shannon MI 之间直接比较。重尾估计器另报分位数版本：把标准差换成四分位距。

## 附录 C：需要补进相关工作的文献

- **arXiv 2409.04747，Explicit MI Maximization for SSL。** 它用二阶统计量的 log-det 作为 SSL 目标，CIFAR-10 上 93.1。注意：其定理 2 的证明依赖 Φ(β,2n)=Φ(β,n)² 这个恒等式，数值核对显示它只在 β=1 时成立，β=2、n=2 时比值为 1.57。因此"超出高斯的显式 MI"这一点并不成立，目标本质上是高斯 MI。
- **CorInfoMax。** 同属 log-det 类 SSL 目标，CIFAR-10 上 93.2。
- **Poly-View。** 多视图对比学习；我们的多视图做法对应其中的 Multi-Crop。
- **Deep InfoMax 的 JS 估计器与 f-GAN。** JS 对照的来源。
- **RuLSIF。** 与 VCS 同目标的已有方法。
- **Song 与 Ermon 2020；McAllester 与 Stratos 2020。** 前者给出 KL 类估计器方差随互信息指数增长；后者证明任何无分布假设的互信息下界所需样本数随互信息指数增长。论文不能声称在互信息尺度上突破这个限制。
