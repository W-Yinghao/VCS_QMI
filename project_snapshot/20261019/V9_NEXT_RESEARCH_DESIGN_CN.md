## 2. 第一优先：让可靠性估计对应学生实际使用的信息

现有 critic 主要把 teacher 的一个相似度分数变为权重。学生还使用更丰富的表示、其它候选以及 hard negative。已有 [理论合同 E 节](ssl_pilot_v9/v9/package_v9_20261016/docs/03_THEORY_CONTRACT_CN.md)指出：令 C 表示干净成分，Z 是 critic 可见信息，w_Z=E[C|Z]，则对同一联合分布下的损失 ell，

\[
E[\hat w(Z)\ell]-E[C\ell]
=E[(\hat w-w_Z)\ell]-E[\operatorname{Cov}(C,\ell\mid Z)].
\]

第一项是估计误差；第二项是信息不足所留下的偏差。即使第一项消失，第二项仍可能存在。这里的 E[C ell] 保留该 ell 的负样本分布，不自动等于“整个 batch 都干净”的训练风险。

**待检验假设：** 标量分数遗漏了与损失相关的信息，增加匹配上下文可能比更换同一标量上的估计损失更有价值。这不是已有结果，也不保证增加特征就消除协方差项。

建议完整对照：

| 因素 | 水平 |
|---|---|
| critic 输入 | 当前标量分数；分数 + 双向正负间隔 + 固定候选集合上的预测分布摘要 |
| 估计/使用方法 | VCS、BCE、RuLSIF、RankMass |
| 重复 | seeds 901/902/903；完整 Flickr train、40 epoch、完整 DEV |

最多 24 次训练；需要新的不加权对照时另加 3 次。既有单位只有在数据、权重、host、优化和选择规则身份相容并逐项核验时才能复用，不能按方法名拼接。先保持当前 SGR host、噪声 manifest、锚点预算、训练尺度和学习率，避免同时更换 CLIP 或数据集。

VCS/BCE 使用同一网络类和选择预算；RuLSIF 使用同一输入并单独记录容量/拟合成本。RankMass 对照用于区分“概率数值有用”与“排序/筛选有用”。候选集合在 TRAIN 内独立指定并冻结，排除查询自身；共享候选造成的统计依赖需要记录。teacher、critic fit、选择、参考矩各角色仍分开，U 的成分真值仅供 evaluator。

主要终点仍是完整检索收益与训练稳定性；后验误差、ESS、按 hard-negative 难度分组的误差是机制解释，不代替终点。若增加信息只改善概率读数，没有完整训练收益，结束该扩展。

## 3. 第二个机制分支：可靠性与负样本、重匹配如何连接

当前零权重 pair 的图像和文字仍可成为其它查询的负候选。但“原始 pair 错配”不意味着该图像/文字对其它查询也是错误负样本。**不能把 w_i w_j 或 1-w_j 直接解释成负边正确概率。**

先用当前全量 Oracle 对照确定值得检查的分支：

| 完整结果的模式 | 后续设计 | 解释限制 |
|---|---|---|
| OracleMask 稳定优于估计权重 | 优先检查信息、校准和估计误差 | 完整真值比 score 后验信息更多；并不单独证明是校准问题 |
| OracleDrop 稳定优于 OracleMask | 优先检查样本池、负候选和训练目标 | 当前 Drop 同时改变样本数、更新数和分布，不能单凭差值确认负样本是原因 |
| 多种估计权重和 oracle 都没有稳定改善 | 结束当前加权接口，重新评估 host/目标是否值得研究 | oracle 不是严格性能上界，失败不证明所有可靠性方法都无效 |
| BCE/RuLSIF 与 VCS 同样有效 | 保留通用可靠性方向，结束当前 VCS 专有优势扩展 | 不通过删强基线维持独特性主张 |

若进入负样本分支，下一份协议应固定训练 anchor 序列、优化更新数和候选数量，单独改变负候选政策；加入等数量随机处理对照，避免把降低难度误称为正确性校正。诊断性真值干预与可部署估计器分表；可部署的负边概率需要自己的标签定义、参考构造和校准，不能从 pair 成分概率自动得到。

重匹配可以作为可靠性的另一个使用接口：在同一个 L2RM 模块中分别接入 VCS/BCE/RuLSIF，使 host、OT 规则、候选和预算一致。这应在当前加权结果分析之后启动，不能通过读取原始正确 pair 真值进行恢复。

文献边界：SREM 已使用批次预测分布与负匹配信息来处理自增强错误；L2RM 已研究用部分最优传输重匹配；NCU 已研究 CLIP 中的假正例/假负例及难负信息。因此，“加负样本处理”“增加多个分数”“接 OT”本身都不足以认领新的方法贡献。候选贡献必须来自明确的可靠性目标、误差控制及相同接口下的完整任务收益。[SREM](https://arxiv.org/abs/2312.16478)、[L2RM，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Han_Learning_to_Rematch_Mismatched_Pairs_for_Robust_Cross-Modal_Retrieval_CVPR_2024_paper.html)、[NCU，ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Han_Unlearning_the_Noisy_Correspondence_Makes_CLIP_More_Robust_ICCV_2025_paper.html)。这次检索用于确认已知重叠，不是穷尽式新颖性检索。

## 4. 稳定收益后的应用问题：用更少可信标注达到相同效果

建议预先固定 2%、5%、10% 三档可信图像预算，嵌套选择；所有档位仍训练全部数据、完整 40 epoch。预算减少的是可使用的干净标签，不是训练集规模。teacher、critic、选择与参考样本全部计入预算。

**必须固定整个训练配对/噪声 manifest。** 如果每档都重新令 A 全干净、仅给 U 注入 40% 噪声，档位同时改变总体噪声量，无法单独回答标注预算问题。合理做法是在同一训练集上逐步隐藏可信标注，其余样本照常训练，真值不能进入 fit；各档 U 的成分比例需按其参考定义重新估计，不能强行都设为 0.4。

最低主比较为 VCS、BCE、RuLSIF × 3 档 × 3 seeds，即 27 次全量训练；是否扩至 RankMass/NCR+A/L2RM+A 取决于前一轮胜出机制和外部方法复现是否完成，最终应用结论不能遗漏最强匹配预算对照。比较同等检索质量所需的人工标注、全部 teacher/critic/student GPU 时和失败运行成本。不能只拿依赖额外干净锚点的方法与无锚点论文分数比较。

## 5. 再下一步验证：噪声机制变化

全局混合 R=(1-rho)P+rho Q 和正确的 Q 参考，是比例与后验解释的基础。随机重配结果不能直接外推到语义近邻错配、来源相关错误或自然网页配对。

只有前述完整实验支持继续，才选一个新机制做完整训练，例如冻结的语义近邻重配；所有估计器使用相同参考构造，明确这是在真实数据上的人工噪声实验。若采用自然噪声数据且没有成分参考/错误真值，则报告检索终点和可验证诊断，不声称测得“真实噪声率 RMSE”。优先检验参考错设是否使方法失效，而非一次扩展许多 rho 数值。

G1/G2 的现有主成功率已接近饱和。后续 REG 若继续，应研究独立组织/采集条件或部分可见性等明确新问题，另立完整协议；已有 TEST 不能再次当作独立未见确认，严格几何阈值也不能忽略标注对齐误差。其资源优先级目前低于 N2 的机制判断。

## 6. 可继续推导的理论接口：面向损失的加权 J

以下是由原恒等式直接得到的工作推导，不是已验证的新算法，也不认领加权最小二乘的新颖性。它给第一优先方向提供一个可检验的实现候选。

对固定、共同、正的函数 a(z)，定义

\[
J_a(T)=E_P[aT]-E_Q[aT]-\tfrac12 E_P[aT^2]-\tfrac12 E_Q[aT^2],
\qquad S_a=E_M[a\eta^2].
\]

配方直接给出

\[
S_a-J_a(T)=E_M[a(T-\eta)^2].
\]

因为 (p-q)=2m eta，展开右侧即可验证。a 在 P/Q 两边必须是同一个 z 的函数；分别按两类质量自归一化一般会改变该目标。a>0 时无限制最优解仍是 eta，不创造新的总体最优 posterior。

在正确混合模型、已知 0<rho<1、T∈[-1,1] 下，posterior 映射关于 T 的 Lipschitz 常数可取

\[
K_\rho=\frac{\max(\rho,1-\rho)}{2\min(\rho,1-\rho)}.
\]

令 hat_w=w_rho(T)、w_Z=w_rho(eta)，由 Cauchy–Schwarz 和 dR/dM≤2，

\[
|E_R[(\hat w-w_Z)\ell]|
\le K_\rho\sqrt{2(S_a-J_a(T))}\sqrt{E_R[\ell^2/a]}.
\]

所需二阶矩须有限，a 可设有正下界。未知 rho 的估计误差、参考分布错设、信息不足的协方差项、训练中自适应选择和批次目标变化均需另行处理；此式不是完整训练泛化界，也不能拿未知 S_a 当已观测证书。

这提示可以用**独立训练后冻结的 teacher 所给出的损失难度代理**设计 a，把估计容量用于对学习更重要的区域。不能直接以当前学生的高损失无限增权：高损失也可能来自噪声，动态拟合还改变分析条件。必须给匹配 BCE 同样的 a、容量和预算，并先用完整训练验证是否比普通拟合/排序更好。该候选在信息扩展有效后再冻结，当前不追加一个大交叉网格。
