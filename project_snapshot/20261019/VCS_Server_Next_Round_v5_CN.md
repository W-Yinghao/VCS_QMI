## 5. NEXT-E-CAL：P108 的固定 critic 标定实验

### 目的

区分“输出后验没有标定好”与“分数已经丢掉依赖”。不更改训练 estimator 的定义，也不以 plug-in 更接近真值为由更换原始主训练目标。

令 U=T0(W)，拟合 g(U) 来预测平衡二元 C。三个固定候选：

- identity：g(U)=U；
- latent-affine：g(U)=tanh(α atanh(clip(U))+β)；仅为数值求解采用固定 ε；
- bounded bins：训练侧定义等频分箱，箱内按平衡 P/Q 权重求 C 的平方回归均值；输出天然在 [−1,1]。箱数使用预先固定的少量候选，在 CAL 内部选。

T0 在原 FIT 上训练；标定在独立 CAL 上训练和内部选择；EVAL 不参与。CAL 从总数据预算中划出，所有对照享有相同独立样本总量。单独报告“同一冻结 T0 的机制比较”和“相同总样本预算的端到端成本比较”，不能给标定版额外数据而声称样本效率提高。

复用 P108 的 C1/C2/C3、N=4096/16384 与已有 oracle。先固定 5 个拟合种子和少量预算，不重跑全旋转网格。若现有 split 不能提供未使用 CAL，重划分并对称重训对应方法，不从 EVAL 借样本。

每个候选同表给出：posterior MSE、J bias/RMSE、S_plug bias/RMSE、evaluation SE、拟合时间。选择只用验证平方风险。发现标定无改进时保留该结果，转查表示压缩和函数类，而非不断添加单调函数。

## 6. NEXT-I-NEST：有限扩大 nested_exact

### 6.1 真值压缩检查先行

两类设置均用现有 Gaussian oracle：

- 零增量：压缩只删独立无关维度，S_B=S_A。
- 正增量：压缩删去部分相关坐标，S_B>S_A；增量由两个 oracle S 的差求得，不假设 S 对坐标可加。

比较 independent、nested_sampled、nested_exact，分别用 VCS 与 JS 拟合。主要终点是增量点估计误差与两端后验误差；R_orth、数据处理排序违反次数、零假设底噪为辅助。

加入常零 critic 控制：常零可以使部分一致性残差看起来完美，但在正增量条件下应具有明显误差。用它阻止“所有读数缩小”被当成改进。
