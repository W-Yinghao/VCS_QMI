# VCS-QMI 第二应用：性质预检简报（服务器端，v1）

日期：2026-09-27
对应仓库：W-Yinghao/VCS_QMI，main 分支（2d394c2 及之前）
上游材料：合作者研究计划（Variational CS-QMI Research Plan，2026-09）；CVPR 草稿 v3；第二应用开放方案 v1；reports/PLAN_CONSTRAINTS_20260925.md；reports/SYNTHESIS_20260925.md；reports/SSL_TECHNICAL_NOTE_20260926.md

**本文性质。** 探索简报，不是第二应用的执行规范，也不是任何正式任务的运行授权。目的是在选定第二应用之前，用四个小规模预检判断这个估计器的哪些结构性质在实践中承重。本文只给问题、正面主张、判据、必须控制的变量和边界；数据、模型、网格、门槛数字由执行方在边界内自行设计，并在开跑前按现有 P 系列格式写成 PREREG_FROZEN 冻结。凡本文写"建议起点"的地方都只是建议，执行方可以替换，替换的理由写进 prereg。

## 0. 为什么先做性质预检，而不是任务预检

- 第二应用开放方案 v1 按任务列了七个候选（A 图文适配、B 异构双塔、C 错配图文、D 短语定位、E 音画、F EEG 对图像、G 多模态配准）。其中 A、B、D、E、F 在现有切法下都是把 InfoNCE 换成 VCS 后跑同一条流水线，最可能的结果是持平。持平不能告诉我们下一步该做什么。
- SSL 阶段的机理诊断已经显示，这个估计器有几条与 InfoNCE 在结构上不同的性质。这些性质在 SSL 里表现为限制；在别的观测关系里很可能是优势。第二应用应当落在这些性质承重的地方，而不是在 SSL 的地盘上再比一次。
- 所以先问"哪些性质在实践中成立"，再问"哪个任务"。四个预检各自决定一整族候选的去留。

## 1. 执行方需要知道的最少事实

### 1.1 第一应用现状（main 分支，5k 选择集，非官方测试集）

| 配置 | 线性验证 | 种子 |
|---|---|---|
| 4 视图，B 256，800 ep | 87.01 ± 0.53 | 3 |
| 同上，强增强 | 87.78 | 1 |
| SimCLR 匹配配方，200 ep | 86.09 ± 0.38 | 3 |

P41 等预算对照调参未启动，因此不存在"胜过 SimCLR"的主张。P44 顶界运行仍在进行，与本简报无关，不要为本简报的预检抢占那些作业的资源。

### 1.2 SSL 机理诊断中与第二应用直接相关的五条观察

1. **critic 收敛为一个阈值器。** 余弦 critic 学到 a ≈ 10、b ≈ −8，阈值 cos* = −b/a 落在 0.8 到 0.9 之间；负配对被推到阈值之下即不再有梯度。SSL 视角下这是"排斥太弱"；换个视角，这是逐对分数携带一个绝对阈值的机制。
2. **held-out J 在 0.93 到 0.965 之间，与表示质量解耦。** MLP critic 的 J 为 0.93 而有效秩 16，余弦 critic 的 J 为 0.97 而有效秩 58。增强配对的 T* 接近 ±1，目标对编码器几何没有话语权，几何由 critic 族和动力学决定。
3. **负样本从不主导梯度。** M = (P+Q)/2 锁定正负各半，K 从 8 到 255 只多约一分。
4. **z 是可分性码而不是检索码。** 长训练的 detach 基线里 z 挤在一个窄锥内，负配对余弦中位数 0.76，z 上的探针比 h 低 4 到 8 分，投影器有效维只有 15 到 31。
5. **负配对右侧 stop-gradient 让正配对基本不饱和**（饱和比例从 83% 降到 0 到 25%），并让负样本在梯度上等价于一个记忆库。

### 1.3 冻结项与可动项（摘自 PLAN_CONSTRAINTS_20260925，以原文为准）

**冻结：** 参考测度 M = (P+Q)/2；目标量 S = I_VQ ∈ [0,1]，CS 变换只在评估时用；J 的精确形式且正负两个分布分别平均；critic 输出必须是 tanh f_θ；不称其为 Shannon MI；Q 由乘积边缘采样得到（derangement、cyclic shift、cross-batch），不按难度选择。

**需先与合作者讨论，本简报内不做：** J 之外的辅助损失；参考测度改动；去掉 tanh；内部配对加权；hard negative 选择。

**可动：** 编码器与投影器；用 z 还是 h；batch 组成；优化器与调度；critic 函数形式（interaction MLP、bilinear、cosine 等，只要输出过 tanh）；配对方案；评估协议。

本简报的四个预检全部在可动范围内。若执行方在设计中发现某个想法必须触碰"需先讨论"项，停下来，把它写进报告的"需要讨论"栏，不要跑。

### 1.4 三条选择原则（贯穿所有预检）

- **P1 中等依赖。** 所选观测关系的 S 应明显小于 1。若某个预检里 held-out J 长期高于 0.9 左右，说明落入了 SSL 同一个退化区，该数据或设置不适合作为判据，应更换或报告为不可判。0.9 是经验值，执行方可以在 prereg 里给出更好的判据。
- **P2 指标不能只是 cosine 排序。** 单调 critic 不改变排序，排序类指标看不出估计器的价值。每个预检至少要有一个非排序类的主指标。
- **P3 真值按构造已知。** 优先选择依赖结构可以人为植入、或由物理量决定的设置，让预检同时校验估计器本身。草稿 6.6 承认估计器的受控验证还没做，预检可以顺手补上一部分。

## 2. 四个预检

每个预检按同一结构写：问题；理论依据与已证/启发式的边界；正面主张；预测信号；推翻条件；必须控制；留给执行方；建议起点；最小交付物。

### 预检 A：标定与阈值搬迁

**检验的性质：** 逐对分数有绝对意义。

**问题。** 训练后的 tanh critic 的 (1+T)/2 是否可以当作"该对是真配对"的概率使用；在一个数据集上定下的 T 阈值搬到另一个分布不同的数据集上是否仍然有效。

**理论依据。** 总体最优 T* = tanh(PMI/2)，在平衡先验下等于 2·P(真配对 | x, y) − 1，sign(T*) = sign(PMI)，PMI = 2·artanh(T*)。这是总体最优的性质，已证。有限网络在有限训练后是否保持标定是启发式，本预检检验的就是这一点。对手是带可学 bias 的 pairwise logistic（SigLIP 式），两者的差别是 Brier 损失对 logistic 损失。

**正面主张。** 在中等依赖的跨模态配对数据上，(1+T)/2 的可靠性曲线接近对角；在源集上按目标错误率选定的 T 阈值，搬到目标集后错误率的变化明显小于用 cosine 阈值做同样搬迁时的变化。

**预测信号。** 可靠性图的校准误差低于同一嵌入上未标定 cosine 的校准误差；阈值搬迁的掉幅低于 cosine 搬迁掉幅的某个比例。比例和分箱规则由执行方在 prereg 里冻结。

**推翻条件。** 校准误差与 cosine 加事后 Platt 标定无差异；或阈值不能跨集搬迁；或"标定"只在 J 接近饱和时出现（那是二值化，不是标定，见 P1）。

**必须控制。** 同一冻结主干、同一 adapter 结构、同一配对与身份划分；比较对象至少包含 InfoNCE 与 pairwise logistic；可靠性图和阈值搬迁都在未参与训练与选择的划分上做；用于评估的负样本来自独立池，不用 batch 内打乱，否则 Hoeffding 界的前提不成立；报告 held-out J、R_binary、饱和比例、若为余弦 critic 则报告学到的 a 与 b。

**留给执行方。** 选哪一对模态；哪个冻结主干；adapter 的大小与可训练范围；K；阈值选取规则；分箱方式；是否额外检验 PMI 恢复值 2·artanh(T) 的数值稳定性；是否同时看一个非余弦的 pair critic，以区分"critic 标定"与"嵌入标定"。

**建议起点。** 中等规模、许可清楚的图文配对数据一份做源、一份分布不同的做目标；冻结双塔加轻量 adapter；不追求检索指标。若图文管线搭建成本高，任何满足 P1 且有身份划分的跨模态配对都可以。

**最小交付物。** 三种目标并列的可靠性图；阈值搬迁表；held-out J 与饱和比例；对"该设置是否处于中等依赖区"的明确判断。

### 预检 B：闭式 critic 与神经 critic；配准能量面

**检验的性质：** 二次目标在固定特征类下有闭式 critic。

**问题一。** 在冻结特征上，线性类的闭式解与训练得到的 tanh critic 的 held-out J 差多少；闭式值作为 S 的下界是否有足够信息量。

**问题二。** 把闭式 J*(ω) 当作两幅不同模态图像在刚性或仿射变换 ω 下的相似度，其能量面与直方图 MI 或 NMI 的能量面相比，捕获范围和局部极小的情况如何。

**理论依据。** 对 T = wᵀφ，

```
J(w) = wᵀd − wᵀA_M w,   d = E_P[φ] − E_Q[φ],   A_M = ½(E_P[φφᵀ] + E_Q[φφᵀ])
w* = ½ A_M⁻¹ d,          J* = ¼ dᵀ A_M⁻¹ d
```

间隙恒等式 S − J(T) = E_M[(T − η)²] 对任意 L²(M) 中的 T 成立，因此闭式值是 S 的合法下界。已证。注意闭式解没有 tanh：本预检只把它用作测量和能量面，**不用它做训练目标**。若需要与冻结的输出形式对齐，可在闭式 w* 之外套 tanh(c·w*ᵀφ)，只拟合一个标量 c。A_M 允许加岭正则，正则量要报告。

**正面主张。** 其一，在同一特征类内，闭式 J* 与神经 held-out J 的差距小于跨 critic 族之间的差距，说明线性类不是瓶颈。其二，闭式 VCS 能量面在大初始偏移下的成功恢复率高于 NMI，且没有发散事件。

**预测信号。** 成功率差距的下限、能量面剖面上的局部极小计数、发散事件计数，由执行方写入 prereg。

**推翻条件。** 闭式 J* 系统性远低于神经 J（线性类太弱，性质只在理论上成立）；能量面局部极小不少于 NMI；成功率无差异。

**必须控制。** 同一 patch 采样规则与数量；同一有效重叠掩码与 padding 规则；同一变换族与初始偏移分布；同一优化器与步数；空间坐标不得直接喂给 critic；成功与否由真实变换真值判定，不用同一批 patch 的分数自证；不让重叠面积的变化通过统计量抬高依赖值。

**留给执行方。** 特征映射 φ 的选择（像素对的小基函数、随机特征、冻结网络的浅层特征）；图像对的来源（RGB-NIR、多序列 MRI、或其他已知变换的跨模态配对）；变换族范围；是否加 Parzen MI 和一个神经 MI 配准方法做对照；是否把预检 A 的冻结特征直接拿来做问题一。

**建议起点。** 一对或几对公开跨模态图像；先只做二维刚性或仿射；先画能量面，再谈优化。

**最小交付物。** 闭式对神经的 J 对比表；能量面剖面图；成功率对初始偏移曲线；发散事件计数。

### 预检 C：batch 解耦

**检验的性质：** 正负样本分别平均，负样本数不改变权重。

**问题。** 把 batch 从大压到小，VCS 的退化斜率是否小于 InfoNCE 与 pairwise logistic。

**理论依据。** J 是两个独立期望之和；n ≠ m 时固定 critic 的方差界为 1/n + 1/m。已证。SSL 中 K 不敏感已观测。是否转化为小 batch 下的实际优势是启发式。

**正面主张。** 同一冻结双塔加 adapter，在固定总更新数和固定总样本曝光两条轴上分别比较，VCS 在最小 batch 处保留的性能比例高于两个对手。

**预测信号。** 最小 batch 处保留比例的差距下限，写入 prereg。

**推翻条件。** 三条曲线重合；或 VCS 的优势只在某个 K 或某个学习率下出现，而对手没有得到同等的调参机会。

**必须控制。** 每种方法在每个 batch 点都有合理的温度、学习率、bias 等设置机会，调参预算公开；固定总更新数与固定总曝光两条轴分开报，不混；不用官方测试集；下游指标至少含一个非排序类指标（见 P2），检索可以作为辅助。

**留给执行方。** batch 网格；K；是否引入 cross-batch 或记忆库负样本（允许，属冻结清单中的 cross-batch）；若引入，陈旧步数的扫描范围；是否把"batch 内负样本"与"cross-batch 负样本"两种设置分开报告。

**建议起点。** 与预检 A 共享数据与冻结主干，省一套工程。

**最小交付物。** 三方法两条轴的退化曲线；每个点的 held-out J 与饱和比例；调参预算表。

### 预检 D：泄漏检出功效

**检验的性质：** 有界目标、分布无关的 Hoeffding 界、可给单侧下置信界。

**问题。** 当表示 Z 与一个 nuisance 变量 N 之间被植入已知强度的依赖时，基于 VCS 的检验在多小的样本量下能可靠检出；与 HSIC 置换检验和分类器两样本检验相比功效如何；条件版本 S(Z; N | Y) 在 Y 离散时用类内打乱是否精确可行。

**理论依据。** 草稿附录 B.1：固定 critic 下 Var(Ĵ | T) ≤ 1/n + 1/m，且以概率 1 − δ 有 S ≥ Ĵ_eval − τ_{n,m}(δ)，因此 Ĵ_eval − τ > 0 即拒绝独立。已证，前提是评估样本与 critic 拟合样本独立、负样本来自独立池。条件版本：Y 离散时在每个 Y 层内打乱 N，得到 P_Y · P_{Z|Y} · P_{N|Y} 的精确样本。此时 P 与 Q 的定义变了（条件化），要在报告里声明；参考测度仍是二者的等权混合，不碰冻结项。

**正面主张。** 在植入强度从零到中等的序列上，VCS 单侧检验的功效曲线在小样本端不低于 HSIC 置换与 C2ST；虚警率不超过名义 δ；S 的估计值随植入强度单调。

**预测信号。** 功效差门槛与样本量网格，写入 prereg。

**推翻条件。** 功效曲线与 HSIC 重合或更低；虚警率超标；估计值不单调。

**必须控制。** 植入机制与强度按构造已知，独立于任何训练；评估样本与拟合样本独立；负样本用独立池；多次重复报告分布，不只报均值。

**留给执行方。** nuisance 的植入方式（颜色偏移、纹理、通道统计、子群标签等）；Z 的来源（现有 CIFAR checkpoint 的冻结 h 是现成的）；critic 类；样本量网格；δ；是否附加一个连续 Y 的近似条件版本作为探索。

**建议起点。** 现有仓库的冻结 h 特征加人工 nuisance，完全不需要新数据。

**最小交付物。** 三方法的功效对样本量曲线；虚警率表；估计值对植入强度曲线；条件版本的一组结果。

### 顺序建议

预检 D 只依赖仓库里现有的冻结特征，其余三个需要新数据或新模块。顺序由执行方决定，但四个都要有结论，不要因为前两个结果好就跳过后两个。

## 3. 共同纪律

- prereg 先于运行，读法规则先写；门槛数字可以由执行方定，但必须在开跑前冻结，并写明为什么是这个数。
- 证据类别沿用现有约定：completed、report-only、pending、proposed，不得混用。
- 不评估任何官方测试集；所有划分按身份切；记录划分哈希。
- 数据只用公开、许可清楚的资源；下载前把来源、许可、哈希、身份分组方式写进 prereg；未核对的资源不得写成可用。
- 冻结项不碰；触碰"需先讨论"项时停下，写入报告的"需要讨论"栏。
- 对手要有同等调参机会，调参预算公开；保留失败配置，不删。
- 机制解释与观测分开写；单种子结果标注单种子；预检结果不外推为应用结论。
- 训练分布、评估分布、negative 来源在每张表里都要能一眼看出。

## 4. 结果怎么读

每个预检只能落入以下三种结论之一：

- **性质成立。** 主张与预测信号同时满足，对应的场景族进入候选。
- **条件成立。** 只在某些设置下成立；写清条件，对应族降为条件候选。
- **不成立。** 推翻条件触发；对应族出局，结果照样完整报告。

四个都不成立也是有价值的结论：它说明这个工具在实践中是一个 loss replacement，论文的重心应回到 SSL 加受控估计器验证，而不是硬凑第二应用。

四个预检做完不选第二应用。把存活的族列出来，标出各自需要的新增工程量和数据风险，交回讨论。

## 5. 执行方可以自行扩展的地方

- 允许提出第五个预检，条件是它检验一个性质而不是一个任务。例子：k 路联合对乘积的采样与 critic（各坐标独立打乱）；依赖对时滞或对层深的剖面；两样本用法下的有界域偏移量。
- 允许在预检内增加对照；不允许为了让某个方法好看而删掉最直接的基线。
- 允许用 h 或 z；允许任何输出过 tanh 的 critic 形式；允许 cross-batch 负样本。
- 不允许：hard negative 选择；按分数加权训练对；辅助损失；去掉 tanh 做训练；改参考测度。这些若在探索中显得必要，写进"需要讨论"栏。

## 附录 A：性质与场景族的对应（供理解动机，不是任务清单）

| 预检 | 性质 | 成立时打开的族 | 不成立时关闭的族 |
|---|---|---|---|
| A | 逐对分数有绝对意义 | 错配检测、开集拒答与验证、逐点 PMI 图、数据加权 | 同左 |
| B | 闭式 critic | 配准、传感器外参标定、跨谱立体代价、无标签嵌入探针 | 同左 |
