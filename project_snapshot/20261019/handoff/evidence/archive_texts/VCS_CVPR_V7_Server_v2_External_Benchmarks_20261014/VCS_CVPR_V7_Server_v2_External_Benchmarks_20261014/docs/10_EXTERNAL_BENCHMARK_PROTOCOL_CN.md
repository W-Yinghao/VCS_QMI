# 外部比较的目标、面板与公平性

## 1. 每行先写估计对象
每一行必须有 `method_id, native_target_id, readout_target_id, pq_id, feature_manifest_hash, reference_measure, sample_role, units`。不同目标不在一列RMSE里排名。

| 面板 | 合法方法 | 真值/终点 | 禁止混同 |
|---|---|---|---|
| A0 原生固定参考CS | 经典CS-KDE/信息势 | D_CS^Lebesgue 的解析或高精度真值 | 不能对它用S或混合参考CS当真值 |
| A1 共同混合参考S | VCS、KDE-posterior、RuLSIF、核平方回归、BCE后读J、经正确映射的KL critic | 同一S、同一eta（有oracle时） | 不把T² plug-in与J混列 |
| B0 原生非CS估计 | DV/MINE、NWJ、InfoNCE、SMILE、LSMI | KL/MI或Pearson各自真值及可实现变分值 | InfoNCE有限K的oracle界不等于MI真值 |
| B1 共同关系检验 | 上述分数、CS-KDE、MMD、HSIC | 同一零假设、规定alpha的功效 | 不直接比较原始统计量大小 |
| C0 语义事件概率 | V7共享表示上的核/相对比/KL/VCS/BCE | soft投票Brier、NLL、公共J | 人工投票不是已知自然eta |
| C1 完整视觉应用 | 发布评分器、完整V7模型、可用的核/KL任务适配 | GenAI-Rank人工M9/Regret、外部SRCC与成本 | 人工总体H不等于元素均值E |

## 2. 历史受控数据复用
先覆盖独立、相关Gaussian、nonlinear/cubic、多模态混合、无关维度、N轴和batch轴的有效已有单元。用最新修正产物而非旧P151字段。目标真值从原始生成器密度/已验证积分得出，TRUTH样本不可用于选带宽和模型。

最低报告应包含：各自native bias/RMSE；共同S中的后验误差或J-gap；收敛曲线；独立评价波动；非有限步骤；pair数和总成本。若某指标没有保存，可以恢复则恢复，必须补跑则明确配置，不为填齐表悄悄插入默认值。

### 新的解析锚点（仅在已有结果不足时补）
(a) 两个等协方差Gaussian，均值差0/小/大，直接检验原生CS、KL和同目标后验。
(b) 联合Gaussian对边缘乘积：固定每侧维度，改变相关；再分别改变无关维度与样本数。
(c) 已知密度的混合/非线性分布：检验核选择和高维模型取舍。对可逆变换，S/KL具有不变性，固定参考CS的变化必须按它自己的密度重新算。

建议先复用N=256/4096及三个原有训练seed，不立刻新开全笛卡尔积。若要测95%区间覆盖，3个seed远远不够：另做明确的数据重复实验并报告Monte-Carlo不确定性；初始化seed不冒充独立样本抽取。

## 3. 核方法不能故意设弱
默认候选按独立FIT上的距离尺度：带宽倍率{0.25,0.5,1,2,4}，正则{1e-6,1e-4,1e-2,1}，中心数{256,1024,min(4096,N)}。仅作初始搜索规范，实际N和维数可能要求调整；首次冻结前给资源上限。

若选中网格边界，允许一次预先声明的同方向扩展，并计入成本；不能反复扩到某方法赢。无关维度轴至少区分各向同性核与FIT-only标准化/对角尺度版本；若训练ARD，明确它已经具有可学习度量并给予相应成本。低维KDE提供规则带宽与CAL带宽对照。

Nyström是RKHS近似，不等于随意把核中心特征做ridge。实现应写正则在系数空间还是RKHS范数；用近似特征Phi=K(x,C)(K_CC+eps I)^(-1/2)时，ridge对应近似RKHS范数。不能用raw kernel features的系数ridge，名字却只写“exact kernel method”。

## 4. 三种预算同时记录
1. 独立基础观测/图片/提示数；2. 构造pair与kernel评价次数；3. 训练、调参、编码、推理的实际总时间和显存。

主学习曲线固定独立数据量；同目标正负P/Q池或精确权重一致。多负例cyclic/in-batch与independent-product分列；N² pair不等于N²个独立样本。允许算法利用自身结构提速，不能以“closed form”当作零成本。

## 5. 非CS的方法要按原生目标给公平参数化
DV/NWJ不套VCS的tanh输出，否则人为剥夺其无界log-ratio函数类。共享隐藏层，但输出映射按原方法。各方法学习率与停止规则可不同，选择机会对称。MINE应注明是否用了其EMA梯度修正；纯DV与MINE实现不无区别混称。[X05,X06]

不能靠缩小目标常数获得“最低梯度方差”：同时报告更新范数、收敛、相对波动、绝对误差和time-to-quality。选定时间阈值或误差阈值在CAL确定，失败按失败报告。

## 6. 检验的有效性
两个独立P/Q样本的同分布检验可在测试池交换组标签；已拟合critic不参与测试标签调优。依赖检验应在独立配对数据中置换一侧，或按场景使用正确块/分组置换。两种零假设不同。

共享图像/多元素/同提示图像不具备pair级交换性时，不能直接使用任意置换制造“显著功效”。没有可证明/验证的重采样设计时，报告分辨曲线而不是伪造受控alpha检验。特征/核若由测试标签选择，需重拟合置换流程或改用独立训练角色。[X08,X09]

## 7. 数值和取舍
有界S在强依赖时也会饱和；log变换会放大误差。InfoNCE有logK上界但仍可能保留排序。不要预写VCS无限高依赖可分、所有KL方法失败、核高维必然失败。

所有方法的native读数和共同读数分别存。经典CS常有1/2因子差异：本包使用平方比约定，必须记录scale_factor而非静默乘2。S的模型级差异只有P/Q、表示和评价池相同才可直接比较。
