# 本轮算什么、复用什么、哪些需额外预算

## 已有V7完整训练不变
- N0/M0/M1/M2 × seeds0/1/2 = 12个正式训练单元。
- M0/M1/M2 × 3个学习率 × tuning-seed17 = 9个调参单元。
- 已运行者复用。v2不改变原始损失、图文输入或初始权重，不“重新开始V7”。

## 新增与必做
| 任务 | 动作 | 是否新训练 |
|---|---|---|
| X00 | 接续新HEAD、登记所有标签使用和原作业 | 否 |
| X10 | 旧CS/MI/MMD/HSIC结果覆盖与后续修复核对 | 以重读为主 |
| X11 | 经典CS/KDE/RuLSIF公式与实现核验 | CPU参考；真实缺失另计 |
| X12 | 非CS原生指标整理，列缺失单元 | 不是重启完整旧网格 |
| X20 | 从共同BLIP2初始模型提取语义特征 | 一次固定视觉前向，计成本 |
| X21 | 4神经×3seed+3确定性核的共同特征拟合 | 15个主拟合，不是完整VLM训练 |
| X30 | FGA/VQAScore/TIFA/DSG/PN-VQA外部评分 | 主要为公开权重推理；本地适配另记 |
| X40 | 外部主表、归因、失败和版本合并 | 否 |

X21神经模型的网格候选数量与v1大模型网格分开，先实测再冻结；各方法都得到相同大小的选择机会。核网格必须计入总耗时，不把一次闭式求解当作全部成本。

## 共同特征结果不替代完整模型结果
共同特征表比较的是估计方法给定相同信息的能力。完整V7神经模型更新了多模态表示，其最终结果更好可能同时来自表示训练。需要分两张表：不能让核只看初始表示、神经看适配表示，却标成“仅估计器不同”。

若需要同一强表示检查，先预定一个与VCS目标独立的、仅用FIT训练的参考模型并对所有方法使用；它属于敏感性，不根据哪套表示让VCS赢来选择。发布FGA不可充当未暴露local holdout的特征源。

## 进度汇报
第一轮返回任务状态、文件入口与缺失预算；不是只有JOBID。后续外部方法与M1的结论分开写，特别是“VCS和BCE都胜核/旧系统”应允许作为共同神经路线的正面结果，但不是二次损失独有证明。

若资源不足，优先核心公开系统与完整主模型，其次同目标KDE/RuLSIF与DV/NWJ；不要只保留M1和M2而把全部外部方法标为将来做。无法完成的一类会限制相应主张，不等于整篇研究自动终止。
