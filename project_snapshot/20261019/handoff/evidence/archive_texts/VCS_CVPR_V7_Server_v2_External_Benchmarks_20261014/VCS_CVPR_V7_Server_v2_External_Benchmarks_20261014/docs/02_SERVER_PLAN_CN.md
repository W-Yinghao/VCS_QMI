# V7 v2 主任务书：外部基准先行，归因随后

## 1. 研究目标
保留 V7 的完整任务：对生成图像中的文字要求作概率估计，再在相同九图候选池中选出更符合提示的图像。新版不以“每个应用都必须战胜Logistic”为进入条件；它分别检验**传统估计路线的改进、非CS替代工具的取舍、完整视觉能力、收益归因**。[F01 §12–13,F02附录4]

## 2. 主张与证据
| 主张 | 主对照 | 主要指标 | 结果边界 |
|---|---|---|---|
| H-CS：在规定高维/样本预算下，学习型路线更有效 | CS-KDE、RuLSIF、共同核拟合 | 同目标误差/风险，原生CS自身误差，质量–成本 | 不由换参考测度产生“误差优势”；核可获胜 |
| H-NC：与非CS估计工具相比有实际取舍 | MINE/DV、NWJ、InfoNCE、SMILE、适用的MMD/HSIC | 各自真值误差、统一检测功效、收敛/失败/成本 | 不把 Shannon MI 当成 S 真值；无普遍稳定性预设 |
| H-APP：图文评分和选择有外部竞争力 | FGA、VQAScore、TIFA、DSG、PN-VQA | GenAI-Rank M9/后悔值，外部相关性，完整成本 | 不只胜CLIPScore，不把自有J当人工质量 |
| H-ATTR：哪些收益来自二次拟合 | 同架构L1/Logistic、共享表示与辅助项 | Brier、M9差值、结构消融 | 不利结果完整保留；它不取代前三类证据 |

预期优势是待检验假说。方法的新颖性仍需在RPC/RuLSIF等先行工作之后明确，外部胜出不能自动制造新理论。[T01,X01–X12]

## 3. 执行块与依赖
### X00：接入与差额
保留旧 V7-00…06 的进度和 N0/M0/M1/M2，读取新 HEAD。已开始的训练不改变损失、数据或选模；若先前看过终末标签，v2 新比较标为修订而非事前冻结。

### X10：估计器外部证据盘点
复用 P85/P86/P108/P151/P152 及后续 R4 修复结果。逐项核对目标、采样、带宽、选模角色、产物和版本；输出真实缺失项。闭合历史线不等于主论文可以漏掉外部方法，但这次也不授权无区别重跑全部网格。

### X11：传统CS与共同S
必须具备：(a)经典固定参考CS-KDE及原生真值/单位；(b)KDE→共同S读数；(c)RuLSIF；(d)核平方回归。RFF/Nyström是实现容量，不算多篇外部算法。有限公式先通过CPU检查，新增自然数据比较见X21。[X01–X04]

### X12：非CS原生估计与检验
MINE/DV、NWJ、InfoNCE、SMILE 在相同受控生成器上各估其定义的目标；只补已知缺失字段/不公平配置。MMD/HSIC 在独立样本或有正确分组置换的实验上评价水平与功效；无合法置换就不报告“同误报率”。新的批量/高维训练先提交缺失清单和预算。[X05–X10]

### X20/X21：V7共同特征的外部估计比较
固定未用EvalMuse训练的共同BLIP2初始化与元素接口；从全FIT提取特征。四条同容量神经拟合（VCS、BCE、DV-KL、NWJ-KL）×3 seeds；KDE、RuLSIF、Nyström核平方回归各1个固定确定性配置，总计15个选定拟合。全部计算相同语义事件的概率风险；能产生样本后验者用相同 E 聚合接入九图池。**不是把经典CS的一个批次标量直接当每图评分。**

各方法的输入、样本与角色一致；高维预处理只能FIT估计且所有方法共享。核fit确定时不重复三次复制数字作为seed方差；Nyström中心和任何随机特征的随机性单列。

### X30：公开完整方法
B0发布FGA、原生强VQAScore、TIFA、DSG为必做复现；N0本地重训与发布checkpoint分列。PN-VQA、现代VQAScore、可用偏好模型/新评价器进入扩展表。源实现或依赖不可获得时，必须给出证据和明确替代，不能悄悄删掉该行，也不能据少数可用旧模型宣称领域领先。[P01–P10]

### 原V7-03：完整模型训练继续
12个正式训练单元与9个调参单元不变。训练型外部基线与VCS使用同样FIT；发布权重只用于系统参照。核/小网络估计实验不代替这一完整训练。

### X40：综合报告
先外部方法，再内部归因。所有预定方法的完成状态、失败、标注/数据暴露、不同目标名称和预算均进入表；缺失不填0、不伪造最差数字。

## 4. 本轮完成的含义

不因这次改包重启SSL、大规模CLIP预训练、扩散模型训练、RefCOCO新网格、付费API或人工标注。条件CS、CS-IB、CS-Aligner作为关键已发表路线必须定位，但不是本应用即插即用的逐图满足概率基线；额外应用对照先明确接口与预算。
