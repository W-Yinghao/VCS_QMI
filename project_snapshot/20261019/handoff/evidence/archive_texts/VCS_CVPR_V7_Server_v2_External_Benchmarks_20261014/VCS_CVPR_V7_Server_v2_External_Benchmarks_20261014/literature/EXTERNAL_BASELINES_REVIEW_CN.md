## 二、直接密度比与已有二次目标
RuLSIF（NeurIPS 2011）以相对比p/(alpha p+(1-alpha)q)缓解普通密度比的高波动；uLSIF（JMLR 2009）具有闭式拟合与模型选择；LSMI采用平方损失MI/密度比，原生目标是Pearson式而非S。[X03,X04,X12]

alpha=.5的相对比与eta只差1，这是强而直接的外部比较，不能仅用一个随意加tanh的ridge版本代表它。V7将原生CV、非负处理与后验投影分别标记。

RPC的平衡参数实例等于原始J。[T01] 完全相同配置只需函数/梯度一致性校验，不重复训练两行制造“击败另一方法”。原生不同参数/训练方案如果另比较，才具有真实算法差异。更换任务不会消除这层归属。

## 三、非CS神经估计与核检验
MINE（ICML 2018）将MI估计变为神经优化；Poole等（ICML 2019）明确不同MI界的偏差–方差取舍；SMILE（ICLR 2020）是重要稳定化对照。[X05–X07] 原计划从一开始就要求这些外部方法，而不只是BCE。

MMD（JMLR 2012）与HSIC（NeurIPS 2007）提供不同的分布/依赖检验路线。[X08,X09] 合理比较是正确误报率下的功效、数据与成本，不是原生数值谁更大。学习核与固定核分列，方法用过的标签需在置换/数据分离中考虑。

V7新增的DV/NWJ语义任务桥接不是它们的原始benchmark，而是从通用KL比估计得到样本后验的明确适配。InfoNCE/SMILE没有默认的同接口样本后验，因此先在原生依赖面板承担主要比较，不伪造它们在元素Brier表上的数字。

## 四、完整视觉比较的独立意义
EvalMuse/FGA、VQAScore、TIFA、DSG都是已发表完整任务路线。[P01–P05] v2把这些放进主要系统表；不再用四个自有训练配置替代对它们的竞争。图文证据可以来源于交叉注意力、整体问答、分解问答或语义依赖处理；这些结构与计算不同，需同时列原生系统和同宿主控制。

FGA公开活跃训练分支是L1，故必须保留N0/M0；Logistic只能解释二次后验拟合，不代表所有非CS方法。官方GenAI-Rank在人类标签下进行候选选择，是完整应用终点；内部J并不是该标签。[G02,G07,P02]

## 五、我们预期什么，而不预先宣布什么
预期检验三条：学习型CS相对传统估计的有限样本/维度收益；相对非CS估计的可用精度–成本；完整评分器相对公开方法的人类选图收益。平方损失与BCE的差异是归因问题。一个方向获胜不自动证明另外两个，BCE接近也不自动否定整个体系。
