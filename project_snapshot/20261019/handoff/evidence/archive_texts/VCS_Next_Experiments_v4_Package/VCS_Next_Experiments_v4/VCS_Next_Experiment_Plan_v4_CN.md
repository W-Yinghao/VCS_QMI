## 1. 总体目标

下一轮同时回答三个问题：

1. **学得更好：**怎样用原始二次目标训练出更强的视觉表示？
2. **测得更准：**在给定表示或数据分布上，怎样提高依赖估计的精度、样本效率和计算效率？
3. **用得上：**估计出的依赖能否帮助识别模型保留和使用的视觉属性，并支持具体的分析或决策？

三者共享合作者的定义与变分目标，但使用不同的评价终点。训练用的固定相似度评分器，不承担对任意冻结表示精确估计 S 的要求；测量用 critic 在冻结表示上独立拟合。通过专门的交叉测量实验研究两者的关系，不预设更高 J 必然带来更高分类准确率。

合作者原始核心保持：

\[
M=(P+Q)/2,\qquad
J(T)=E_PT-E_QT-\tfrac12E_PT^2-\tfrac12E_QT^2,
\]

\[
S-J(T)=E_M[(T-\eta)^2],\qquad
\eta=(p-q)/(p+q).
\]

主要应用继续是完整视觉 SSL；不扩建 CLIP 系统。不把新的残差算法、解释方法或大规模数据下载设为 SSL 继续推进的前置条件。

# A. 完整 SSL：五个新单元解决两个核心问题

## A0. 先收齐已安排的确认

- G2 与 G2F，各 seeds 0–2。
- U2 与 U2F，各 seeds 0–2。
- 继续收齐已授权 P100（momentum queue）等分支；本文件不取消或重复它们。
- 每个结果同时报告预训练配置、最终 epoch、原始 h 的线性读出、kNN 和实际时间。
- 三种子包含已用于开发的 seed 0；有希望的结论再用预先固定的新 seeds 3–4 确认，避免把开发筛选当成独立确认。

问题是：改善主要来自相同初始 a,b，还是来自整个训练过程中固定刻度？

## A1. 补齐“评分形式 × 损失”的小型比较

主比较：

| 评分形式 | VCS 原 J | 匹配 JS/logistic |
|---|---|---|
| 固定 f=2s-1 | 复用 G2 | 新增 A-L1 |
| f=as+b，从 (2,-1) 开始学习 | 复用 G2F | 新增 A-L2 |

其中 s 为单位投影表示的内积，T=tanh(f)。JS 使用：

\[
L_{JS}=\operatorname{mean}_P\operatorname{softplus}(-2f)
+\operatorname{mean}_Q\operatorname{softplus}(2f).
\]

两边保持相同 encoder/projector 初始化、增强、配对索引、负右端 detach、训练长度和评价。第一轮为严格匹配配置比较。因两种损失的梯度在 f 不为零时不同，严格匹配并不等于两种损失各自充分调优；最终胜出主张还需要一个预先规定的小型优化器/学习率敏感性对照，不能将相同超参数当作充分调优的保证。

这组实验的解释：

- 固定刻度同时改善 VCS 和 JS：主要收益来自评分结构。
- 固定刻度下 VCS 仍优于 JS：说明平方目标与该结构有有利交互。
- 差异很小但 VCS 达到相同质量更便宜：转而报告质量–计算取舍。

不要将任何一种结果提前写成结论。

## A2. 围绕 G2 建立完整的配对与梯度 2×2

过去的 G3/U2 使用 a=1,b=0；它们没有回答 a=2,b=-1 下的组合效果。固定 G2 的刻度，补齐下表：

| 配对范围 | 负右端 detach | 负双侧普通反传 |
|---|---|---|
| K=8 跨视图循环移位 | 复用 G2 | 新增 A-P1 |
| 全部视图 token 配对 | 新增 A-P2 | 新增 A-P3 |

五个新完整训练单元为 A-L1、A-L2、A-P1、A-P2、A-P3。第一轮每个 seed 0，4 views、B=256、800 epochs；每个候选通过实现检查后完成完整日程。早期 J、rank、kNN 用于诊断，不作性能型提前淘汰。

全视图构造保持 P/Q 各自平均：

\[
n_P=VB(V-1),\qquad n_Q=VB\,V(B-1).
\]

P 为同一图像不同视图的所有有序对；Q 为不同图像的全部视图组合。正配对始终双侧梯度。完整负梯度使用普通反向传播，不增加任意负损失系数、不使用自定义梯度补偿。

这三组将分别检验：更完整的负项梯度、较少的配对抽样噪声、二者的交互。不能由 G4 的失败推断 G2 下完整负梯度也必然失败；也不能假定两个单项收益可相加。

## A3. 精度继续提高的后续空间

先完成上述比较，再确定两项以内的后续改动：

1. **固定刻度的小范围敏感性。** 只有在 G2 对 G2F 的结论明确后，围绕 kappa=-b/a 与 a 做少数单因素完整训练；不重新展开大网格。
2. **增强交互。** 最终候选与 SimCLR 都使用相同的标准/强增强块。复用匹配的 P90 结果，不拿新方法强增强与旧对照标准增强比较。
3. **投影结构。** 仅当层间测量显示新的具体瓶颈时，测试一项 projector 深度或归一化变化。旧自由 MLP 的结果不能自动替代新固定评分器的结论，但也不因此全量重扫。
4. **预算效率。** 从零分别训练 200 和 800 epochs 的冻结配方，画实际时间–精度曲线。长日程中的 epoch 200 checkpoint 不是一个独立 200-epoch 日程的替代。

不默认增加到 1600 epochs，也不把更大的 backbone 当成 estimator 改进的证据。

## A4. 正式确认

优先比较当前最强候选、原 VCS、匹配 JS、充分调优 SimCLR；直接 CS 核路线保留为研究主线对照。关键正向候选的种子、增强和读出规则统一冻结。

第二视觉数据集首先复用已有 CIFAR-100 接口，使用相同选择程序，不为每个方法临时选择不同的 probe。原始 h 与 L2-h 结果并列时，主要读出规则事先固定，不能事后选最高列。

ImageNet 仍需单独的数据与算力决定。本计划不授权下载或启动 ImageNet 作业。

# E. 估计器：优先做能直接支持主理论的两项实验

## E1. 相同 critic 下，变分读数与平方 plug-in 的误差

固定一个已经拟合的 T，比较：

\[
\widehat J(T),\qquad
\widehat S_{plug}(T)=\tfrac12\overline{T_P^2}+\tfrac12\overline{T_Q^2}.
\]

二者使用完全相同的独立 EVAL 样本，区别只有读数公式。

若 T=eta+e，总体上：

\[
J(T)-S=-E_Me^2,
\]

\[
S_{plug}(T)-S=2E_M[\eta e]+E_Me^2.
\]

设计两层验证：

- **精确机制检查：**构造有界 T_t=(1-t)eta+tU。预设 U=0 与一个独立的非零有界函数，检查偏差随 t 的阶次。U=0 时，J 的偏差为 -t²S，plug-in 的偏差为 (-2t+t²)S。
- **真实拟合检查：**复用 P85/P86 数据生成器、oracle 与函数类，选三个预定条件（中等 Gaussian、高维加无关维度、非线性条件），改变独立 FIT 样本量与求解预算，比较 signed bias、RMSE、后验误差、评估方差与拟合成本。

同一偏差阶次不保证每个有限样本格子上 J 的 RMSE 更小；实验同时报告偏差和方差。J 可在 EVAL 为负，原值保留。不同读数的数值量不能混合成一个最优成绩。

JS 拟合得到的 T 也可代入同一 J，作为“公式的性质”与“拟合损失的性质”的拆分对照。保留原计划要求的 MINE/NWJ/InfoNCE/SMILE 参照，跨目标时比较各自真值误差或阶梯分辨能力，而不是共同的原始数值。

## E2. 高维优势与实际求解成本

复用已经完成的无关维度与样本量实验，不重跑完整旧网格。新增：

- 每端分别施加固定的可逆正交旋转，将已知信号分散到多个坐标。旋转在数据划分前固定，所有方法共享；真值由原生成器的逆变换计算。
- 原坐标和旋转坐标使用相同 FIT/TUNE/EVAL、网络宽度、核选择程序和独立样本预算。
- 每种方法在有限的固定时间/更新预算点上测同目标误差与后验误差，记录调参总成本以及选定模型的成本。

主要结果是“误差–独立样本数”“误差–时间”曲线。不要仅用某个单次拟合的运行时间宣称效率优势，也不要把所有交叉 pair 数当成独立样本数。

如果收益对旋转敏感，结论应具体定位到有效结构和函数类；这也会指导以后是否值得加入低秩输入映射。首轮不把低秩映射加入主模型。

## E3. 计算和推断的可用性

从上述数据直接补充：固定精度所需的时间、显存、不同求解停止点的波动、独立重复拟合的误差。P105 的二次闭式/迭代求解与 JS 数值求解也同时记录时间和停止残差。

不把“L-BFGS 数值收敛”称作解析闭式解；对 tanh 包裹后的模型，不将未包裹 ridge 解说成最终非线性目标的精确最优解。

# X. 交叉测量：连接表示质量与 estimator 质量

## X1. 统一独立测量 critic，避免自评分

冻结 4 类 encoder：原 VCS、G2（确认后）、U2（确认后）、同预算 SimCLR。优先使用最终 checkpoint，早中期 checkpoint 只在实际保留时加入。

每种表示上独立拟合统一的 measurement critic 家族：校准 cosine、小型配对 MLP、一个既有核/相对回归参考。选择过程只使用 FIT/TUNE，EVAL 仅记录。加入 T=0 作为候选，可判断有无有效估计；EVAL 负 J 不裁成零。

测量与表示两类结果并排：

| 编码器 | 训练评分 J | 独立测量 J | frozen linear / kNN | 对任务外属性的条件依赖 | 干预后的预测变化 |
|---|---|---|---|---|---|

独立测量 J 仍是有限函数类的下界读数，不叫真实 S。对同一表示使用不同测量器的分歧，描述测量的不确定性。对不同表示，不以最高 J 代替最终质量。

重点检验：G2 是否在训练分数更低时，已经形成更有用的表示；独立重拟合是否仍恢复很强的配对关系；任务外属性与下游行为如何变化。没有预设必须出现哪一种相关性。

## X2. task 信息与 nuisance 信息分开评价

可分别估计 S(H;Y) 和条件 S(H;N|Y)，但各自使用固定标签分布与配对协议。不将不同变量上的原始依赖值简单相减形成一个未经验证的综合分数。

任务标签可用于下游与分析训练集，不能进入 SSL 预训练。该分析中的标签使用必须单独标明。

多个 checkpoint 来自同一训练轨迹，不能当成独立预训练重复。跨模型的关联图作描述；不以少量模型上的相关系数代替方法验证。

# I. 可解释性：从“检出”推进到“定位和实际使用”

## I0. 先完成已经安排的 P105

P74 的优势首先是一个完整 estimator 管线的功效优势。P105 区分 VCS/JS 的目标、critic 类及求解器。无论结果来自何处，都记录真实的精度–求解成本取舍；不为了维持独有性质而删除公平对照。

## I1. 主应用：条件依赖审计

核心问题：**模型是否保留某个任务外属性？这一属性是否进入预测？**

每个模型冻结 encoder 和 clean-trained classifier。使用已有颜色、模糊构造，优先保持实验可比；后续只增加一种局部属性，例如已知位置的纹理或角标。

对每张基础图像生成配对版本，记录类别 Y、植入状态 N、强度 s 和图像 ID。基础图像按 FIT/VAL/EVAL 分离，同一图像的所有版本不得跨集合。

三层输出：

1. **存在：**检验 H 与 N 在给定 Y 后是否相关。报告功效、错误拒绝率、样本数和测量成本。
2. **保留位置：**对固定层/投影/logits 进行同一检验与依赖估计。事前定义层集合；多层正式显著性使用共享置换的 max-statistic 或明确的多重比较校正。
3. **预测作用：**计算同一图像干预前后的预测概率差、分类 margin 差和准确率差，按类别汇总。高依赖但几乎无预测变化，与进入预测的依赖分开报告。

这比单独展示热力图更能验证工具。属性强度与信息损失增量不要求单调；分别报告 H 和 logits 的依赖曲线。强模糊可能损害真正的类别证据，不能预先当作纯 nuisance 或把所有准确率下降都称为 shortcut。

所有学习型检验统计量在 EVAL 外拟合和选择，EVAL 上的置换不再调参。离散 Y 下的类内置换需要对应的条件可交换性；图像多版本按基础 ID 保持采样单位，不能把重复增强当成独立观测。

## I2. 依赖增量的改进，作为并行小实验

P102 的误差说明，分别拟合不同信息集的 critic 会产生不同程度的逼近误差。新增两项，而不强行让结果满足理论：

- 细信息集 critic 保留一个可精确复用粗信息集 predictor 的分支，使其函数类真正包含粗模型；同时保留独立拟合对照。
- 对已有的二元 N、已知 P(N|Y)，负项可通过对 N=0,1 加权枚举得到，去掉条件负采样噪声。此处理也给 JS 对照使用。

共同/残差训练需独立评价。不能对 EVAL 差值做截零、单调回归或强制正交，然后再宣称理论被验证。记录 Delta_J、D_T、二者差、链的正交残差以及独立 refit 波动。

先在一个零依赖和两个非饱和条件上完成 pilot，确认误差确有下降后再扩展。这里的 pilot 是测量算法验证，不替代 SSL 的完整训练。

## I3. 空间可视化是后续展示，不是第一终点

局部植入属性有已知位置，可对预定区域进行条件依赖审计，再做保留/去除该属性的输入干预。区域选择在 FIT/VAL 上完成，在新的图像上验证。

卷积特征的感受野可能跨区域，输入植入位置不等于某个 feature cell 的唯一因果来源。单对的 critic 分数也不是像素贡献度。空间图必须与植入位置、随机区域和干预结果共同评价。

# V. 不限于 accuracy 与解释性：三类有价值的补充

## V1. 少标签利用与跨数据迁移

对最终冻结 encoder，在预训练 FIT 图像的 1%、10%、100% 标签子集上训练相同读出；子集按类别固定，并在所有方法间共享。新 probe 的超参数只在 FIT 内选择。报告标签效率，不将其写成 estimator 的无标签样本效率。

可使用 CIFAR-10 预训练 encoder 到 CIFAR-100 的冻结迁移读出；目标数据只训练下游头，另列为 transfer，不与在 CIFAR-100 从零 SSL 的结果混合。

## V2. 自然扰动与压缩耐受

初期使用训练/验证分区上的固定、可复现变换做开发；冻结模型、分类器和协议后，才做授权的标准 corruption benchmark。

报告 clean accuracy、各严重度 corrupted accuracy、相对下降及预测一致性。严重度作为同一基础图像的重复观测，置信区间按图像聚类。性能水平不同的模型同时给出绝对准确率与相对退化，不只挑其中一项。

CIFAR-10-C 基于官方测试图像生成，不得拿来为本轮新配置选参数。现有 official test 已被多轮研究读取，论文应披露；新的主要泛化结论还需要独立确认。

## V3. estimator 辅助选择：候选应用，不马上扩大

可构建一个受控的模型/表示选择任务：若干训练配置在 clean-validation 精度接近，但利用颜色/角标的程度不同。比较只按 clean accuracy 选择，与加入条件依赖审计后的选择，在独立的关联反转环境上表现如何。

预先定义选择规则，和 HSIC/JS 审计作对照。模型池、阈值选择与关联反转测试分离。不预设低条件依赖一定有更低目标风险；只有选择真的改善外部结果时，才把它写成决策用途。

此模块适合作为“测量是否有行动价值”的候选，优先级低于 A、E、I1。无需进入 CLIP，也无需先训练复杂的去偏网络。

## 5. 统一汇报字段

每个实验交付一张完整结果表和一段结论，字段至少包括：

- 研究问题、主要终点、对照与实际完成范围；
- 数据划分、基础图像数量、正负 pair 数和独立重复数；
- 原始目标、critic/评分形式、训练路径；
- 配置与 checkpoint hash、完整/未完整运行状态；
- 逐种子或逐重复数据、均值与样本标准差、配对差值；
- 实际 GPU/CPU、训练/拟合/评估时间、峰值显存；
- 训练评分与独立测量分开，变分 J 与真实/参考 S 分开；
- 主要结论、机制推断及尚待检验的解释分开。

不通过同一批结果反复更换主指标。统计上的未达差异标准不等于等效；需要等效结论时先给出具有实际意义的容许区间。

## 6. 当前优先判断

accuracy 仍有具体空间：固定刻度与配对/梯度交互尚未被完整检验。最值得新增的是五个直接对照，而不是一个新的大模块。

estimator 最应展示的两项新增证据是：相同 critic 下变分读数的误差性质，以及高维/有限预算下学习型估计的精度–成本取舍。

可解释性的主应用应为受控条件依赖审计：先检出、再定位、最后验证预测使用。精确增量分解作为估计能力加强，而不是先验要求真实数据必须出现漂亮的正交图。

低标签、迁移、扰动和选择用途提供更广的应用价值；它们按优先级逐步开展，而不是同时建立多个独立项目。
