## 3.2 保留原协议，再加相同信息的读数

R4-VL2 的原生排序为：

$$
\ell_\nu(r,w,G)=\log\nu(r\mid G)+2f_\theta(r,w,G).
$$

它来自 $e^{2f^*}=p(r\mid w,G)/\nu(r\mid G)$。改变 $\nu$ 是改变 $Q$，不是对同一 QMI 换一个无偏采样器。[S2,O1；D1]

先保留原来的 C1–C4、固定融合与全部 seed，再附 R5 读数：

| 分析 | 规则 |
|---|---|
| F0：原协议 | 完整保留，不改历史选择和原始数值 |
| F1：固定 checkpoint 的 CAL 融合 | 每个目标相同的 $\lambda\in\{0,0.25,0.5,1,2,4\}$；按 CAL 选，DEV 只读所选与冻结锚点 |
| F2：epoch＋融合 | 仅当各方法有相同可恢复 epoch 范围时追加；缺权重不假装重新选择 |

统一融合分数为 $2a\cos+\lambda\log s_{\rm det}$。对 $\nu$ 训练模型，$\lambda=1$ 才对应其原定义下的后验修正；其他值是任务校准，单独标记。F1/F2 是既有完整模型的评分重读，不是新的冻结特征探针。[S6；本轮新增控制]

若旧模型按未融合准确率选 epoch、新模型按融合准确率选 epoch，则 C3 包含训练与选择规则的合并效果。不能仅凭 C3 就排他地归因为训练参考。原协议里“区间包含 0 就弥合差距”需加勘误：它只表示未检测到差异，不证明等效。不要回写修改冻结记录。

# 4. R5-20：三个相互补充的诊断

**这些诊断解释现有完整模型，不根据 DEV 选择新的训练网格。**所有分析都写出图片数、查询数、支持条件、缺失原因、预定义分层与种子。细节及公式见 `docs/04`。

## A. 危险错误候选的参考质量与评分梯度

对每条有合法候选的查询，分析最高分错误框和前五个错误框：它们占多少 $Q$ 质量、多少错误框评分梯度、残差和饱和状态如何。VCS/JS 用实际 $p,q,f$；softmax 用实际集合概率。既报告各模型自己的高分错误框，也报告同一固定参考模型给出的错误框集合，避免把不同候选集合当成同一干预。

输出 $\partial L/\partial f$ 和 $a\,\partial L/\partial f$；后者才是当前仿射 cosine 评分上的导数。不同损失的绝对尺度不直接作优劣排名，重点看每条查询中梯度分配比例和方向。不得将这些结果称作 encoder 参数梯度或因果机制。

检测分数参考是 query-independent；它未必能区分两个同样可信的人中谁符合文字。是否真正增加关键干扰项的权重，必须实测。[S1 的假说；本轮 H1]

## B. 合法框数与正例概率要求

按合法框数 $k=1,2$–$3,\ge4$ 分层，并报告总候选数、覆盖率、目标类别和框质量分布。不能只比较三个组成不同的子群就作因果归因。辅助比较使用相同总候选数段和类别支持；支持不足记 NA。

增加合法集合概率、合法集合内部的概率不均匀程度、IoU 0.5／0.75 和错误类型。所有结果至少分开 VCS、JS、集合 softmax；R5-30 完成后用同一代码加入分布式 softmax。

假说 H2：当前分布目标还要求在多个合法框之间恢复规定概率，而集合目标只关心命中合法集合。该差别可能影响学习，但不预设它一定解释当前差距。

## C. 同一批查询的嵌套候选阶梯

固定一批至少有 31 个错误框且至少一个合法框的查询。正确目标取 IoU 最高的合法框；按检测分数、proposal ID 处理平局。对每条查询，用与模型无关的固定 hash 随机排列错误框，重复 32 次，取前 1、3、7、15、31 个及全部错误框。

每个模型、每个训练 seed 使用完全相同的查询和候选顺序。先对重复平均，再按图片平均；不要把随机重复当作新增独立查询。全部候选同一查询重复会给同一成绩，也不能当作 32 个样本。

这属于 oracle-assisted 分析，不能用于候选预选或官方部署成绩。不能把少于 31 个错误框的查询偷偷混进较大阶梯。

# 5. R5-30：新增 6 次完整训练，而不是扩大模型搜索

## 5.1 为什么新增分布式 softmax

当前 VCS/JS 的正分布在所有合法框上均匀。集合 softmax 为：

$$L_{\rm set}=-\log\sum_{r\in\mathcal A_w}\pi_\theta(r\mid w).$$

新增的分布式 softmax 使用同样的正目标：

$$L_{\rm dist}=-\frac1k\sum_{r\in\mathcal A_w}\log\pi_\theta(r\mid w).$$

二者满足直接恒等式 D2：

$$L_{\rm dist}=L_{\rm set}+\log k+
\operatorname{KL}(U_{\mathcal A_w}\|\pi_\theta(\cdot\mid\mathcal A_w,w)).$$

$\log k$ 对模型是常数；真正新增的梯度来自合法框内部分布约束。$k=1$ 时两种损失及梯度应一致。这个恒等式是本轮实现与实验的依据，不宣称为新的散度理论。

## 5.2 锁定比较条件

| 项目 | 规定 |
|---|---|
| 数据集 | RefCOCOg、RefCOCO+；沿用 R4-VL1 FIT/CAL/DEV |
| 模型 | 原始 SigLIP 2 B/16 权重开始，双塔完整更新；不从已胜出的 checkpoint 起步 |
| 新目标 | `distribution_softmax`；分母包含所有真实检测候选 |
| 参考对照 | 复用 R4-VL1 的 uniform VCS、JS、集合 softmax |
| 训练预算 | 同 R4-VL1 option A：10 epochs、AdamW 1e-5、wd 0.05、有效 32 图、warm-up 200、同余弦日程 |
| 配对／权重 | 正目标均匀合法框；每图合法查询均匀、再图片均匀；无合法查询按旧规则处理 |
| 评分 | 与现有集合分支相同 $u=2f$；相同增益初始化与优化组 |
| 选择 | 每 epoch CAL 全候选图片宏平均 Acc@0.5；并列取最早 epoch |
| seed | 0、1、2 全部完成，不依 seed 0 增删 |
| 数量 | **2×3=6 次新增完整微调**；不另开大主干 |

当前配置是共享 recipe 比较，不称为“每种目标分别充分调优”。不偷偷为新目标挑更好的学习率。[S3]

## 5.3 实现最容易出错的地方

旧 `conditional_softmax` 用正质量判断有效区域，可能把从未成为任何正例的检测框排除出分母。新分支必须使用**显式 real-region mask**，或在本协议全支持下使用 q 支持。不能仅替换函数名。[S4]

空／填充查询损失为零、梯度为零，不出现 $0\cdot(-\infty)$。没有任何合法查询的训练图片显式排除并计数；评价没有候选或没有命中目标的查询仍算错误。精确 chunk 累积先按原批次的图片总数归一，不能平均“chunk 的平均值”。

代码接入先做单元、梯度、padding 和 chunk 等价测试，再做少量图片的完整双塔 smoke。训练预算按实际 smoke 和缓存情况确认，本文不虚构运行时长；6 次不是自动提交命令。

# 6. 怎样读结果，怎样决定下一步

| 结果 | 允许的认识与动作 |
|---|---|
| detector-score ν 的优势不超过校准后的旧模型 | 不能排他归因于训练参考；保留结果，不扫更多检测分数指数 |
| VCS/JS 都因 ν 改善 | 参考分布设计有效；不写成 VCS 独有 |
| 分布式 softmax 低于集合 softmax，且接近 VCS/JS | 支持“正例分布要求是部分因素”；不是全部原因的证明 |
| 分布式 softmax 仍明显领先 VCS/JS | 正例集合解释不足，关注二元配对风险与多候选竞争；不再重跑同一分层 |
| k=1 条件差距仍大 | 多合法框约束不是唯一解释；看危险负例和函数类 |
| 冻结诊断发现危险候选被均匀／检测分数参考显著低权重覆盖 | 可以起草冻结语义教师的 query-dependent ν，但先审批新目标与预算 |
| 没有稳定作用，或改动与任务增益脱节 | 保留 VL 为已测应用，停止同质扩展；不以更多任务替代创新定位 |

条件参考方案见 `docs/05`。本轮不自动训练该方案、不引入大模型、生成 caption 或新数据集。下一项实验必须对应本轮得到的特定证据，而不是“再试一次看看”。
