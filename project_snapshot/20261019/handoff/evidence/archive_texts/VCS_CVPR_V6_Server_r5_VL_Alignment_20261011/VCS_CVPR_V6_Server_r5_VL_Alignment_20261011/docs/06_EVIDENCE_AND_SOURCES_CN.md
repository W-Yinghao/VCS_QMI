## 3. 进入本包的事实

### S1：proposal-aware结果（不是新跑的）

SigLIP2 B/16，原始预训练权重开始，双塔完整更新，10 epochs，三个seed。DEV all-proposal image-macro Acc@0.5：

| 数据集 | VCS | JS | set-softmax |
|---|---:|---:|---:|
| RefCOCOg | 71.73±0.21 | 71.36±0.27 | 73.58±0.36 |
| RefCOCO+ | 73.03±0.34 | 72.86±0.16 | 76.25±0.45 |

相对原given-box训练的大幅共同提升已经完成；它不属于VCS独有改进。VCS−set的配对seed区间为−1.85[−2.41,−1.29]和−3.22[−5.08,−1.37]。S1描述的“uniform参考对困难负例关注不足”是解释假说，而不是已证明因果机制。

### S8：求解检查

CAL-selected posterior MSE，直接VCS／直接JS／JS→J／JS→JS-reset：

- N4096：0.0503／0.0421／0.0425／0.0422。
- N16384：0.0215／0.0188／0.0204／0.0192。

更多数据缩小直接差距，未反转。此条件下没有证据表明JS起点后切换J能改善后验。本包不把结果推广成logistic普遍最优，也不追加无界求解搜索。

### S9：统计检查

实例验证支持按基础观测／图片处理依赖；n≥128多数已测条件的jackknife接近名义覆盖。有界区间保守；K=16在n512时节约评分计算。源报告明确说“标准实例验证，不是新方法”，本包保持该定位。
