r1 已经包含外部测量器比较、同图预测响应、真实压缩和规模化 SSL；这些内容不作废。但它将最终 VCS encoder 主要列为可选增加的对象，§5.3 的任务输出仍侧重一个外部模型的审计。

修订V6现在明确两步：**先检查测量程序，再使用同一程序理解最终SSL模型。** Table3保持“同一个SimCLR上的不同estimator”；新增Table4则是“同一个VCS测量流程下的最终VCS与SimCLR”。因此只换PDF不够，任务轴、模型清单、样本对齐和输出表也要同步。
