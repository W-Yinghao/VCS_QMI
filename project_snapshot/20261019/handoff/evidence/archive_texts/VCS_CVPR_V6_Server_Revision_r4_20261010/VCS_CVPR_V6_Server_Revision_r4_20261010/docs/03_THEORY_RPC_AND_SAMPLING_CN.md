# 数学规范：哪些是基础，哪些需要继续研究

本文件的推导用于实施校验，不自动构成新的论文定理。来源 [O/A/R/L] 与本轮推导 [D] 分开。原始 S/J 不变。

## 1. 符号与目标锁定 [O]

对任意两概率分布 P、Q，M=(P+Q)/2，η=(p−q)/(p+q)，定义

$$S=E_M\eta^2,\quad a_+(t)=t-t^2/2,\quad a_-(t)=-t-t^2/2,$$
$$J(T)=E_P a_+(T)+E_Q a_-(T),\qquad S-J(T)=E_M(T-\eta)^2.$$

T∈[−1,1]，但单次或总体 J(T) 可以为负，范围为 [−3,1]；S∈[0,1]。报告前不得把负 J 截成零来改善偏差；只有明确的下界展示使用 max(0,LCB)。CS 变换为 2log((1+S)/(1−S))，只在合法 S 范围讨论。经验 J 超界/负值单独记账，不偷偷剪裁后当原估值。

## 2. 与 RPC 的身份 [L1；D 的完成平方]

$$F_{\alpha,\beta,\gamma}(T)=E_PT-\alpha E_QT-\tfrac\beta2E_PT^2-\tfrac\gamma2E_QT^2.$$

对 β,γ>0，$T^*=(p-\alpha q)/(\beta p+\gamma q)$，并有

$$F(T^*)-F(T)=\tfrac12\int(\beta p+\gamma q)(T-T^*)^2d\mu.$$

α=β=γ=1 时，F=J、T*=η。同一输出张量上的损失、梯度应完全一致。不同 RPC 参数/原生训练配方可以作为方法比较，但不再是同一 S 的完全匹配对照。

RuLSIF 的 α=1/2 相对比值为 1+η；不能将混合分母与最小二乘本身标成新发现。[L2] 一般 incomplete U-statistic 已研究以较少 tuples 保持学习速率，故“稀疏 pair + 理论”本身也不是排他性创新。[L4]

## 3. Logistic 与平方拟合的比较 [O，A4 的限定]

平衡机制后验 D*=p/(p+q)，T=2D−1。用 f 参数化时，T=tanh f，D=σ(2f)。

单 pair 的损失取 $\ell_V=\tfrac12(T-c)^2$ 和 $\ell_L=\log(1+e^{-2cf})$，则

$$\partial_f\ell_V=(T-c)(1-T^2),\quad \partial_f\ell_L=T-c.$$

这只说明 logit 梯度权重，不能自动称为整个估计器的 robust influence function；参数 Jacobian、Hessian、输入杠杆和错误饱和都需要另外控制。JS 更好的有限样本后验 MSE 不证明总体优越，也不唯一证明 VCS 优化慢。增加 N 与延长训练分别试验，不能预言必然反转。[L3]

共享 J 的 gap、值域、独立评价界对由 JS、核或其他方法产生的固定 T 同样成立。“优化即报告”是一种求解对齐，不是标准平方回归性质的首次发现。

## 4. 两种采样制度不能混用 [D]

### 4.1 每图内部精确 P_G/Q_G

对相互独立的基础图片 G₁…G_N，图内区域和文本允许任意依赖。先精确计算 J_G，再按图平均：

$$\widehat J=N^{-1}\sum_iJ_{G_i}(T).$$

假设 encoder/critic 以及预处理已经在评价之外固定，则 J_G∈[−3,1]，

$$P(|\widehat J-E_GJ_G|\ge\epsilon)\le2\exp(-N\epsilon^2/8).$$

两侧半径 $r=\sqrt{8\log(2/\delta)/N}$。它约束的是固定 T 的平均值；S 的有效单侧下界可取 max(0,Ĵ−r)。若图片来自固定无放回池，需说明有限总体目标，不把抽样解释成新图片总体。

### 4.2 同一批 (X_i,Y_i) 构造跨观测负对

设 W_i=(X_i,Y_i) iid；a(W_i)=a₊(T(X_i,Y_i))；b(W_i,W_j)=a₋(T(X_i,Y_j))。定义对称二阶核

$$k_T(w,w')=\tfrac12[a(w)+a(w')]+\tfrac12[b(w,w')+b(w',w)].$$

那么

$$\widehat J=\frac1n\sum_i a(W_i)+\frac1{n(n-1)}\sum_{i\ne j}b(W_i,W_j)
=\binom n2^{-1}\sum_{i<j}k_T(W_i,W_j).$$

设 μ=E k_T(W,W')=J(T)，

$$h_1(w)=E[k_T(w,W')]-\mu,$$
$$h_2(w,w')=k_T(w,w')-\mu-h_1(w)-h_1(w').$$

则固定 T 的精确方差为

$$\operatorname{Var}(\widehat J)=\frac4nE h_1^2+\frac{2}{n(n-1)}E h_2^2.$$

这是标准 Hoeffding 分解的本问题实例。它包括正项和负项共享基础样本的协方差；不能只给负项估 SE 再忽略与正项的相关。

**保守有限样本备选：** k∈[−3,1]，更改一个 W_i 最多使 U-statistic 改变 8/n。bounded differences 给

$$P(|\widehat J-J(T)|\ge\epsilon)\le2\exp(-n\epsilon^2/32).$$

半径 $\sqrt{32\log(2/\delta)/n}$ 可用作实现的保守核对，不以其过宽作为算法有效证据。另可对不重叠 W 对计算独立 k，得到独立块的界。进一步紧化或自适应区间需文献核对和证明，不在本包预先宣布。

## 5. SE、重采样和退化情形 [D]

### 5.1 Delete-one jackknife

对 n≥3，从核矩阵删去第 i 个基础观测得到 U_(−i)。

$$\widehat V_{JK}=\frac{n-1}{n}\sum_i(U_{(-i)}-\overline U_{(-)})^2.$$

这是固定非退化 U-statistic 的近似方差方法，不是所有 S、所有学习器下的无偏区间保证。独立性、T≈0 或最优 critic 导致一阶项退化时，普通正态覆盖需单独验证；保守界/精确有限模型核对不能省掉。

### 5.2 重采样单位

图内完整平均实验：重采样整张图片，连同区域/文本一起。跨图片乘积实验：重采样基础 W 后重新形成跨 pair，或使用已验证的等价加权/乘子实现。**不能只 resample 已存在 pair 的平面列表。**

若非参数 bootstrap 允许同一原图片多次抽到，不同 bootstrap 位置可能对应同一原图；必须明确自配对规则及其有限样本影响。没有保存重复位置所需的核对角项，就不要声称实现了完整非参数 U-bootstrap。参考代码本轮只提供 delete-one 与图内 cluster bootstrap。

### 5.3 拟合与评价

固定 critic 实验：重复 EVAL，比较 J(T) 的覆盖。重新拟合实验：重复 FIT/优化种子，记录其额外方差；不能把固定 critic 的 1/n 界说成训练全流程的方差界。

单次独立 FIT/CAL/EVAL 是首轮方案。若将来 K-fold：每折拟合不能读取该折任何评价标签/配对统计；跨折 fits 重叠，不默认分数 iid。固定外部 encoder、相同总体 S 时，可用每折 δ/K 的条件界和 union bound 得到保守折均下界；它不自动是高效估计。若各折 encoder 本身不同，连 S 都不同，必须另定义目标。

## 6. 稀疏 pair 的两类方差 [D；复用 P138]

给定基础观测 W 和固定 T，采样负 pair 得到 Ĵ_K。若条件无偏，则

$$\operatorname{Var}(\widehat J_K)=\operatorname{Var}(\widehat J_{all})+
E\{\operatorname{Var}(\widehat J_K\mid W,T)\}.$$

这里条件包含固定 T；若 T 从另一个训练集随机产生，应再对训练随机性分解。

把 n−1 个非零 cyclic shift 的均值记为 v_l，均匀无放回取 K 个 shift：

$$\operatorname{Var}(K^{-1}\sum_{l\in S}v_l\mid W,T)
=(1-K/(n-1))\,s_v^2/K,$$

其中 s_v² 为 n−1 个 v 的样本方差（分母 n−2）。复用已完成 P138 的设计与结果，不将其重新注册成新发现。统计有效样本量、pair 数、网络前向数与墙钟成本分别报告。

## 7. 污染关系与其适用条件 [A4 + D]

对 $P_\rho=(1-\rho)P+\rho Q$ 且 Q 固定：

$$\eta_\rho=\frac{(1-\rho)\eta}{1-\rho\eta},\quad
\eta=\frac{\eta_\rho}{1-\rho+\rho\eta_\rho}.$$

若 Q 是原联合的乘积边缘，独立对污染保持边缘，因此可使用该恒等式。其他离群/重尾污染可能同时改变 Q，不能照搬。

逆映射的最大导数为 $(1+\rho)^2/(1-\rho)$；测度变换为 $dM/dM_\rho=1/(1-\rho\eta)$。反解后在污染评价池直接无权平方平均，不是清洁 S 的正确读数。

进一步有

$$(1-\rho)J_{P,Q}(T)=E_{P_\rho}T-E_QT-\tfrac12E_{P_\rho}T^2-\tfrac{1-2\rho}{2}E_QT^2.$$

ρ<1/2 时是 RPC(1,1,1−2ρ)；ρ=1/2 为边界，ρ>1/2 不属于原正参数族。该代数关系不因有限经验非凸/有噪而自动给出好优化器，不作为本轮默认训练新法。

## 8. 标签信道与推前分布 [D：对附录 4 的进一步限定]

标签可从观测恢复，是标签信道依赖在观测上保持的充分条件；“当且仅当所有标签都可恢复”过强。准确的等号条件是相应最优后验/密度比对观测可测。独立情况或对后验无影响的标签合并也可等号成立。因此，本轮不在自然 CLIP 特征上仅凭类别信道公式填写精确 S。

| 结果类型 | 可写内容 | 不足以单独声称什么 |
|---|---|---|
| RPC 恒等、标准完成平方 | 清楚定位原目标 | 新泛函 |
| 正确 U-statistic 实现/保守界 | 纠正相关 pair 的误差计算 | 新统计原理 |
| 在明确条件下新的有效区间/配对设计及成本收益 | 经过证明与验证的具体估计贡献 | 任意依赖、任意网络均有效 |

第一轮的目标是确定哪一项真正需要/允许继续研究，不是先认定所有建议都能升级为新贡献。
