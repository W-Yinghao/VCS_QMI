# 理论对象、应用连接与创新边界

本文件不是合作者原计划的替换稿。标签 S=来源已有，D=本轮直接推导，P=新研究方案。首次性没有被完整证明的内容只称候选；旧理论保持原样。

## 1. 继承内容 [S]

对两个一般概率分布 P,Q，M=(P+Q)/2，eta=(p-q)/(p+q)，S=E_M eta²。有限表也采用同一积分约定。J(T)=E_P[T-T²/2]+E_Q[-T-T²/2]，S-J=E_M(T-eta)²。J(T)<=S 是总体性质；经验 Jhat 可能高于 S 或小于零，不裁剪原始统计量掩盖波动。

D_CS^(M)=2 log((1+S)/(1-S))。S 接近1时对数敏感；不存在“换神经估计器而完全保持经典 Lebesgue/KDE-CS 对象不变”的自动等价。

平衡 RPC 的 F_111 与 J 相同；一般 RPC 完成平方就得到加权 L2 gap。RuLSIF 的半混合相对比为1+eta。Logistic 可以恢复相同平衡后验，并读取同一个 J。独立评价界、U-statistics、模型平均和条件期望正交性都需承认先行工作。[O1; R1]

## 2. 确定性观测与“依赖高”陷阱 [D]

若 A=g(B)，且 A 的分布无原子，则联合分布集中在函数图像上，而 P_B P_A 给函数图像概率0。因此两分布互相奇异，S=1。g 可以丢掉大量任务信息。离散 A 时也常出现由支持/类别频率主导的饱和值。

结论：不能以“教师与学生整体依赖最大”替代任务信息保留；也不能假设对任意两幅固定图像，任意可逆空间变换都会给出有区分力的总体依赖。坐标、实例ID、唯一纹理可产生容易的配对证据。

REG 使用跨独立场景的局部观测、受控视野和明确参考；无自然分布 oracle 时不将有限标注表的 S 当自然真值。原始混合参考不变，不代表所有 P/Q 选择都适合几何任务。

## 3. 任务证据增量 [D；标准投影结构的应用]

在同一联合概率空间上 C∈{-1,1}，P(C=1)=P(C=-1)=1/2；U 是 UV 的投影。对每种观测 W，P_W=Law(W|C=1)，Q_W=Law(W|C=-1)，M_W=Law(W)。于是 eta_W=E[C|W]。

Δ=S_UV-S_U=E(eta_UV-eta_U)²=R_U*-R_UV*≥0。

局部收益 d(u)=E[(eta_UV-eta_U)²|U=u]。在平方损失、可获取一次 V、Bayes predictors、获取成本 c(u) 只依赖已观察信息的条件下，最优即时决策为 d(u)>c(u)。这是单步风险决策，不是多步最优性的证明。

### 非平衡与多类

C 非平衡时 eta=(p-q)/(p+q) 仍对应人为的平衡实验，而自然数据上的 E[C|W] 包含真实先验。必须选一个目标并全程一致。自然先验风险不能直接由平衡S差冒充。

多类官方任务使用 q_U=P(Y|U)、q_UV=P(Y|UV) 时，多类 Brier Bayes风险差为 E||q_UV-q_U||²。它是标准扩展，不等于每类分别重平衡后 CS 的简单和。策略实际以官方多类风险/accuracy/cost评价； binary S connection 单独报告。

## 4. 有限模型的收益不能由平方分歧替代 [D]

对固定预测器 a(U), b(U,V)，令 z=(b-a)²，h=(C-a)²-(C-b)²，则

h = z + 2(b-a)(C-b)。

对每个 u 取条件期望，g_model(u)=E[h|U=u] 才是使用这对有限模型的实际期望平方风险改善；它可以为负。只有 b 足够接近条件均值等条件下，残差项才消失。

- **Oracle**：d(u)，受控数据可计算。
- **Square-disagreement target**：z，用模型后验差估计信息增量，有逼近偏差。
- **Realized utility target**：h，在未训练这些预测器的样本上计算，期望是实际模型收益；单样本负值不删除。
- **Residual diagnostic**：h-z。它帮助发现“模型不一致冒充新增信息”。

h 恒等式本身不是新偏差修正算法，也不保证最小方差。直接预测 h 是必须的强基线。如果它总是更实用，不能将标准风险预测重新叫作独有 CS 创新。

## 5. 构造的验证条件 [P]

(1) 冗余：V复制U，Bayes增量0。(2) 无关：C依赖U，V独立，增量0。(3) XOR：U,V均匀独立二元，C=UV；S_U=0，S_UV=1。(4) 可见上下文：U=(K,X)，K=0时C=X，K=1时C=XV；d(U)=K。

再加入不完美预测器和错设，证明z可正而真实增量为0、实际收益为负。所有构造都执行，不按方法强弱选择。

## 6. 配准用到的量 [P]

训练后固定T，评估变换phi得到 F_T(phi)=J(T;P_phi,Q_phi)。其导数来自两个分布项的变换依赖；不能默认Q是常数。

F_T(phi) 的较高值是固定见证函数对当前关系的响应，不等于已经求出 sup_T J。只在critic对每个phi达到总体最优、适当可微与最优值条件成立时才能用包络推导；首轮不声称这些条件。

若训练与测试使用同一图像拟合critic再优化warp，过拟合风险与成本必须分别披露；本轮主方案在独立训练场景拟合关系模型，测试冻结，禁止以测试坐标/变换真值重训。
