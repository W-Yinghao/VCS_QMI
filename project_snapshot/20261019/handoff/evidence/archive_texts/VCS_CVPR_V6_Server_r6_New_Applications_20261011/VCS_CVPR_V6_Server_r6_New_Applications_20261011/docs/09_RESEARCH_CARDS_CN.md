# 五张科学问题卡：初稿，服务器需结合实际实现补全

这五张卡不是五条默认训练线。REG/GAIN优先完成受控验证；只选择一条自然数据主pilot。所有“希望改进”的内容都是可查否的假说，不是预设结果。

## REG｜局部统计证据能否引导跨模态几何恢复？

**对象：**跨独立场景的局部观测P_phi，对同场景独立位置的Q_phi；固定训练好的critic，用J作为几何能量。
**用途：**未知平移/旋转下恢复对应关系；终点是几何误差，不是配对分类分数。
**新增候选：**明确局部观测、共享支持与独立训练下，估计误差/曲线分辨如何影响变换优化；必须超出已有CoMIR和MI配准的替换损失实验。
**预测：**如果学习型局部关系有效，应在未见场景上比仅依赖亮度相似的基线更能恢复变换；VCS是否优于matched Logistic不预设。
**反例：**重复纹理、完全无相关模态、坐标/边界泄露、任意可逆变换保留的实例关系。
**外部评价：**变换误差、TRE、初始化范围曲线、总推理成本。首选Zurich，后备BF/SHG或EPFL。

## GAIN｜获取前能否预测额外模态的实际任务价值？

**对象：**同一任务类别条件分布的S增量；多类真实任务用明确Brier扩展。有限模型实际收益与平方后验差并列。
**用途：**只看U决定是否执行V分支；实际错误和计算预算共同评价。
**新增候选：**将二次证据增量估计与有限模型残差区别落实为可部署的获取策略；必须与直接风险收益回归、entropy、EDDI/AdaMML比较。
**预测：**在获取前可見质量决定新增收益的构造上，策略应区分高低收益；在恒定收益XOR中不应期望优于随机同预算。
**反例：**V冗余、V无关、full predictor更差、策略偷看full输出、节省FLOPs却不节省时延。
**外部评价：**实际风险/accuracy—成本，收益预测校准；AV-MNIST小型完整流程，CREMA-D正式扩展备选。

## NUISANCE｜减少干扰关系时，能否避免把critic失效当成功？

**对象：**P_Y P_ZN|Y 对 P_Y P_Z|Y P_N|Y；任务损失与干扰约束分开。
**用途：**偏差变化后仍能预测任务。新内容不能只是在DANN/ReBias中换一个判别损失。
**预测：**若真的降低干扰可利用性，独立强probe和新的偏差组合下的行为应一致改善；低训练J不构成证据。
**触发：**已有明确可观察干扰和OOD任务，且REG/GAIN未被选为主线。

## COMPRESS｜在真实预算下，保留多少任务证据足够？

**对象：**完整B与压缩A=g(B)在同一任务实验中的风险差。排除确定性教师学生整体QMI饱和。
**用途：**token/通道/码率分配；标准蒸馏和压缩算法是主对照。
**预测：**若测量有用，应改善预算分配而不仅提高训练J；与直接风险预测同预算比较。
**触发：**现有模型确有计算/存储瓶颈，且证据增量估计已得到独立验证。

## AMORTIZE｜大量关系估计是否可通过可复用critic减少重拟合？

**对象：**由P/Q小样本条件化的critic，再在独立样本上读J。不是将InfoNet式摊销重新命名。
**用途：**多个场景/模态组合的快速依赖测量。
**预测：**在已定义分布族中以更低总成本达到相同误差；分布外要可发现失败，不能只报告均值。
**触发：**实际应用已证明逐问题拟合是主要成本；首轮不训练大型生成/基础模型。
