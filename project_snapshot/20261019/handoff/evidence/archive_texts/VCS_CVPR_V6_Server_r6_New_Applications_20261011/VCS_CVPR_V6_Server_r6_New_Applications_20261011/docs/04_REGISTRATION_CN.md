# REG：跨模态图像配准的具体设计

**类型：P，新应用研究方案。** 不是已运行结果；不改变原始S/J。本轮首选2D平移/刚性，不直接进入3D医学形变网络或点云任务。

## 1. 科学问题与新增内容

研究局部跨模态统计关系能否形成可用的几何优化目标。相较于“配对判别正确率更高”，真正要解释的是正确变换附近的分辨、远处初值的收敛范围、错模态/噪声下的几何失败，以及达到相同精度的样本和计算成本。

CoMIR已用对比学习生成跨模态稠密表示后进行配准；已有MINE图像配准、传统MI/NMI、CS点集分布配准。因此“第一次把CS/MI用于配准”不是候选贡献。[L1–L3; L9]

本轮可争取的新增能力：在相同局部观测与独立场景训练下，更可靠地将可学习依赖证据转成几何恢复，并说明critic误差与配准目标曲线的关系。该能力是否存在由实验决定。

## 2. 数据选择

首选公开入口是 Zurich Summer 的RGB/NIR四波段图像，作为轻量、可控的2D实验。它只有20个原始tile，patch不是独立场景；不得制造“大样本”统计。第二选择是BF–SHG成像；EPFL RGB-NIR作为非医学替代。详见数据表，图像ID/组织芯片/邻近场景必须成组分割。

Known-perturbation任务：在已有对齐或近似对齐的成像对上生成已知刚性错位，再估计逆变换。这只给人工扰动的真值，**不证明原始两幅图像本身完美配准**。自然残余形变/标志点任务另列。

不得根据VCS首次表现选择哪个数据集；按数据/许可、可核验对齐、独立单位和基线可复现性选择，写入route decision。

## 3. P/Q 与观测定义

对独立场景G，固定支持区域Omega，从Omega均匀抽空间位置x。U_G(x)与V_G(phi(x))是两模态局部观测。首轮不输入绝对位置、场景ID、变换参数或边界mask。

- P_phi：先等权抽G，再抽x，返回同一位置假设下的局部对(U_G(x),V_G(phi(x)))。
- Q_phi：先等权抽同一个G，再独立抽x,x'，返回(U_G(x),V_G(phi(x')))；两分布采用相同支持和同样插值链。

Q_phi是**同场景独立位置参考的混合**，一般不等于所有图像混合后的global product。因此称within-scene-reference CS discrepancy，不偷换成原global QMI。若另做跨场景Q，必须单列target_id，并控制critic仅凭场景身份判断配对。

主critic只看到局部观测，不看到G的ID。P/Q在经过这个观测映射后才是统计对象；不能给它分配原始索引级oracle。

训练对齐关系使用原训练对的phi=id。测试T固定，用F_T(phi)=J(T;P_phi,Q_phi)作为匹配能量。它不是逐phi重新最大化的真实S_phi；若需研究完全变分的逐变换估值，仅作为独立、计时的诊断，首轮不启用。

## 4. 先做正确性验证，再做完整小型学习

### REG-C0：受控局部场

包内提供二元局部传感器关系P(u,v)=(1+rho*u*v)/4。Q=1/4，S=rho²/(4-rho²)。跨位置独立时S=0。在随机独立场上施加整数平移，检查warp符号、P/Q、读数和正确位移恢复。

这是有精确真值的离散实现检查，没有连续几何梯度，不用于宣称自然配准优势。再实现平滑随机场与已知平移的可微检查，用有限差分核对dJ/dphi；没有解析自然S时只称方向/实现验证。

### REG-P1：第一个自然数据完整pilot

优先统一局部模块：两个小型、同深度卷积编码器（无坐标通道、无全局图像身份输入），输出稠密局部描述子，外接相同大小的联合MLP critic；T=tanh f。固定相同感受野、归一化规则、训练图像和增强。

建议首版实现配置（不是文献最佳设置）：输入patch 128×128，局部描述16或32维；联合MLP两层64单元；同场景采样256对位置；AdamW；最多100 epochs，CAL选择。实际在低维原始patch上同时做数值检查，避免只验证复杂网络。

VCS与Logistic在同样P/Q上完整训练编码器和critic。InfoNCE采用同一局部观测/配对但保留其自己的候选归一化，并标明不同目标。另有固定原始描述子的同目标核和MI/NMI数值配准基线。

这不是“训练一个冻结CLIP probe”；主要产物为完整训练后的图像关系模型及真正的配准输出。若直接原始patch critic在任务上已可用，可作为独立估计路线，但必须报告其与学习稠密表示的区别。

## 5. 几何优化与防止伪对齐

1. 先平移，再增加旋转；一次pilot只冻结一种主要transform family。建议范围：平移最多视野短边10%，旋转最多15度；这些是任务规格，不是理论预测。CAL小样本检查可见性后统一冻结。
2. 固定中央支持Omega，使其在全部允许变换下均落在图像内。不要让高分来自缩小重叠区、看到零padding或把难区域丢掉。
3. 每张图采用相同的位置随机数、固定初始化和预算；各方法共用多尺度优化器。Q中的V位置也经过phi；不能漏掉Q的梯度。
4. 对信号做双边相同重采样链；identity也经历同类插值。报告插值、像素中心、align_corners约定、变换方向和compose顺序。
5. 窗口内重复纹理、几何对称性和恒定强度是反例条件，不当作数据清洗噪声删除。
6. 测试critic不重训、不看变换真值。任何在线拟合版本必须使用独立空间块/场景和独立预算表，不能混入主结果。

## 7. 评价

主要：已知扰动的变换误差；可用标志点TRE（像素/物理单位分开）；同初值下的成功率曲线；中位数与失败尾部；注册耗时和模型训练成本。

次要：在固定路径上的F_T(phi)曲线、正确方向的局部导数、初始化范围—误差曲线、同样本量下估值波动。J更高不是主要胜负标准。若用相关系数/SSIM判断恢复，必须有几何真值作主指标，否则跨模态亮度差可能误导。

报告以独立场景聚合；同图数百个patch和数十次扰动提供条件重复，不变成数千独立场景。小图像数采用全部预定拆分/重复，不能把最好一折作为主结果。

## 8. 失败时改什么

- 全方法失败：先核对几何、支持、初始重叠和原配准质量，再讨论新估计器。
- critic可分辨，但曲线不导向正确变换：检查场景捷径、位置泄露、重复纹理；不要靠增加classifier accuracy解释。
- 神经VCS/JS都好于核但相互接近：承认学习型函数类贡献；进一步看固定计算预算下几何效用，不制造VCS独有性。
- CoMIR更强：检查其等变结构/监督/局部信息是否共享；不通过削弱基线恢复优势。
- 分数到处饱和：在FIT/CAL规定观测尺度/感受野再检验；这是改变观测对象，不叫无条件更精确。只允许一个有依据修正，不无限扫噪声。
- 数据源难获取或独立单位太少：切到已列下一可用数据入口；保留原失败原因，不依据测试性能切换。

REG若没有清楚的几何价值，可以结束pilot而不否定VCS总体理论；再考虑GAIN，不回到候选框调参惯性。
