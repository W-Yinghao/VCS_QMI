# 1. 本轮要解决的问题

我们已有完整 SSL、合成依赖估计、视觉测量和多轮区域—语言定位。现在需要停止把“一定要在 RefCOCO 排序里追上 softmax”当作唯一研究目标。新应用必须让 estimator 的读数、后验或误差结构参与一个实际决策，而不只是换一个训练损失。

**优先展开两条不同的问题：跨模态图像配准（REG）；任务相关证据增益与按需模态计算（GAIN）。** 它们不是已经确定的两项新贡献。先完成对象核对、受控验证和数据/基线检查，再选择一条进行自然数据完整 pilot。

| 线 | 实际问题 | 最终评价 |
|---|---|---|
| REG | 不同成像方式之间，局部统计关系能否引导正确几何对齐？ | 变换/标志点误差、配准成功率、收敛范围与成本 |
| GAIN | 已看到一部分输入，再计算一个模态是否值得？ | 实际风险—成本曲线、预算下准确率、获取前收益预测 |
| 三条备选 | 去干扰、任务相关压缩、摊销估计 | 先明确对象和新增能力，不全部开跑 |

本包保留原始 $S,J$，不改变合作者理论；REG/GAIN 的任务选择、模型和实验是新增方案。一般的配准、主动获取、条件期望投影和密度比估计已有先行工作，换应用不自动解决 RPC 新颖性问题。[O1; R1; L1–L8]

# 3. 理论保留什么，新应用改变什么

对一般分布 $P,Q$，设 $M=(P+Q)/2$：

$$
\eta=(p-q)/(p+q),\qquad S=E_M\eta^2,
$$
$$
J(T)=E_P(T-T^2/2)+E_Q(-T-T^2/2),\qquad
S-J(T)=E_M(T-\eta)^2.
$$

以上来自合作者原计划；平衡 RPC 的泛函与 $J$ 相同。混合参考 CS 为 $2\log[(1+S)/(1-S)]$，训练与测量可以保留有界 $S$，不必显式使用对数变换。[O1; R1]

本轮允许改变的是：**P/Q 表示的关系、critic 的观测、测量所服务的实际决策**。固定 $\tanh(2s-1)$ 不是一般理论的要求。

| 对象层次 | 可用解释 | 不允许混称 |
|---|---|---|
| joint vs global product | 原定义的 QMI | 同图随机参考未必是 global product |
| 一般两分布或任务类别条件分布 | CS discrepancy、二元平方风险 | 不自动叫 Shannon MI/条件 MI |
| 多类 Brier 风险与证据增量 | 明确标注的标准扩展 | 不是未经证明的同一个二元 S |
| 有限 predictor 差异 | 实际模型收益、拟合敏感性 | 不是已知 Bayes 信息增量 |

独立 Logistic 后验也可转换成 $T$ 并使用同一个 $J$；gap 和共同读数不是平方训练独占。新增贡献必须是一个具体问题的解法与证据，而不是再次认领二次损失、标准浓缩界或主动获取。[O1; O2; R1]

# 4. 第一条优先线：REG 配准

**研究问题。** 学习到的局部跨模态关系，能否形成一个对正确空间变换有分辨力、且能实际优化的配准目标？“critic 配对精度高”不替代几何恢复。

首先从 2D 平移/刚性开始，不立即开 3D 形变网络。可用入口为 Zurich RGB–NIR、CoMIR 的 BF–SHG、EPFL RGB–NIR；数据集之间的原始对齐和切分条件不同，需先核验。[D1–D3]

**最小闭环。** 独立训练图像上的局部配对 → 训练共享关系 critic → 冻结后在新图像上优化变换 → 用已知人工扰动及可用真实标志点评价。原始图像上的低维描述子先用于正确性检查；自然任务的主要证据采用完整训练与配准流程。

对所有候选变换使用固定空间支持与相同抽样规则；两侧独立位置的参考项也随变换正确计算。禁止用绝对坐标、图像 ID、变换编号或边界填充值泄露配对标签。多像素不当作多独立图像。

**首批对照。** 同类 VCS/Logistic critic；同目标核读数；传统 MI/NMI；CoMIR 或可复现的同类配准方法。相同几何优化器的损失对照，与原生完整系统对照分表。[L1–L3]

# 5. 第二条优先线：GAIN 证据增益

**研究问题。** 已有观测 $U$ 时，新增 $V$ 对同一任务降低多少预测风险？获取策略必须在尚未计算 $V$ 时作决定。

平衡二元任务 $C\in\{-1,1\}$，$\eta_U=E[C|U]$，$\eta_{UV}=E[C|U,V]$：

$$
\Delta=S_{UV}-S_U
=E(\eta_{UV}-\eta_U)^2=R_U^*-R_{UV}^*.
$$

这是同一任务实验上的条件期望推导，不是新 CMI/PID。对当前有限预测器 $a(U),b(U,V)$，还必须保留：

$$
(C-a)^2-(C-b)^2=(b-a)^2+2(b-a)(C-b).
$$

第二项不为零时，平方分歧不等于实际收益。**这是本轮必须验证的区别，而不是可以忽略的理论注脚。**[O1; O2; D-本包推导]

首轮受控任务包含冗余、无关、XOR 互补以及“可见上下文决定新增模态价值”四种情况。自然任务入口为 AV-MNIST；若进入正式视觉应用，再选择 CREMA-D 音视频或其他原始模态可访问的数据。[D4–D5]

部署策略只看 $U$。实际成本包含廉价分支、策略网络、数据解码、被选择的额外分支与融合；不先算完昂贵模态再声称节省。多类任务保留官方分类目标，使用多类 Brier 扩展并与概率交叉熵比较，不为套二元理论任意丢弃困难类别。

**必须有的对照：**永不获取、总是获取、随机获取、廉价分支不确定性、直接预测实际风险改善；同类平方与 Logistic 拟合。EDDI/AdaMML 和较新的主动获取方法是相关工作与完整系统对照，不是从未存在的新问题。[L4–L7]

# 7. 怎样选择一条自然数据路线

REG 优先看：是否有可靠独立图像与变换真值、强基线是否能复现、局部依赖在正确变换附近是否有可用分辨。GAIN 优先看：新增模态是否在完整系统中真的带来任务收益，以及这种收益是否能由获取前输入预测。

| 观察 | 解释与处理 |
|---|---|
| REG 在几何正确性检查中就依赖边界/图像 ID | 修支持、插值和采样；不是增加 critic 深度 |
| REG 的自然目标平坦或错误极值普遍 | 检查信息量/尺度/重复结构；传统强基线也失败则数据/任务可能不适合 |
| GAIN 全模态不优于廉价分支 | 不将多算一个模态当成“理论收益”；检查训练或改成更合适的真实任务 |
| GAIN 全模态有益，但获取前无法辨别谁受益 | 报告条件可预测性限制；随机/静态预算可能已合理 |
| 两条都只重现已有方法或无独立用途 | 保留结果，不将换应用伪装成新 estimator；返回作者确定理论增量 |

实用门槛可按任务误差和成本定义，但与理论预测分开。对来源文献的范围也要分开：传统 CS 点集配准并不等于本文的局部多模态依赖；主动获取已有 CMI/解释排序路线，不能声称首次。[L3–L7]
