# 实验不理想时怎样调整：诊断与有限替代路线

本文件列出预先考虑的替代方案，不是要求依次运行到VCS赢为止。所有门槛是本轮的开发规则建议；正式确认仍用独立验证、共同预算与配对区间。

## 1. 先判断失败发生在哪一层

| 层 | 典型征象 | 不应直接归因于什么 |
|---|---|---|
| 数据/协议 | 框无效、短语错绑、正确对象不在候选、评测图训练见过 | 不能归因于散度 |
| 表示 | 同一输入下多数小头都失败，context或统一更好编码器明显改善 | 不能仅靠加迭代修复不可读信息 |
| 优化/拟合 | TRAIN很好、CAL差；高饱和；不同初始化差很大 | 不代表总体目标不成立 |
| 估计/决策对齐 | J改善而Top-1变差；先验变化后排序反转 | 检查密度比与任务后验的区别 |
| 应用价值 | 所有公平神经方法接近，风险和成本均无改善 | 可能只是一个可用应用，不是独有优势 |

先交数据/实现检查，再以DEV定位科学问题。不得把所有负结果都称为bug；也不得因一组超参数差就否定整个估计对象。

## 2. 十二类情况及具体处理

### F01：数据取不到，或许可/存储不满足

**检查：** 图片和注释分别可用吗？COCO是否已有缓存？是否只是旧作者下载站不可达？

**动作：** 保留取得记录，优先RefCOCOg UMD（若已有COCO）或DCI（许可与必要SA图片已具备）。只迁移数据adapter，保持损失/评分/评价定义。

**退出条件：** 无可确认的合法来源就停该数据单元，不从未知网盘补全并宣称官方完整集。新的N按实际图像数给出，不复制样本。

### F02：原CLIP准确率已经接近天花板

**触发线索：** DEV全候选Top-1≥95%，或者错误主要来自未标注的合法表达。95%只作开发提醒。

**先查：** 候选是否误用了跨图随机负例？图片是否只有一个合理对象？已标注共指是否被漏掉？

**一次变更：** 在保留全主表的前提下，增加预定义的同图同粗类对象子集；再用RefCOCO+ / RefCOCOg或DCI。不得专挑VCS和JS分歧最大的样本成为新test。

**可主张：** 新数据中的细粒度匹配；不能把减少训练量只对CLIP不对VCS施加。

### F03：所有方法都很差

**实现检查：** 100张TRAIN可视化；CLIP图文对齐是否用错输出层；区域裁剪是否几乎空白；token是否截掉名词；答案索引是否错误。

**表示检查：** 固定全部方法，比较tight crop与crop+global context+box几何。关系短语如“在桌子后面的人”，仅人物crop可能确实不够。类别/属性标签不能作为候选特征偷偷加入。

**替代：** CLEVR-Ref+作诊断；若裁剪仍没有视觉信息，可统一换FLAIR/FG-CLIP特征或预定局部池化。更换权重后所有方法重建基线，增益归于输入与估计器交互，不全部归于VCS。

### F04：仿射标定提高J，Top-1完全不变

这是期望现象：a>0的affine–tanh保持cosine排序。不要继续扫100个a/kappa。

**动作：** 标定作为估计结果保留。需要新的任务排名时选F2联合评分器，或identity adapter＋几何头，两条分别分析。代码对排序一致性设测试。

### F05：训练J很高，独立J或任务结果很差

**检查：** CAL是否按图划分；同一entity的caption是否跨split；实际Q是否仍为图内乘积；同图多对是否造成样本量错算。绘制训练／CAL共同J和任务曲线，而不只记录最后值。

**一次变更：** 256宽MLP改128宽，或固定一个共享正则点；CAL早停。所有损失共同改动。保留zero critic仅作风险基线，不用它替换测试上的负J以美化主结果。

**下一步：** 只有样本曲线仍改善，才增加训练图片。不能靠更多epoch强行让验证读数上升。

### F06：VCS低于匹配JS，但核方法更差

**第一解释：** 当前收益主要属于学习型后验估计，未显示二次损失独有优越性。[O2]

**先查：** 正负权重、半logit转换、参数初始化和输出饱和；在相同函数类和有限网格下比较两种损失。

**最多一个混合拟合实验：** 用前1/4预算的logistic拟合初始化，后3/4预算最大化J；对照直接J、全程logistic、相同总预算的J延长。用共同CAL J选择。明确命名“logistic-initialized CS”，不是偷偷把好JS结果改名VCS。它改进的是求解路径，最终统计目标仍由J定义。

**停止条件：** 若风险、样本效率、成本和任务都相近，写成CS的有效用途；不自动搜索更多数据直到输赢反转。是否将其放正文由全文贡献决定。

### F07：J提高但区域选择下降

**检查：** 区域先验是否均匀；m是否变化；训练选择是否基于共同J而任务需要后验；是否将topic关系错误用来评价own-caption。

**动作：** 验证prior correction：按log p(r|G)+2f排序。先验只来自冻结的训练采样规则／候选设计，不从test真值估计。拆开estimator_selected和task_selected的结果。保持同一照片内的查询分布，避免训练均匀区域、评价极度不均匀短语而不披露。

**替代：** 如任务确实只需要条件分类，可保留明确的Q_task并称通用CS判别，而不是原条件QMI；这种变化必须连同基线重新立协议。

### F08：adapter把原CLIP的检索／匹配毁掉

**检查：** 初始化是否严格恒等、训练前后特征角度／范数漂移、最优checkpoint是否就在step0。P80的旧坏结果保留。[R1]

**优先动作：** 冻结双塔＋F2即可作为最终方法，不强求训练表示。

**可选修复：** 只适配文本侧，或两侧加入共同的identity anchor正则，lambda∈{0.01,0.1,1}最多一轮；所有损失同配置。总目标写为J加正则，不能继续称只有原J。记录局部匹配增益与整图检索损失的Pareto关系。

### F09：给定真实候选有效，换检测候选后失败

**检查：** 提议器召回、每图候选数和IoU、目标有没有进入topK、截断是否按query选择。

**动作：** 用统一更高召回的query-independent proposals；不重训练estimator前先比较同一GT对象附近的候选分数。与GT候选分表，分母包含未被提议器覆盖的查询。

**替代：** 以“给定候选的短语匹配”为主用途，不假装完整grounding。若整套定位器成为主要瓶颈，可转DCI固定mask匹配，而不是投入一个新检测项目。

### F10：只有极小样本差，更多数据时神经方法接近

**动作：** 增加一个中间N，不改测试集；用达到同一预定准确率/风险需要的独立图片数评价。双方允许同样的超参数预算。

**替代用途：** 保留少配对／小预算结论。若大N没有优势，不说“规模越大越强”；若大N更好而小N都失败，不将论文命名为few-shot。

### F11：长描述有效，短语任务无收益，或相反

**诊断：** 统计token截断、细节密度和候选歧义；对同一图片保留相同数量的描述，不把多文本曝光当免费。

**替代：** DCI局部详细描述或DOCCI整图细描述。文本侧分句/汇聚是共享新增模块；固定D1的结果和新D7/D8结果分表。

**限制：** 从区域任务转整图检索，必须更新P/Q和数据划分；不能直接复用原本排除上下文的区域评分器作为唯一表示。

### F12：噪声、组合性、泛化或全部强对照都没有优势

旧随机错配路线已有负结果，故只在干净方法成立后做一次预定义噪声压力测试。随机、同类、属性错误和词序错误分开，不能把都叫“20% noise”后合并。

当公平比较确认没有收益，应明确保留：可计算性/同目标神经估计用途、或阶段性负结果。不得降级JS基线、隐藏未经适配CLIP、只报告有利方向或把评价数据改成训练数据。

**真正的停止条件：** 一轮数据协议修复＋一轮有诊断依据的结构/优化修复后，主任务仍没有相对原CLIP的实际收益，且估计/成本也无明确贡献，则VL不继续消耗大预算；现有SSL与estimator主线继续。

## 3. 五条可独立选择的备用应用

### B1｜保持局部匹配，换更丰富描述：DCI

改数据和文本表示规范，保持冻结双塔＋VCS/JS/kernel。主要终点为同图局部描述检索、长短描述分层、样本效率。只取得官方需要的图片与注释，遵守许可。

### B2｜上下文指代：RefCOCOg / RefCOCO+

统一context特征和box几何；主要终点给定候选Top-1和proposal grounding。能够分析位置/关系的困难，但不引入大型生成语言模型或开放VQA。

### B3｜多caption精确图文检索：COCO / Flickr

采用同图所有caption为合法对应的多正例目标，冻结双塔或identity adapters。保留原CLIP、balancedJS、InfoNCE与SigLIP形式。评价双向R@1/5/10和细节基准；测试图片先从训练中排除。这是新明确协议，不恢复主题配对训练/自身caption评价错配。

### B4｜细粒度自然类别文字：CUB＋Reed descriptions

研究低配对数据的鸟类外观匹配。固定图片级任务或类别级零样本任务中的一种，按其原划分运行；二者不能混称。原CUB的属性标签只用于分层，若参与训练必须披露额外监督。

### B5｜已知视觉关系诊断：CLEVR-Ref+

用少量已知场景检查多个相似对象、左右/前后、颜色/材质关系。固定已知的随机对应通道时才有S真值。成功主要支持机制，不单独替代自然图像主实验。

## 4. 每次改路线前提交一页决定记录

填四栏：**观察到什么、哪一项诊断支持原因、只改变什么、原结果怎样保留**。再写新的数据、P/Q、独立单位、主指标、预算和freeze时间。

每次只允许一条备用主路线和一项低成本诊断并行。主数据测试集一旦看过，不再用来选择新的评分器。只有DEV出现差异才选择后续协议，最终确认另用未参与选择的样本/种子；差异为零同样是完成结果。
