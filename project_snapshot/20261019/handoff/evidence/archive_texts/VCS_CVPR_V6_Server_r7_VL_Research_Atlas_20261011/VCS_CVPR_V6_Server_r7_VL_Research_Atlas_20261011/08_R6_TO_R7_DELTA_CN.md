# r6 → r7：转回VL内部的研究扩展

r6提出配准REG与模态获取GAIN等新应用。用户随后明确“仍留在VL，但不要只做候选排序”。r7据此展开六个VL问题，不自动取消r6已批准的代码/数据核验，也不默认继续其大型运行。

继承：原S/J、有限风险残差、以基础样本为统计单位、已验证CPU检查与旧VL负结果。新增：六份专项综述和六份完整实验方案，67项文献、35个数据/协议条目、官方指标/基线对照矩阵。

r5/r6的具体应用任务未自动授权为本轮全部任务。接入先核对HEAD和真实作业，再按实际数据可用性与最近先例选择一个主方向。D1/D2优先核实完整训练与部署路径，D3先做有限条件分布检查；D4/D6是有工程复用价值的备选，D5的学生重训练成本必须明确。

任何先前未成立的说法（VCS天然抗错配、BCE一定较差、zero threshold语义概率、精确J数值代表下游质量等）不因换应用恢复。新应用中的一般P/Q不默认叫QMI。
