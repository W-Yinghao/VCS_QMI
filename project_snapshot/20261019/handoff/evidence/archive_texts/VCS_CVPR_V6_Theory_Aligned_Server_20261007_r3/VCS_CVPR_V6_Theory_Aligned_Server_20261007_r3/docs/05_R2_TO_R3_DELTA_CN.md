## 相比上一轮讨论的两个限定

“梯度方差随依赖强度”来自合作者原计划；不能只画bounded S的低方差，就宣称优于不同量纲的Shannon MI。必须同看误差/分辨率，保留数值稳定的多负例baseline。

“用噪声检查DPI”是本次视觉实例化，不是恢复旧noise优化路线。P101已给出负结果，合成Gaussian只是相关系数重参数化。r3只问既定通道下的真实测量是否可重复/可分，并保留零分数与饱和控制。

## 接入流程

在仓库外解压。已接入r2者不重新做全部盘点，只更新HEAD、P142–P148结果映射与新缺口。旧冻结单元不改变统计规则。r3参考目录中的r2/V6属于只读历史；发生文稿冲突采用三方合并，由负责人决定。

先交现有字段/产物表，再决定R3-E1是否需要任何新拟合。R3-V1也优先用P122缓存；算法、数据法则、checkpoint或预处理不同的历史行，不能因为数值接近就当复现实验直接拼入。

不增加新的长训练授权，不恢复已清理的intermediate checkpoint全程重训，不新开saliency、CLIP、概念瓶颈或依赖分数选模项目。
