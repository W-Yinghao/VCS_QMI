# 1. 本轮决定

**完整 SSL 继续作为主学习应用；测量端回到合作者原问题：对明确的依赖目标，测得多准确、稳定、有分辨力。** 条件颜色检验和预测响应保留为模型认识，不再承担“精确变分式更好”的主要证据。

这不是换损失、换理论或再造解释系统。当前 J、equal-mixture reference、bounded critic、exact regression gap 不变。依赖增量是补充的测量能力，不代替原计划的稳定估计主线。[O1 §1、4、10、12、17；O2 §2.6、3.3、3.7]

本文的标记：**[原计划]** 来自合作者研究计划；**[补充]** 来自2026-09-28意见；**[仓库]** 是指定提交的结果；**[建议]** 是本次拟定实验，不是已完成结果或已批准预算。具体来源和后续补充说明见 `docs/06`。

# 3. 原理论—指标—已有证据

| 理论所说的事 | 主指标 | 已有工作与当前缺口 |
|---|---|---|
| $S=\sup_TJ(T)$；估计明确目标 | $\widehat J-S$、posterior MSE | P86已做高维/样本量/依赖阶梯；不重开整套生成器 |
| $S-J=\|T-\eta\|_M^2$ | 同一T的gap、估值偏差、评价方差 | P108已验证局部二阶关系；实拟合的plug-in多半更准，必须保留 |
| bounded最优critic与经验项 | 输出/梯度尾部、有限读数失败、方差分解 | 先查P86原始过程记录，缺少完整图才补日志或少量拟合 |
| 不含DV指数矩 | 在各自目标下的误差、分辨率、计算与失败 | 保留in-batch DV/NWJ/InfoNCE及修正SMILE；不只展示单负例DV失败 |
| 数据处理与可逆不变性 | 配对变化读数、变换前后漂移、真实信号恢复 | P108已有合成旋转；P101已有冻结噪声负结果；本轮只补真实关系的定向检查 |
| [补充]二次增量几何 | oracle增量误差与有限critic敏感性 | P118有真值证据；P144真实量化未成功，仍不扩成主问题 |

**检验功效、下游accuracy、表示rank不是这几种数值误差的替身。** 一个严格递增的分数变换能保留置换p值，却改变对S的数值标定。常数零也有零方差、可逆不变性和数据处理单调性，却没有恢复非零信号。每张“稳定”图必须同时显示误差或实际分辨能力。[本次说明；参考代码含反例检查]

# 5. R3-E0：先整理一张真正对应原计划的主图

[原计划] §17指定的关键图是“估计/梯度方差随依赖强度”，§12同时要求误差、输出分布、失败率与成本。

[建议] 主图用三组相互独立的面板或三张图，不用只包含方差的一张图：

**E-Precision：**横轴为同一生成器的依赖参数或已知MI（仅作为设置索引），展示VCS、logistic→common-J及同目标核的posterior MSE、估值RMSE和置信区间。图注同时给出对应S，不能将MI当成S真值。

**E-Stability：**固定已拟合critic，重复独立EVAL抽样，分开记录评价方差、配对选择附加方差；固定FIT再变优化seed，或变FIT再重拟合，各自注明。原生loss梯度尾部和非有限步比例另图。raw gradient绝对尺度仅作同损失/同参数化诊断。

**E-Resolution：**相邻依赖水平的读数排序概率、带不确定性的差值，以及相对于各自oracle的误差。InfoNCE、DV、NWJ和SMILE保留，不把不同原生量直接排在一列RMSE里。

P86已发现in-batch InfoNCE能很好地区分各阶梯；修正SMILE也有限且能排序。P108修正后：plug-in在70/72格的绝对偏差更小、69/72格的RMSE更小。r3据此展示具体取舍，不再预设J普遍具有更小有限样本方差。[R8,R9]

**第一项交付是字段矩阵，而不是新任务：**列出每个原格子是否有oracle、选定权重、逐样本T、bootstrap、早中晚checkpoint、梯度、实际成本。文件被清理则记MISSING，不为补一张诊断图重训800epoch SSL。

# 6. R3-E1：只有缺口真实存在时，补最小稳定性单元

[建议，待冻结] 复用P85 Gaussian生成器：$d=20$、$N_{fit}=4096$、$B=256$、依赖阶梯$I\in\{2,6,10\}$；这里I只是已有生成参数索引。训练预算上限2000步，评估点250/1000/2000，超参/停止沿已登记方法规则。改变max budget不意味着挑最有利的EVAL checkpoint。

方法是VCS、matched logistic、DV/MINE、NWJ、InfoNCE、corrected SMILE六类。优先已有in-batch或等价多负例实现，K8 VCS的历史行单列；单负例DV作为旧stress行，不是唯一对照。每个条件三条配对fit seeds；上限54个新的“条件×方法×seed”单元，只有缺失者才执行，超参候选的成本另计。

**不得修改算法来制造稳定：**MINE保留已验证的log-sum-exp/EMA等数值实现；SMILE保留修正后的clipped-DV读数与实际训练梯度；拒绝不稳定exp手写版本作为主要baseline。新拟合必须存被选中权重、低成本过程指标、oracle与逐样本评价统计。

每个冻结critic重复64个独立评价batch；同一批数据上再做配对选择重复，区分图像/生成抽样与配对噪声。若旧日志已经覆盖，就只重新聚合。共同J梯度误差仅比较可转换到相同T坐标的VCS/JS及同目标核；参考梯度来自已知生成器参数的oracle导数。$\nabla_\phi L$的原生优化梯度与对生成参数的依赖梯度分列。

**验收不是VCS必须获胜。** 交付条件限定的bias/RMSE、尾部、失败与成本；分辨率为零/近饱和时不以小方差宣传稳健。跨目标的归一化梯度变异系数只作辅助，均值梯度近零时标无信息并同时显示绝对量。具体公式见 `docs/03`。

# 7. R3-V0：在真实SSL表示上固定一个清楚的测量问题

[原计划+视觉实例化] 对已冻结encoder，在同一测量增强法则下生成两个独立视图，研究

$$
P=P_{H^{(1)},H^{(2)}},\qquad Q=P_{H^{(1)}}P_{H^{(2)}}.
$$

它与SSL的配对问题直接对应，但只读模型，重新拟合measurement critic。最终VCS和SimCLR是被测对象，VCS-J、logistic-fit/common-J和同目标RFF是测量算法，两个身份分开记。

**优先P122。** 其中已有标准/强测量法则、标量s/full pair及三种子扩展。常规法则下$s$的最佳读数已接近0.97–0.99，不能把微小数值波动当“低方差优势”；强测量法则恢复了更多结构。先恢复原缓存、manifest、独立读数与初始化记录。[R11]

[建议] 最小新fixture为两个数据集×最终VCS/SimCLR，共4个固定checkpoint，优先seed1（与现有分析接续，不按分数选seed）。首轮用backbone $h$，不扩成全层×全属性。新增数据时复用10k FIT/2k VAL/8k EVAL的base-image角色，但必须重新确认与现有视图缓存的法则相符。属性版clean/modified数据不能冒充两个独立随机增强。

样本从已有训练侧数据选取，不擅自打开官方测试；是否曾被encoder预训练见过单列。每个角色内，不同base image的关系保持。预测读数的已有classifier不介入当前两视图critic。

# 8. R3-V1：测真实关系的稳定性，而不是再给噪声取一个好看的名字

## 8.1 可逆坐标检查

[原计划] S对共同推送后的可逆重参数化不变。[建议] 每侧施加独立、固定的正交矩阵。矩阵和seed在FIT前登记，对FIT/VAL/EVAL统一使用。

先做**运输权重的实现检查**：对full-pair MLP同时变换第一层权重，前向输出应数值一致；对精确各向同性核，距离/Gram应一致。这验证坐标变换实现，不是新的统计发现。

再做**重新拟合检查**：各变换下独立拟合、同预算，测漂移、拟合离散度和成本。P108已有合成旋转，不重复其全网格。有限RFF采用哪些随机频率、是否随坐标运输必须注明；固定cosine在两端独立旋转后不再是同一个标量观测，不能据此宣称S定理被违反。

## 8.2 共同随机通道

[建议，非原计划指定视觉实验] 在FIT上仅估计一次均值和一个全局RMS尺度，得到每坐标平均方差为1的固定坐标表示。定义

$$U_t=\widetilde H^{(1)}+W_t^{(1)},\qquad
V_t=\widetilde H^{(2)}+W_t^{(2)},$$

其中两侧Brownian噪声独立，$\operatorname{Var}(W_t)=tI$。初始测量水平固定为$t\in\{0,0.25,1\}$（每坐标标准差0、0.5、1），不再每水平归一化/重新PCA。P/Q两种分布经过相同通道。对$t_2>t_1$，可由独立增量构造$t_2$，所以总体S不增加。

这只是一个可解释的压力轴。**不是“噪声改善VCS”的方法**，不接入SSL训练，不搜索最大测试收益的噪声，不为保证曲线下降做isotonic或clipping。P101已否定旧VCS checkpoint上“加噪提高分辨且保留kNN”的路线，该负结果原样保留。[R10]

Gaussian上的等效相关系数只用作代码核对，不能另算一项新结果；补充意见已指出它只是已有阶梯的重参数化。[O2 §2.4]

## 8.3 对照、预算与解释

每个fixture四个设置：原坐标$t=0$、旋转$t=0$、原坐标$t=0.25$、原坐标$t=1$。三种拟合路线，每路线三条fit初始化；首轮共144个选定分析格，历史完全相同的格子复用。每格至多三个预定义TUNE候选，因此实际拟合启动数上限432；这只是小critic预算草案，不是获批GPU额度。首轮$N_{fit}=2048$，最多1000步；额外样本轴和$z$位置都等这轮预算/结果完整后再另记协议。

共同候选数不等于算法总成本完全相同，记录fit、TUNE、EVAL、特征提取的真实时钟。原有已验证的critic配置优先；新空间中固定基准lr和核带宽候选在EVAL前冻结，不根据算法胜负更换函数类。

每次实验报告$\widehat J$和其不确定性、同一T的$\widehat S_{plug}$、$T$分布/饱和比例、fit/VAL/EVAL差、相邻水平差和重拟合漂移。**真实图像不报告oracle MSE，也不把较高预算critic称truth。** T=0与独立配对null始终保留，保证“不变/单调”不被当成充分精度证据。

P144说明两个拟合都接近零时不能量化损失；同样，真实两视图均接近1时微小方差也可能只是可分饱和。统一给出数值可分/不可分/估计敏感的条件性读法，不自动要求VCS成功。

# 9. 不确定性要真正匹配采样

[建议] 真实基线优先独立评价：EVAL 8k中预先分配2000个正对base image，2000个负左端base image，2000个负右端base image；三池互斥，余2000保留。两个负端按已固定规则一一配对，同一base不重用。由此固定critic的P项、Q项评价可用独立两样本方差公式。

所有方法/坐标/通道水平共享池划分与重采样索引，以估计配对差值；不能分别抽完再称paired。同一图像的多个视图、噪声副本和K负例不是额外独立样本。若复用原U-statistic/full-pair评价，就保留其依赖结构：按独立base-image块重建统计量或采用明确的U-statistic方差，不能把每一条边当iid。

至少分列三种误差：**固定fit的评价抽样波动；固定数据/表示的配对选择噪声；重拟合带来的差异。** 三个encoder种子是第四种变异来源，不能与100次检测重复合并增加训练样本数。

# 10. R3-C0：真实压缩只做一个有限核对

P144是真实$h\to r\to z$与$h\to O$，但当前定量读数不可分，且1000步并未改变早停选择。不能简单再延长训练。[R7]

[建议] 只取CIFAR-10最终VCS seed1、colour0.1、$h\to O$及对应null；同一P143数据上复用P143/P144的两种函数类，各用VCS/JS拟合，统一读common-J。对齐输入标准化、包含的Y/N交互、exact-Q、先验权重和训练角色。原$n=3000$、300步/1000步规则先保留；若原函数类需其他solver，按已登记短预算如实报告。

保存逐样本/独立块预测，补paired bootstrap；拆开固定数据变优化seed与变base sample的差异。比较的是为什么检测与估值不同，不默认bug、不默认信号不存在。保留signed $\Delta J$、$D_T$、null基线、选择到step0的比例。区间不包含未知函数逼近偏差时要注明。

若仍无可靠量化，完成结论就是“该条件只支持检测，不支持定量压缩”。已知真值P118仍可展示二次结构的测量作用。后续是否引入新估计方法另作研究决定，不把这个单元扩成必须修成功的大项目。
