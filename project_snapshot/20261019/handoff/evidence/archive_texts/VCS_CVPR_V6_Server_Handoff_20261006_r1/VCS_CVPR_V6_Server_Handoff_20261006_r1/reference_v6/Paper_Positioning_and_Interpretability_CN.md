# 1. 本轮的核心决定

**这是一篇估计器论文，以完整视觉 SSL 为主应用，以冻结模型的条件依赖分析为第二个直接应用。可解释性应证明这个 estimator 能测量一个真实视觉问题，而不是再发展一套独立的通用归因系统。**

论文的研究问题是：

> 怎样把 Cauchy–Schwarz 依赖变成一个可以直接从样本学习、具有明确误差关系，并能用于高维视觉表示的工具？

新的英文标题采用：

**Variational Cauchy–Schwarz Quadratic Mutual Information for Visual Representation Learning**

整篇文章保持一个方法名称 **VCS**。服务器中的 A-P3、G2、recipe VCS 是配置标识，不再作为不同的“我们的方法”出现在主比较表。当前正文使用 A-P3 对应的完整实现；保留必要的固定／自由评分消融，但将其放在补充材料。

本轮不是把上一份局部可解释性计划原封不动塞进正文。上一份计划的外部比较原则保留，但三个模块被重新分工：**有真值的解释检查归入 estimator 实验；概念／属性审计成为一个紧凑的视觉测量应用；空间显著性暂不成为论文必须完成的第二主线。**[O1,O2,O3]

# 2. 为什么需要这一调整

旧稿 v5 的摘要、方法和贡献仍围绕“可学习 cosine critic＋负配对单侧梯度＋多视图”，主要结果为 CIFAR-10 的 87.01%。它尚没有吸收后续 estimator 直接比较、固定刻度完整梯度、CIFAR-100，以及独立测量实验。[O1]

而上轮可解释性重构又向另一个方向展开过快：真值三状态、概念审计、区域掩膜、观测分辨率、RISE/RELAX/HSIC、VOC 等同时出现。这样会产生一篇新的 attribution 论文，要求解释算法本身有一套独立的新颖性和大规模基准，却不一定加强原始 CS estimator 的主贡献。[O2]

因此，本稿采用以下分工，而不是一个实验接一个实验地堆叠：

| 层次 | 论文真正要回答的问题 | 主要证据 |
|---|---|---|
| 估计对象与理论 | 这个量是什么，为什么能从样本计算，误差从哪里来？ | 混合参考 CS、精确回归 gap、估计误差与观测压缩 |
| 估计器实验 | 在相同目标、样本和预算下，哪些估计性质得到改善？ | 高维后验误差、样本量、核／神经直接比较 |
| 视觉学习 | 这个目标能否训练出实际有用的表示？ | 完整 SSL、外部方法、数据集与增强条件 |
| 视觉测量 | 模型固定后，这个工具能否提供有意义的依赖读数？ | 条件属性检验、有限样本对照、同图预测响应 |

**学习与测量是同一工具的两种用途，不是“估计更准必然导致分类更准”的因果链。**

# 3. 可解释性应在全篇中承担的作用

## 3.1 第一职责：直接检验测量用途

SSL 中，encoder 可以通过变化来配合评分器；因此，好的 accuracy 不能单独证明 estimator 对固定分布的测量准确。冻结模型后的依赖分析补上了另一个场景：模型不变，只有测量器拟合，估计对象也事先明确。

主对象首先用外部 SimCLR 模型。主表按“同一模型上的 VCS、核方法、JS 或 HSIC”组织。最终 VCS encoder 可以接受同一流程，但不能由旧配方到新配方的改善来证明解释工具优越。

## 3.2 第二职责：使二次误差结构具有视觉含义

主理论中的

\[
S-J(T)=\mathbb E_M(T-\eta)^2
\]

说明估计误差是什么；一般观测压缩中的

\[
S_B-S_A=\mathbb E(\eta_B-\eta_A)^2
\]

说明需要测量的变化是什么。二者共同说明：比较压缩前后的表示时，应同时处理两端的 critic 拟合误差。[O3,O4]

有真值的嵌套压缩实验放在 **Estimator precision** 部分；视觉属性审计再使用该测量思想。这样，压缩理论不是为了一个临时图表增加的定理，可解释性也不是与主理论没有关系的附加热图。

## 3.3 第三职责：解释“可检测性”和“预测响应”的区别

对属性变量 N、类别 Y、表示 H，估计器比较

\[
P=P_Y P_{H,N\mid Y},\qquad Q=P_Y P_{H\mid Y}P_{N\mid Y}.
\]

它测量的是条件依赖。独立的同图干预测量概率变化、分类变化和预测翻转。两栏并排，能够回答“模型中是否存在可检测的属性关系”和“规定属性变化使输出改变多少”。

这不是像素贡献分摊，也不把关联强度当成因果效应大小。当前没有必要为了“可解释”三个字，额外引入响应噪声、空间掩膜或生成式反事实模块。

## 3.4 不承担的职责

可解释性不负责挽救小幅 SSL 提升，不负责证明我们训练的表示普遍比别人“更可解释”，也不负责在尚未完成实验时声称超过所有归因算法。

当前的证据可以支持 **a direct dependence-measurement application on frozen visual models**。要升级为“更强的通用解释工具”，需要完整外部解释基准；这不是本版稿件预写的结论。

# 5. 这版到底写入了什么结果

## 5.1 Estimator 主结果

P86 的相同目标比较已经完整。独立无关维度增至每侧 50 维时，VCS 后验 MSE 为 0.169，RFF 0.507，KDE 0.527；该轴真实 S 为 0.540。增加样本量时，VCS 从 N=256 的 0.364 降到 N=16384 的 0.029。匹配 logistic 经常接近或略好，因此正文明确把主要优势归到相对于已测试核估计路线的结果，而不是声称二次损失处处优于神经 logistic。[R1]

有真值的嵌套实验单独验证增量：VCS 的真实零增量步骤误差 −0.0204→−0.0001，真实正增量 RMSE 0.0105→0.0070；JS 嵌套版本同样有明显改进。本文将其称为改善测量可靠性的结果，不把 nested 当成一个与原估计器无关的新方法。[R4]

## 5.2 SSL 主结果

正文只出现一个选定 VCS。CIFAR-10 的五种子 linear 为 89.02±0.04%，SimCLR 为 88.31±0.21%；主比较表另用一致的三种子给出两个数据集。CIFAR-100 的当前 VCS 为 60.00±0.25%，SimCLR 为 58.25±0.35%，但 kNN 排序相反。[R2]

**本轮新纳入的结果：CIFAR-100 调参后的 JS 已完成三种子，60.49±0.21%，高于当前按规则保留的 VCS 约 0.49 点。** 这已经写进主表，不能继续只展示共同默认参数下 VCS 领先的结果。共同默认参数五种子对照保留在补充材料，回答另一个问题。[R3]

强增强下 VCS 88.25%、SimCLR 89.49%，也在正文文字与补充表中保留。正文不以更高 J、较小方差或内部消融代替这些外部准确率事实。[R2]

## 5.3 可解释性现有结果

正文采用固定外部 SimCLR 的测量对照。三种已完成条件中，VCS／短预算 JS 的拒绝率分别为：blur0.5、n1000：0.75／0.82；blur0.5、n2000：0.99／1.00；colour0.2、n2000：0.97／0.94。对应拟合时间约 0.04–0.05 秒与 0.05–0.07 秒。[R5]

**这张表证明可用的条件检测与现实成本，不证明 VCS 有全面的解释精度或 30 倍计算优势。** 旧报告使用长预算 JS 时的 30 倍读法没有进入稿件。

另一个同图配对审计中，外部 SimCLR 在 colour0.2 下的准确率约下降 0.7 点，平均真实类别概率改变 −0.007，约 3.8% 预测翻转。它用来解释测量和行为的关系，不与上一张表的不同 audit fixture 混合计算。[R6]

# 6. 对最新分层报告和旧措辞的处理

P141 的分层读出值得保留，但不应直接称“每种方法都丢失了细粒度信息”：SimCLR 的 fine 读出从 h 的 56.6 到 z 的 56.7，至少不支持“所有方法均下降”这句话；而且任务 probe 精度不是信息量。[R7]

本稿因此只写：VCS 与 SimCLR 的任务可读性排序随表示位置改变；表格使用明确的标准化读出，并注明 seed 数。它作为表示分析放在 supplement，不承担解释器比别人更好的结论。

同样，P109 的“removed”“not used”改成“在这个样本量和检验下未检出”“规定干预的预测响应较小”。新文本不以这类变化偷偷修改原结果数值，而是在作者证据表中明确记录这一表述收紧。

# 7. 上一版可解释性计划的取舍

| 原计划内容 | 本篇论文中的决定 |
|---|---|
| 三状态 oracle（不编码／编码但输出不变／编码且输出变化） | 可作 estimator 补充检查；不再独立占一条视觉应用主线 |
| 条件概念／属性审计 | **保留为第二视觉应用的核心** |
| 真实嵌套关系与依赖增量 | **保留，直接承接平方误差理论** |
| 在同一外部模型上比较 VCS／核／JS／HSIC | **保留，是正式测量实验的正确比较单位** |
| 同图属性干预 | **保留，说明实际响应，与依赖读数分开** |
| 随机掩膜空间图、RISE／RELAX、大规模 VOC | 本稿不要求；作为后续独立应用选择 |
| 为解释另加响应噪声 σ、区域查询网络 | 不进入当前方法和主实验 |
| 旧 VCS→G2→A-P3 的属性差异 | 开发记录或 SSL 消融，不再作解释章节的主要成功证据 |
| 依赖审计辅助选模 | 保留已有负结果，不扩展 |

这个收束不是将解释性删除，而是让它回答一个足够具体、与 estimator 紧密对应的问题。**一张有外部对照的测量表，加一组同图响应结果，比三套尚未完成的解释系统更有论文价值。**

# 8. 下一步对整篇论文最重要的补充

现有正文只写已完成且可核对的实验，没有给 ImageNet、空间图或新的外部解释基准填入预测数值。以下工作进入作者计划，不以 TBD 表格进入正文。

**第一，完成规模化 SSL。** 当前 ImageNet 只有数据／配对／吞吐预检查。最终 CVPR 投稿的规模论证仍应依赖完整的 ResNet-50 训练与合理外部对照，不能让可解释性承担这一缺口。已有管线和服务器任务继续执行，不重复新开。

**第二，把条件审计对照收成一个固定模型上的完整预算表。** 保留相同目标的 kernel、匹配 JS 和对应 HSIC；采用相同样本、null、停止规则和成本。现有主表只有有限的 VCS／JS 结果，不能据此声称全面胜出。至少再纳入一个外部 encoder 和一个数据集，是比新增像素归因更合适的补充。

**第三，补充真实视觉压缩的稳定测量。** 复用 nested_exact，在真正的 h→r→z 或 h→固定任务输出关系上测量；以 oracle 实验校验误差，以独立 EVAL 检验读数，不强制单调、不截断负增量。这里的终点是测量可信度，而不是必须发现最终 VCS 最少依赖某个属性。

三件事共享同一套论文中心：**估计器有什么统计性质，它能否用于实际学习，它是否能提供实际测量。** 不再围绕“某个内部配方比另一个内部配方更好”组织新章节。
