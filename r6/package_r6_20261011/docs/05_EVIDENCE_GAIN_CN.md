# GAIN：任务相关证据增益与按需模态计算

**类型：P，新应用方案。** 先做一次新增模态决策，不做复杂序贯RL、无监督因果发现或通用信息基础模型。

## 1. 任务

U是已可用的低成本观测，V是需要额外计算的观测，Y为原任务标签。最终系统先运行廉价分支与策略，只对被选样本运行V分支，再使用对应预测器。

目标：在相同实际成本下降低任务风险，或以较少额外分支调用保持预定任务质量。不是为了让两模态互相“更像”。

原理是同一平衡二元任务的S增量=Bayes平方风险改善；多类真实任务采用多类Brier扩展。必须同时区分理论证据增量、有限模型收益、策略可预测性。详细推导见docs/03。

## 2. 首轮四种可计算的构造

| 构造 | U,V,Y | 应有结论 |
|---|---|---|
| 冗余 | V=U，Y由U决定 | Bayes新增收益0 |
| 无关 | Y由U决定，V独立 | Bayes新增收益0 |
| 互补 | U,V独立均匀±1，Y=UV | 单看U无效，联合完全可预测 |
| 价值异质且获取前可见 | U=(K,X)；K=0时Y=X，K=1时Y=XV | d(U)=K；只有K=1需要V |

再做两个负检查：让full predictor比cheap predictor更差，z=(b-a)^2仍为正；在纯XOR中d(U)恒定，每个样本价值相同，策略不应被预期优于相同预算的随机选择。

构造的真值仅属于这个生成器，不是“冻结CLIP特征的真值”。自然数据标签不能在没有可恢复性条件下充当观测MI oracle。

## 3. 自然数据入口及任务

AV-MNIST适合完整小型原始输入流程：图像分支和音频分支。使用官方10类识别作为自然任务，二元CS连接只在受控构造或预定义额外二元实验中展示；不删困难类别凑有利结果。

若pilot成立，再选择一个真正视觉场景：CREMA-D音视频（演员不重叠；官方原始视频而不是audio-only镜像），或已有可访问的RGB–depth / video–audio数据。CREMA-D不依赖新医生或临床标注；AV-MNIST不能单独承担CVPR规模证据。

如果V是已采集但未处理的音频，结论是“选择性计算”，不是物理传感器成本减少。视频解码/前处理也要计时。使用预计算特征可作定位bug的工具，但不能把省略了视频分支的特征级时延当原始端到端时延。

## 4. 数据角色与完整预测模型

按独立来源group先划分官方训练数据为FIT_TASK/FIT_POLICY/CAL/DEV（建议60/20/10/10；实际按样本与组数量冻结，不任意破坏官方train/test），官方test保持最终一次评价。音频原文件在AV-MNIST中可能被重复配对；若不能追踪original音频ID，应披露无法保证原始音频独立，而不是假装每条pair独立。

在FIT_TASK训练廉价预测器a(U)和全模态预测器b(U,V)，分别有：
- 平方/Brier训练家族；
- 同类网络的Logistic/多类交叉熵家族。

初版采用完整小型CNN而非仅冻住外部embedding训练线性头。a可与b共享廉价分支以重用计算，但理论“U嵌套在UV”是输入关系，不自动保证两个有限网络的风险有序。共享/不共享选择对所有方法一致。

训练预算、数据、模型规模与CAL选择规则对称。自然pilot建议每家族3种子。预测器从FIT_TASK产生，在FIT_POLICY上输出未训练过的样本预测；不将其训练残差作为策略真值。

数据多时可K折交叉拟合以提高策略样本量，但必须把critic/预测器训练成本计入。首轮不必为了“理论感”加入复杂重拟合系统。

## 5. 两种策略目标都运行

在FIT_POLICY上计算：

z_i=||b_i-a_i||²，
h_i=||e_y-a_i||²-||e_y-b_i||²，
res_i=h_i-z_i。

二元用C∈{-1,1}而非one-hot，多类用概率向量。为便于比较，记录每个分量，不只存最终平均值。

- **GAIN-square：**由U预测z，目标对应近似Bayes证据增量。
- **GAIN-utility control：**由U直接预测h，目标是使用当前模型时的实际风险改善。
- **Residual measurement：**按CAL预测收益分箱，检查h-z是否接近0及对路由错误的影响。

策略网络相同（如廉价表示上的两层MLP），不可输入V、full logits、Y、真实扰动强度或任意部署不可见信息。z/h只可作训练目标。h的负值保留，不无说明截断为0；即便最终策略不获取负收益样本，训练也要知道其存在。

策略冻结后由CAL设阈值/预算。DEV只读既定预算曲线，不能在DEV选择阈值或挑最佳预算点。

## 6. 必备对照与归因

| 对照 | 作用 |
|---|---|
| 从不获取/总是获取 | cheap/full端点和是否存在新增模态收益 |
| 随机获取（同额外调用比例，多随机重复） | 检查是否真的能预判谁受益 |
| 基于cheap entropy/置信度 | 常见、便宜的策略，不需要新estimator |
| 直接风险改善h预测 | 最强的任务对齐控制；不能省略 |
| EDDI式信息增益 | 方法定位；可复现时同任务对照，不能只比较弱random |
| AdaMML或适用的现代获取策略 | 原生视频任务中作完整系统参照，标明监督/输入成本 |
| 知道Y或看完V后的逐样本oracle | 仅上界，不算可部署方法 |

将两种预测器家族和两种策略目标分开，形成2×2的轻量归因表。若主要收益来自策略目标而非平方拟合，不称其VCS损失独有优势。若只得到直接h策略更好，不把标准风险回归重新命名为新CS方法。

近期AFA已有解释排名、随机潜变量和跨任务in-context策略；需要对任务和输入权限定位，不必首轮全部移植。[L4–L7]

## 7. 评价

主要表：获取比例(例如0/.25/.5/.75/1)、实际端到端毫秒/样本、显存/FLOPs、Brier风险、准确率。预算是任务规格，不是预测提升。

增益预测：预测收益分箱与实际h均值；受控oracle中的d(u)误差；自然数据上的policy regret只能相对明确的finite predictor oracle，不伪称Bayes regret。

运行成本：cost_total=cost_U+cost_policy+selection overhead+I(acquire)*(cost_V+fusion incremental)。全模态b若重新计算U，必须算入；缓存只在部署真实可用时使用。测量至少两个batch/覆盖率设置以发现稀疏路由导致的低吞吐。

统计：视频/演员/原始图像等真正独立group重采样；模型种子变异与评价样本变异分开。最终可部署策略不读测试标签，不根据TEST全体收益排序分配预算。

## 8. 有限pilot单元

一个自然数据源，2种预测器拟合目标×3个种子=6组cheap/full系统（每组包括两种输入条件，不隐瞒训练次数）；同一批OOF或FIT_POLICY预测复用给GAIN-square、GAIN-utility和cheap uncertainty/random。策略训练不重复预训练所有编码器。

共享模型从头或按统一预训练初始化完整训练；数据量和epochs在一次资源实测后冻结。参照官方MultiBench小型网络可用，但生成几百条随机配对的smoke不算完整自然实验。

## 9. 失败时处理

- full不改善任务：检查训练/模态质量；不靠强迫添加信息制造收益。
- z很大但h<=0：模型误差，不是信息增益；报告残差并与直接h控制比较。
- full有益但U无法预测谁受益：静态/随机策略可为合理解；不让selector偷看V。
- 比random好但不如entropy：应用价值尚不足；看是否有真实互补子域和校准收益，而不是换阈值追名次。
- 省FLOPs不省时间：按实测报告，不能用理论调用数代替壁钟加速。
- 原音视频下载受限：先用完整AV-MNIST检验方法，再换到已列可访问原始数据；不使用缺失音频补零却继续声称多模态获取。

## 10. 此线可成立的贡献与边界

有意义的结果应同时说明：测得的新增证据与实际收益的关系、仅用已有信息能否作决策、效果—成本是否优于强简单策略。公式本身是标准条件期望结构；可争取的是有限估计与实际获取的可用方法，不能提前宣称“证明了新的互补信息理论”。
