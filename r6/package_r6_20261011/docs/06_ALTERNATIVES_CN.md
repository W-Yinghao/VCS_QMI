# 三条备选路线与转向决策

本文件保留发散，但不形成三个默认作业队列。每条先交科学问题卡与最直接的prior-art表。REG/GAIN没有出现实质用途时，再决定是否推进；不要用“上一条没赢”作为唯一理由。

## A. 去除干扰依赖

对象：任务Y、可观察干扰N、表示Z；比较 P=P_Y P_ZN|Y 与 Q=P_Y P_Z|Y P_N|Y。原始J不变，但估计条件分布与Y分层需要足够样本。

用途：保留任务损失，同时减少干扰依赖，评价新的偏差组合/域上的表现。DANN/ReBias/HSIC及适用的偏差鲁棒方法必须比较。

最小验证：可控背景/纹理关联改变、标签条件的干扰变量、独立强probe和真实OOD任务。训练critic的低J不是独立性证明，max_T没有充分求解时min_encoder J可只是在欺骗critic。多个probe同样不能给普遍上界。

触发：已有真实、可观察干扰和明确OOD测试；否则不开放泛化“消除全部shortcut”的新故事。数据入口可先核对Waterbirds或同类已定义偏差任务，版本/许可/预训练暴露由服务器核验后再用。

## B. 任务相关压缩/蒸馏

对象：同一个任务实验中的完整观测B与压缩A=g(B)，研究任务风险/证据损失，而不是确定性教师—学生整体QMI。

确定性非原子输出可能令joint/product互相奇异、S=1，与压缩是否保留任务无关。须先完成docs/03的这个负例检查。

用途：选择通道/token/码率，主指标为误差—计算或码率曲线。对照标准task-only compression、KD、VID/CRD和已有CS蒸馏。若仅换掉蒸馏loss，不作为新能力。

触发：我们已有模型和真实预算瓶颈，且GAIN的有限预测风险工具证明有用。不能将对原SSL checkpoint的另一次probe当成新完整压缩系统。

## C. 摊销依赖估计

对象：一小组P/Q样本条件化一个critic，另用独立评价样本读J。InfoNet已有无需测试时优化的MI估计，因此“摊销”不是首次。

用途：需要反复估计大量关系时，减少每次新训练成本。主指标为oracle误差、分布外失效、适配成本和回退成本；原目标是S不是Shannon MI。

最小验证：明确分布族与out-of-family测试，防止训练分布先验输出稳定但错误值。直接预测数值和输出critic后读J分开。

触发：REG/GAIN实际需要大量逐问题拟合，并且其成本已经成为瓶颈。没有这个需求先不训练大模型。

## 转向并非换榜单

| 当前原因 | 合理替代 | 不合理替代 |
|---|---|---|
| REG数据难获取 | 已列另一个公开成像源 | 下载不明镜像后忽略许可/对齐 |
| REG依赖能量与几何无关 | 修改观测假设或结束此pilot | 无限加大critic直到配对准确率高 |
| GAIN收益不可由U预判 | 静态预算结论或选择新的明确问题 | 把V/full logits偷偷给selector |
| 两条只有既有算法重现 | 回作者定位真实理论增量 | 新起名称、换场馆后继续宣称新estimator |
| 准确率相近但成本/测量能力明确改善 | 以实测新能力收束 | 只说competitive而无任何新增证据 |

本轮不默认转文生图、医学诊断、EEG项目或CC3M预训练。EEG可与原计划背景相容，但不与用户其他未发表项目混合授权/数据。
