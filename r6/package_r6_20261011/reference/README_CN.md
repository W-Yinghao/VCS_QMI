# 参考代码的用途

仅验证r6中的数学与实施约定。它不替代当前仓库训练器；没有下载新数据、训练自然图像/音频模型或访问服务器。

`r6_reference.py`：有限分布S/J、RPC恒等式、任务证据增量、有限模型实际风险、获取策略输入/成本、group分割、离散传感器整数位移示例。

`run_reference.py`输出四种oracle任务和一个“平方分歧为正但实际收益为负”的反例；整数平移示例使用生成器已知的uniform product Q，不是自然REG中同场景shuffle对象。它没有连续配准梯度，不能作为配准成功率结果。

只依赖NumPy与Python标准库。运行见包README。`validation/`保存本地测试结果，服务器接入时应再次运行。
