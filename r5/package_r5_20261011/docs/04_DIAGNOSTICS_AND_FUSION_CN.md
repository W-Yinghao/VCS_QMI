# r5 分析规范：已有模型的评分重读与解释

## 1. 共同对象与数据清单

本轮模型来自完整双塔微调，不重新拟合任何冻结特征分类头／critic。

- 现有主池：R4-VL1 两数据集 × VCS/JS/set-softmax × seeds 0,1,2，共18个 checkpoint。
- 增量池：R4-VL2 两数据集 × VCS(ν)/JS(ν) × seeds 0,1,2，共12个，待确认输出完整。
- 后续池：R5-30 的6个 distribution-softmax checkpoint。

每个 checkpoint 需要：模型 hash、所选 epoch、a/b、CAL 与 DEV 每查询各候选 cosine、proposal ID/框/检测分数、目标框或可复原的 IoU、真实候选 mask、数据角色。候选、查询和图像必须按稳定 ID 对齐，不依赖文件偶然顺序。

先复用 `outputs/R4_VL0/scores_r4vl1/`、R4-VL1/R4-VL2 最终输出和现有 `r4_vl0_scores.py` 的接口；路径以实际 intake 为准。缺评分只允许对已训练模型重做 forward，不重训。

不可变 inputs manifest 包括 image_id、query_id、proposal_ids、model hash、A阈值、score阈值和规范化规则。若检测器输出变了，不能称为同候选比较。

## 2. R5-10：分数融合与选择规则分离

### 2.1 F0：原协议主读数

原样呈现 R4-VL2 的 canonical score `2a*cos + logν`、uniform 模型 plain score、其固定系数融合控制、每个seed与所有缺失项。原定 λ=1 是冻结方案，不事后删除。

新增勘误而不修改协议：区间包含0只代表区间包含0。若未事前规定等效或非劣 margin，不写“已弥合”“相等”。C3b 不显著也不能排除存在训练作用，更不能据此断言所有收益仅来自融合。

### 2.2 F1：每个固定 checkpoint 的相同 CAL 搜索

对每一目标／seed，固定其原先 CAL 选定 checkpoint，搜索

`lambda = [0.0, 0.25, 0.5, 1.0, 2.0, 4.0]`

score=`2*a*cos + lambda*log(detector_score)`。每个候选均满足正分数，logν与logdet只差查询内常数。选择主指标为 CAL all-proposal image-macro Acc@0.5。若完全并列先取更小 λ；不使用 DEV 破并列。预留 λ=0、1 两个冻结锚点，DEV 只报告这些和 CAL 选定值，不展示整张 DEV 调参曲线。

对 ν 训练模型，λ=1 保持原生解释；其它 λ 标记 `posthoc_task_calibration`。对 uniform 模型加检测分数是测试时信息融合，不声称对应其原来的密度比修正。

这组控制回答“相同额外检测信息和有限标定机会下，整个已选择模型的使用效果”；不能单独隔离训练参考，因为 checkpoint 选择规则可能不同。

### 2.3 F2：检查 checkpoint 选择影响

仅当各方法存在相同候选 epoch 列表且权重或评分可恢复时，在相同的 epoch×λ 网格选择。并列取最早 epoch，再最小 λ。各方法只能使用完全共同的可恢复 epoch 范围。记录增加的 CAL 查询次数。

若仅保存最佳 checkpoint：F2=not_identifiable_from_saved_states。不能假造旧 epoch，不能把新训练模型换成末尾状态、旧模型用最佳状态，也不自动为补 F2 再跑几十个训练。

共同读数仍保持原 F0/F1；F2 是附加，不覆盖原实验。如果 F2 无法做，结论明确是“参考训练＋模型选择的总效果”。

## 3. R5-20A：危险错误框的参考与评分梯度

### 3.1 诊断集合

主分析覆盖所有有 ≥1 合法、≥1 非法候选的查询。无合法或无非法分别计数，不删除出部署主准确率分母。

每条查询固定合法集合 A（IoU≥0.5）。非法候选的两个排序：

- `self`: 当前模型的实际部署分数；uniform plain=f，score-reference=2f+logν。
- `shared`: 固定 zero-shot SigLIP 2 B/16 cosine 所给的非法候选顺序；如果源评分缺失，则对原始模型作一次 forward。不得改成“哪个基线恰好更适合本方法”后再选择。标注不参与共享排序，只用于识别非法候选。

两种排序各取 top1、top5（非法不足5就取全部，实际数单列）。self 指不同模型各自易错对象；shared 才在相同干扰集合上比较。

### 3.2 字段

按查询的条件 p,q 计算 π=1 的输出梯度；按真实图片 π 与实际 batch 因子另算训练权重版本。报告：

| 字段 | 定义与用途 |
|---|---|
| q_mass_top1/top5 | Σ选中 q；并报告除以全部非法 q 质量后的比例 |
| abs_grad_fraction_top1/top5 | Σ选中 |g_f| / Σ非法 |g_f|；分母=0记 NA，不填0 |
| f_grad / cosine_grad | 实际损失对 f 与 cosine 的梯度；cosine_grad=a*f_grad |
| posterior_residual | T−η，其中η是本图标注采样实验下的有限表值 |
| wrong_saturated_invalid | 非法框 T≥0.95 的比例与梯度；它们的η=−1 |
| bounded_saturation | |T|≥0.95，阈值固定且只是描述性 |
| near_overlap band | 非法框中 IoU 0.3–0.5 与<0.3；不更改任务标注 |
| type | 沿 R4 的局部/重复、同类别、其它类别、无匹配标注定义 |

绝对梯度比较必须记录 a、b、objective loss scale；不同类目标可能有不同标度。主要比较候选上的份额、谁贡献了错误竞争，而不是“某损失梯度小所以稳定”。

P和Q分量分别保存，避免在合法框处把抵消解释为“没有负项”。候选参考改变时，p不变而q变；同一个候选上的目标后验η也变，不把两个η当同一真值。

### 3.3 样本与时刻

主比较用已冻结 CAL-selected 模型。若已有早中晚评分可恢复，则固定1、5、10 epoch作补充；没有就记缺失，不新加训练。对新 distribution-softmax 保存同样锚点及所选epoch。

DEV 上的梯度只是固定函数在评价图片上的损失导数诊断，并非真实训练历史；训练过程的机制必须使用 FIT 锚点且记来源。本包不自动做需要再次保存大量 backward 图的 encoder 参数梯度实验。

### 3.4 可允许的解释

q_mass 变大但梯度份额没变：参考质量变化没有转成相应评分更新，需看残差、饱和与抵消。

q_mass/梯度都更集中且任务改善：与危险候选解释一致，但仍需区分训练选择、额外检测分数和正例目标。不能称为因果证明。

VCS与JS共同变化：归为参考设计的共同作用，不能写成只有平方目标才有的机制。

## 4. R5-20B：合法框数量、质量和概率要求

主分层 k=1、2–3、≥4；总真实候选数 m 分层为1–15、16–31、≥32。每格记录图像/查询数量、目标类别、合法框的IoU分布、正确率、coverage。

只在每个 k 层自身按图片宏平均报告，注意图像可能出现在多个层；层间差的 bootstrap 必须对原始图片一起抽样，不能把层当独立数据集。固定共同类别×m支持进行辅助重加权，缺支持记 NA。事后仍为关联分析。

概率用同一 candidate probability 约定：

- uniform 模型：ρ=softmax(2f)。
- ν 模型：ρ=softmax(2f+logν)。

对每条查询输出合法集合概率 h=Σ_Aρ、条件概率ρ_A=ρ/h，以及 KL(U_A||ρ_A)。k=1 的KL应为0。

这些是候选分布坐标，不等于 semantic match Bernoulli probability。合法框内最大概率、熵、最高分合法框的IoU可辅助判断概率集中是否与框质量相关；真实正P仍均匀，不将较高IoU偷偷换成软标签。

R5-30完成后，重点差值为 D−E（分布式减集合softmax），其次 VCS−D、JS−D。即使 D≈VCS 也只支持部分解释，因为函数类、二元损失和优化路径不同。

## 5. R5-20C：同查询、同目标框、嵌套干扰

固定阈值：≥31非法候选，≥1合法候选。目标选最大IoU框，完全相等按检测分数降序与proposal_id升序。

候选数序列以非法数计：[1,3,7,15,31,all]。每query使用32个预先固定repeat seeds；用SHA-256(query_id, repeat)建立本地随机流，所有模型、训练种子共用。一次打乱非法ID列表，前缀嵌套，避免每个n单独重采样。

可按统一参考困难顺序做第二条探索曲线，但不能取代随机嵌套主诊断，也不能用 VCS 自己选择一条对它有利的曲线。严格共同支持子集的覆盖率与类别分布必须附表；它不是完整任务总体。

每个query先平均32次命中率，每图再平均query，最后平均图片。bootstrap只抽图，不抽“repeat×query”伪样本。全候选点与repeat无关。报告固定查询池上的per-seed曲线和差值，不把原来不同支持集的曲线接在一起。

## 6. 公共 J／风险读数与统计单位

原生J_uniform、原生J_score分开，因为Q不同。公共比较至少给出固定 uniform P0,Q0 的风险：R0=1−J0。可以对现成T直接读，但注明未经共同参考重校准。

若沿用已有 affine J_recal：仅在CAL上按每模型相同规则重拟合两个标量，再在DEV读。它只是沿用的评分重读，不自动授权新MLP探针。所有模型可以用logistic拟合后转换T；误差恒等式的权利不归某种训练损失独占。[O1,S10]

区间以图像为独立单位。不同训练种子分开；图片级bootstrap仅条件于这些模型。反复DEV选择已经发生，不用bootstrap掩盖自适应选择。
