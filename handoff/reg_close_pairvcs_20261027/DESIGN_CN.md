# 配准收尾：按图像对校准的 VCS 结构匹配器机制验证（2026-10-27）

依据：`reg_arch_review/VCS_Registration_Architecture_Review_20261027`（zip sha256 29def908…，MANIFEST 通过）。用户：「我们拿这个来做配准的收尾吧」。

## 范围

这是配准线的最后一项实验，只做包 03_DECISION_GATE 的三步机制诊断（A/B/C），**全部为推理期计算，不训练结构基底、不做双层训练、不恢复配准长训练**。冻结宿主为已接入的 MINIMA-RoMa（`handoff/r23_sota_matchers_20261026` 的锁定配置与环境）。结果无论正负都完整报告并据此关闭配准线；可训练基底 + 双层训练版本明确列为“未运行”。

数据：BF，与 A 现代匹配器同一协议（V10 BF DEV32 的 320 题；A 步只用 FIT/CAL 的明确真值）。不读 TEST134、不打开任何 closed/ 或 Learn2Reg 隔离文件。

## 模块（每对图像一次，固定后不再改）

1. 特征：MINIMA-RoMa 冻结粗/细特征，在 BF/SHG 各自的稠密网格位置取局部描述子；φ(u,v) 用 M1 的 simplex-bilinear 有界参数化（复用 `src/v10/adapter.py` 的约束求解器与精确矩）。
2. 支持集 S：宿主初始匹配经双向一致性 + 可匹配性筛选；空间分块，支持块与检查块分开；支持点与权重固定。P_S 为加权支持对应，Q_S = (P_S)_U ⊗ (P_S)_V（实际边缘乘积，含对角）。
3. 校准：â = argmax_{a∈C} aᵀd − ½aᵀHa，记录有效秩、条件数、求解残差、覆盖；支持不足或退化时回退宿主路径并计数。
4. 对应生成：固定 â，在检查块评价候选，保留坐标与多个空间分离峰，不平均坐标。
5. 几何：与宿主相同的刚性模型、RANSAC 次数与内点阈值；细定位沿用宿主精修。

## 三步诊断（全部运行，不设阈值阻止后续步骤）

- **A 可表达性上限（仅 FIT/CAL）**：支持集用训练真值的明确正确对应（oracle，只作诊断）。看检查块中新正确对应数、top-K 真对应覆盖率、严格定位。
- **B 可观察支持（DEV320）**：宿主真实 noisy 支持。记录支持数量/错误率/覆盖/校准稳定性/回退频率，fit 与 holdout 差异。
- **C 完整任务与归因（DEV320，同特征、同搜索范围、同总候选预算、同几何求解次数与精修预算）**：
  1. 宿主原生（A 已有结果在同一协议下重算一次作配对参照）；
  2. 宿主 + 等预算额外搜索控制；
  3. seed-only 几何解（只用支持点）；
  4. 固定全局 VCS critic（在 FIT 上拟合一次，所有图像对共用）；
  5. 按图像对校准 VCS；
  6. 按图像对校准 matched BCE（同 P/Q 定义、同有界参数类，报告同计算量与自身收敛两种设置）。

## 指标

机制：检查块新增正确对应数与精度、top-K 覆盖、有效空间跨度、同预算变换候选 oracle 及选中与 oracle 差距、seed-only vs 扩展。任务：严格/宽松成功率、宽松失败数、p95、最坏 core、回退次数与成本。按 core 聚类 bootstrap，不把同 core 扰动当独立样本。J、inner gap 只作诊断。

## 解读（事后，预先写定方向）

只有 J 上升、只在 oracle 支持有效、seed-only 已一样好、或 VCS 与 BCE 无差别且系统不超过强宿主 —— 配准线按此关闭。若 C5 相对 C1–C3 与 C6 都有稳定改善，如实报告为开发证据（DEV 已多轮使用、Neon/MINIMA 权重与数据重叠），作为未来独立确认协议的候选，不在本轮扩展。
