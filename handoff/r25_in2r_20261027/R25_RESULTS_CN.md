## 2. 结论

- **VCS 相对原生 SCE**：6/6 格为正，均值 40% +1.83、60% +1.09。替换 noisy 修正目标有小而一致的收益。
- **VCS 相对同接口 BCE**：BCE 在 5/6 格更高，均值 40% −1.45、60% −0.38。收益不是 VCS 特有的；同 critic 的 balanced BCE 更好。
- **预登记开发门槛**（40/60% 平均 VCS−SCE ≥ +6、VCS−BCE ≥ +3）：实际 +1.46 / −0.91，**未达到**。按协议不进入 COCO/CC152K 的 P3 扩展；论文目标（约 +10 并接近外部强标杆）远未达到。
- 宿主本身很强：H0 在 40% 上 510.5（论文报告的 IN²R TEST 504.1，划分不同，不可直接比较）。

## 3. 局限

- 3 个 seed，seed 级配对差；图像分组的 query bootstrap 需要逐 query 排名，本轮运行未保存，未计算。
- 外系数 c_J 在共同原生状态下按 FIT 梯度量级一次标定（CRITIC_AND_SCALE / calib），critic C1 在 40%/seed1001 上按 full DEV 选定（该格属于开发选择，其余 5 格为同协议复用）。
- 原生代码三处缺陷（单样本 labeled batch NaN、空 caption、SPS `it.next()`）与 SPS 第四处缺陷（跨设备索引）均已修复，对所有臂一致；失败尝试存档并计入成本。
- Flickr TEST 已在旧轮次读取过，锁定后的 TEST 评估只算重复 benchmark，且需用户批准后执行。
