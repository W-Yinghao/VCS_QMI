## 3. 已经确立的机制

1. **拼接 MLP critic 把 encoder 拖向低维可比编码。** 无论容量、学习率、K，h 秩停在 13–21，projector 输出只剩 7–11 个主方向，800 epoch 的
   linear 天花板 ≈ 79–80。换成余弦 critic（2 个参数）秩到 58，同 epoch +2.2；带显式交互特征的 MLP 到 39；MLP + 双线性项仍是 16（只要有
   自由拼接通道就会走回低维解）。**critic 的函数形式决定 encoder 的几何，容量无关。**
2. **负配对的梯度路径在两种 critic 下作用相反。** 负分支 detach 在 MLP critic 下彻底塌缩（44.5），在余弦 critic 下是最好的单因素
   （+2.2）。余弦只看方向，正配对本身就足以防塌缩；把"推开"信号限制在 z1 一侧似乎减少了噪声。机制未证，只有这一对观察。
3. **J 与表示质量在不同 critic 族之间不可比。** MLP 的 J 0.93 对应秩 16，余弦的 J 0.97 对应秩 58；同一族内 J 单调上升而 linear 早已平台。
   J 是"当前 critic 族下配对可分性"的度量，不是表示质量。饱和比例（84–94%）在所有配置里都高，且变难的增强降低 J 却不改善表示——
   "饱和 → 信号弱" 这个早期解释不成立。
4. **优化配方本身不是瓶颈。** LR、schedule、B、wd、增强都在最优附近；seed SD 0.4–0.8。

## 4. 发散：真正的瓶颈可能是什么

### 4.1 目标只要求"可分"，不要求"均匀"
InfoNCE 等价于 alignment + uniformity（Wang & Isola）：log-sum-exp 让每个 anchor 与所有负样本持续互斥，压力永不消失。VCS 的二次目标是
逐对回归到 ±1：负配对一旦 cos 低于阈值就饱和、不再有梯度。余弦基线学到 a≈9.8、b≈−8.1，即阈值 cos* ≈ 0.83——负配对只需 cos < 0.7
就"完成任务"。这只给出很弱的、有阈值的斥力，对应我们看到的：秩 58 对 SimCLR 的 90，kNN 差 9 个点大于 linear 差 5.6 个点（kNN 更依赖
全局几何）。**这是可以直接测的假设**：在缓存的 selection z 上计算 Wang-Isola 的 alignment 与 uniformity，VCS 各变体对 SimCLR。

### 4.2 正负权重被参考测度锁死为 1:1
M = (P+Q)/2 意味着 J 中正、负两个分布各占一半权重，且负项是 K×B 个分数的均值——K 再大，负样本总权重仍是 ½。InfoNCE 里负样本项随
数量增长、主导梯度。这解释了"K 从 8 到 255 只有 +1"的现象，也是 VCS 与对比学习在结构上的根本差异。这一点属于合作者计划的核心
（pM+qM=2 恒等式依赖等权混合），不能由我改；但值得作为理论侧问题提出：一般混合 αP+(1−α)Q 的 CS 参考测度是否保留可采样的变分形式。

### 4.3 高依赖场景下总体最优解简并
T* = tanh(PMI/2)，增强配对的 PMI 极大 → T* ≈ ±1 → S ≈ 1。任何让配对"容易区分"的 encoder 都几乎达到最优，最优解对表示几何没有偏好。
学到什么几何完全由 critic 族的归纳偏置和训练动力学决定——这正是 §3.1 观察的理论解释，也是为什么所有"常规超参数"都不起作用而
critic 形式起作用。计划 §12.3 把这种情形称为"高依赖压力测试"，SSL 恰好整个落在这个区间。

### 4.4 梯度只来自约 10% 的配对
84–94% 的配对 |t| > 0.95，每步有效信号来自少数未饱和配对。AdamW 归一化了幅度，但方向噪声大。可行的（不改 J 的）缓解只能通过 f 的形式：
限制尺度 a（N3 在跑）、或让 f 成为 cos 的更平滑单调函数，使更多配对留在非饱和区。

### 4.5 尺度自由度
余弦 critic 只约束方向，pre-normalization 的尺度与均值完全自由（critic 读 h 时 ‖h‖ 塌到 0.5 就是极端表现）。projector 末层 BN（N4，在跑）
和输出归一化是直接对策；这也是审查 §5 的判断。

### 4.6 不太可能的方向
数据/增强（与对照同）、评估协议（已验证）、优化器步长（已验证）、模型主干（不动）。

两个训练分布视图，冻结的最终 checkpoint。

|---|---|---|---|---|---|---|
| SimCLR | 86.09 | −3.84 | −0.01 | **−2.81** | 0.24 | — |
| VICReg | 85.46 | −3.68 | −0.02 | −2.52 | 0.27 | — |
| VCS MLP K=1 | 74.34 | −2.05 | 0.37 | −1.51 | 0.58 | — |
| VCS MLP K=8 | 77.44 | −1.93 | 0.44 | −1.61 | 0.55 | — |
| VCS cosine K=8 | 78.32 | −3.51 | 0.06 | −1.56 | 0.59 | 8.35 / −3.91 / 0.47 |
| VCS cosine K=255 | 79.32 | −3.51 | 0.06 | −1.57 | 0.59 | 8.49 / −3.95 / 0.47 |
| VCS cosine K=8 neg-detach（最好） | 80.48 | −1.56 | 0.58 | **−1.79** | 0.52 | 9.81 / −8.09 / 0.83 |
| VCS MLP K=1, 800 ep | 78.93 | −1.55 | 0.57 | −1.63 | 0.55 | — |
| VCS MLP K=8 clr×10, 800 ep | 79.56 | −1.60 | 0.57 | −1.86 | 0.50 | — |

读法：
1. **h 层的均匀性是 VCS 与对照之间最干净的分界。** 所有 VCS run 的 h-uniformity 落在 −1.5 … −1.9，两种对照都在 −2.5 以下；负配对在 h 上的
   余弦中位数 VCS 0.50–0.59，对照 0.24–0.27。线性 probe 与 kNN 读的正是 h，这与 §4.1 的假设一致："目标只要求可分不要求均匀"在 h 上直接可见。
2. **z 层的均匀性不决定 linear。** 普通余弦 critic 把 z 铺到 SimCLR 的水平（−3.51 对 −3.84，负配对余弦 0.06），但 h 没跟上（−1.56），linear 只有
   78.3；neg-detach 反而让 z 变得很不均匀（−1.56，负配对余弦 0.58，阈值 cos* 0.83），却是 h 最均匀的 VCS run（−1.79）并且 linear 最高。
   两层 projector MLP 吸收了"铺开"的工作，encoder 得不到这部分梯度。这把 §4.1 的假设收窄为：**缺的是作用在 h 上的均匀性压力**，不是 z 上的。
3. **VCS 各 run 内部，h-uniformity 与 linear 大致同序**（−1.51 → 74.3；−1.61 → 77.4；−1.79 → 80.5；−1.86 → 79.6），但斜率远不能外推到对照
   （−2.8 → 86）；这只是相关，不是机制。
4. **neg-detach 的作用方式与预想不同。** 它没有让负配对分得更开，而是让 critic 把阈值推到 0.83、让正配对更紧（alignment 0.090，所有 run 中最小）。
   它改善的是 h 的几何而非 z 的几何，机制仍未证。

由此新增两个候选（已排入 P28）：`proj_linear`（projector 退化为单个线性层）和 `proj_bnonly`（无 projector，critic 读 L2(BN(h))，BN 无仿射
参数以避免 cos_on_h 的尺度塌缩）。两者都不改 J，只是去掉能替 encoder 完成"铺开"的非线性层，检验读法 2。

3. **VCS 的 projector 丢掉的类别信息远多于对照**：z_l2 比 h 低 6–14 个点（对照 2.5–3.9），p_raw 有效秩 7–14（普通 cosine 42；对照 77–87）。
   critic 实际看到的是 ≈10 维的编码——足以分开正负配对（heldout-J 0.93–0.97），不足以逼 h 变丰富。这就是 §4.3"最优解简并"在各层上的样子。
4. **普通 cosine critic 下 p_raw 的 kNN 比 h 高 4.4 个点**（77.2 对 72.8）：目标塑造的度量结构在 z 上，h 只继承一部分；neg-detach 把差距抹平
   （74.7 对 74.6），与 §4b"neg-detach 把铺开的层从 z 换成 h"一致。两条都指向 projector 是 VCS 与对照分岔的位置——P28 的 proj_linear /
   proj_bnonly 正是检验这一点。

wave G 已出的两条：a0=5 可学 **81.90**（kNN 77.0，秩 45）、a0=5 固定 **81.54**（kNN 77.0，秩 46.9），基线三 seed 80.48 / 80.58 / 80.72。
