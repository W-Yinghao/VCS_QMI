## 二、论文范围与表述

### P1 — 查询内归一化的 VCS critic（KLIEP 归一化）
- **证据**：在 RefCOCOg / RefCOCO+ / RefCOCO 上，VCS 落后 softmax 的差距分别有 61 % / 69 % / 86 % 被归一化弥补（+1.13 / +2.22 / +7.56 点）。
  - 目标泛函不变；该归一化与总体最优密度比满足的约束一致，但受限的 a·cos + b 模型能否逼近真实后验需要实证评价。
  - VQ − 分布式 softmax 的区间在三个数据集上都低于 0（−0.99 / −0.78 / −1.73）；VQ − 集合 softmax 在 RefCOCO+ 上的区间包含 0。两组比较不能合并成"所有 softmax 比较都显著落后"。
  - 剩余的准则差距是在所测数据、函数形式、优化和选择规则下的结果，不是 VCS 的不可避免代价，也不是下界定理。
  - 诊断显示，它显著减弱了差距随干扰项数量增长的趋势，但没有消除：RefCOCO 上 VQ 相对集合 softmax 从单干扰时接近 0，到全部干扰时约 −1.40。
  - 报告：`reports/R5/R5_QNORM_REPORT_20261012.md`、`reports/R5/R5_QX1_REFCOCO_REPORT_20261012.md`。
- **选项**：(a) 作为方法变体（"VCS critic with within-query normalization"）并写入分解分析；(b) 只作为分析，解释差距从何而来；(c) 不写。
- **［已定］(a) 方法配置 + 分析**：方法节可设小节 "Candidate-normalized VCS for visual grounding"；它是已有 KLIEP 式归一化思想的实例，不写成新 estimator 或首次提出；保留原 VCS、归一化 VCS、匹配 JS 和两种 softmax 一起报告。

### P2 — r6 REG（跨模态配准）的表述
- **证据**：学习 critic 比逐图 MI / NMI 多配准 18–20 个百分点（平移和 ±30° 刚体两种设定）。在 < 42 px 时与 CoMIR 没有可检测差异，在 < 9 px 的精度上更好。VCS、logistic、InfoNCE 三者没有可检测差异。
- **［已定］保留为正面应用，改写归属**："在已测 BF–SHG 配准设置中，学习到的局部跨模态关系比所比较的逐图 MI／NMI 配准能量获得更高的成功率；VCS 是其中一种有效训练准则。"不把 InfoNCE 归入"CS 族"，不写成一般的"CS 优于 MI"，也暂不升级为本文独有的核心优势。CoMIR 的比较是"其表示 + 同一优化器"，不是其完整原生流程。

### P3 — r6 GAIN（按需计算额外模态）的表述
- **证据**：回归实际收益 h 的策略优于熵（CREMA-D 上明显，AV-MNIST 上很小）。平方分歧 z 可能显著劣于 h（CREMA-D 的 Brier 族）。CREMA-D 上，25 % 预算点：DEV Brier 0.564，墙钟 9.7 ms / 片段，约为"总是计算视频"（Brier 0.486，33.3 ms）的 29 %；这是一个风险—成本操作点，不是"质量不变省 71 % 时间"。
- **［已定］作为证据增益的适用边界分析，优先放附录**：核心是纠正"分歧就是收益"（有限模型下 h − z = 2(C − b)(b − a)）；CREMA-D 的结果连同同一操作点的风险一起展示；两种目标都是标准风险回归，不写成 CS 特有方法。

- **［已定］按使用位置充分披露**：若论文保留 AV-MNIST 数值，正文实验设置必须简短说明按音频片段分组，附录给完整审计；若主文不用，保留为附录的数据审查记录。表述限定在本次下载的版本和所检查的数组：字节重复证明输入重复，跨标签对应说明配对需谨慎解释；不据此断言所有使用 AV-MNIST 的既有工作都只是在记忆，也不在未验证时指认其原始生成过程有误。

- **r7 最重要的比较**不是"有没有超过均匀剪枝"，而是：S1（VCS，经由任务后验间接得到的证据损失）是否比直接学习宿主风险变化的 S3 更有用；与同样读取平方差的 S2 相比又有什么区别。S1 的小型测量网络与 LLaVA 不是同一个预测器，它的证据损失不会天然等于宿主的回答损失。
- D1-10 只表明宿主输出的平方分歧与实际风险变化有一定关系，部分条件存在系统偏差；所谓 "calibrated-teacher ceiling" 是在教师自身概率模型下生成的参照，不是自然数据上所有方法的理论上限。
