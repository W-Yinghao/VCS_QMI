## 0. 输入、标签与偏离

- **模型输出**：24 个正式单元 `V8-FIT-<arm>-s{0,1,2}` 的 `pred/images_{DEV,CAL_SELECT,CAL_PROB}.jsonl`。它们是 `best.pt` 的导出，checkpoint_id 写作 `best_e<0 起算的 epoch 索引>`。

- **无标签导出**：24 个正式单元的 GenAI-Rank 与 TIFA160 预测，以 `--label-mode none` 处理，行内不含任何标签字段（package `validate_rows` 强制检查）。
- **标签**：只用开发角色 DEV（3257 图、307 个 prompt）、CAL_SELECT、CAL_PROB 的 EvalMuse public TRAIN 投票。GenAI-Rank、GenAI-Bench、TIFA160 的标签都没有读取，本轮没有新增标签读取，标签台账不需要新行。
- **偏离 1，cluster**：manifest 没有 `component_id`，因此用 V7 的 `prompt_group` 充当（它是 V7 做角色划分时使用的近重复连通分量，见 `ssl_pilot_v7/scripts/v7/v7_data.py` 第 413 行）。DEV 的 307 个 prompt 落在 304 个 cluster 中，其中 3 个 cluster 各含 2 个 prompt。
- **偏离 2，q 再归一化**：导出的 q 是 float32 softmax，|Σq−1| 最大约 2e-7，超过 package simplex 检查的 1e-8 容差。预处理把 q 除以其和、令 u = tails(q)，score 保留原 mu。逐单元偏差记录在 `results/d04a_export_consistency.csv`，|mu − q·L| 不超过 1e-6。
- **偏离 3，候选顺序**：DEV/CAL 用 `adapt_v8.py` 的规则，即 prompt 内按 image_id 字典序（仅开发用途），外部系统与核桥使用同一顺序。GenAI-Rank 用官方 candidate_index，pool 为 prompt×generator（1600 池，每池 9 图）。TIFA160 的 pool 为 prompt（160 池，每池 5 图），这张无标签表是本包未要求的附加描述。GenAI-Bench 的池没有构建（package D00）。
- **偏离 4，score_kind**：输出全部落在 [1,5] 的回归器（B0、V7 单元、核桥）记为 rating_mean，其余记为 native_score。本节只用排序与选择，不用 MSE。
- **偏离 5，TUNE 单元**：`V8-TUNE-*` 是 seed 17 上的 lr 网格，不是 seed，只进入 V81_03 的次级表。

## 3. [解释]

1. **换损失与换 seed 对决策的改变处于同一量级。** 刻度臂之间的 top-1 一致率为 0.768，同一臂跨 seed 为 0.739。在当前骨干、数据与选模规则下，损失函数没有产生超出训练随机性的系统性不同选择。在 U-CS 的同 seed 对中，与 U-BCE 的一致率最高（0.786），这与“相同后验、不同 proper scoring rule”的关系一致。
2. **选择不同、均值相近。** 84 个同 seed 对平均有 0.262 的池选择不同，但 U-CS 的选中质量差都接近 0，且区间含 0。这对应 docs/02 §3 第二行“错误与收益异质”。互补参照依赖真标签，推不出可部署融合。
3. **U-LIST 的选中优势是开发描述。** 它与 listwise top-one 目标一致，但 U-LIST 的 pooled Spearman 与分布读数更差（V81_03、V81_04a）。这不改变 V8-04/V8-05 的结论，也不能作为更换主方法的依据。
4. **与零样本评分器的决策大多不同。** U-CS 在 DEV 上的选中质量更高，但 DEV 与 FIT 同为 EvalMuse 分布，V8 单元正是在 FIT 上训练的。这只是开发侧的领域内位置，对外位置以已提交的 V8-04/V8-05 和 V81_06 为准。
5. **域外导出上的一致率更低。** GenAI-Rank 的同 seed 一致率为 0.664，DEV 为 0.738；跨 seed 为 0.658，DEV 为 0.739。在域外候选上，决策对损失与 seed 都更敏感。TIFA160 每池只有 5 图，随机一致的基线更高，因此不能与 9 图池的数值直接比较。

## 4. [未验证假设]

- 跨臂与跨 seed 处于同一量级，可能主要来自“选模噪声 + 训练随机性”。要把两者分开需要更多 seed 或逐 epoch 权重；逐 epoch 权重没有保存（V81_01，V81_03 §2.4），本轮不补训练。
- U-LIST 的选中优势在独立数据上是否存在没有验证。已经暴露的确认集不得用于事后检验。
- 更强的视觉适配（C1）或结构改动（C3）是否会扩大损失间的决策差异，没有测试。
