## 0. 输入与定义

- **数据**：24 个正式单元在 DEV（3257 图）与 CAL_PROB（1630 图）上的 q/u/mu，使用再归一化后的导出（见 V81_02 §0 偏离 2）。人工投票为 3 票或 6 票，每图等权，这就是 V8-03 的 natural weight。
- **指标**：package `distribution_metrics` 给出 random-rater RPS（= CDF 拟合 MSE + 投票常数）、histogram 交叉熵（截断 1e-12）、mu-MSE、预测评分方差和四个阈值的 Brier。RPS 恒等式的残差逐图核对，都不超过 1e-10。主读数为 prompt 宏平均。
- **先验**：使用每个单元日志里的 FIT `prior_fit` 与 `fit_hist`（R1），不从 DEV 或 CAL 重算。
- **CS 原生读数 J_k**（docs/05 §1）：
  - T_k = tanh((logit u_k − logit π_k)/2)，π 取 FIT 先验。P_k ∝ w·y_k，Q_k ∝ w·(1−y_k)，w 是该角色内的自然权重。
  - J_k = E_P T − E_Q T − ½E_P T² − ½E_Q T² = S_k − E_M(T−η)²。S_k 未知，但对同一角色的所有模型相同，因此 J 的差就是后验比拟合误差的差。
  - 实现由单元测试核对：T = η 时 J = S，扰动后 J 下降。
- **交叉核对**：RPS、log loss、mu-MSE、Brier 与冻结的 V8-04 评价 JSON 一致到约 1e-8，残差来自 q 的再归一化。
- **区间**：U-CS 对其余臂做同 seed 配对差，用 prompt_group cluster bootstrap（2000 次，seed 2718）。RPS、log loss、mu-MSE 用 package `cluster_bootstrap` 作用于逐 prompt 的差；J 在同一组重采样上重建比值。

## 3. [解释]

1. **分布训练四臂给出几乎相同的分布质量。** U-CS 与 U-BCE 在所有分布读数上都没有可检测差异，包括 CS 自己的 J。这与“同一后验、不同 proper scoring rule”的关系一致：在有限的 FIT 上，两者收敛到相近的阈值后验，CS 的二次评分规则没有带来可测的后验优势。
2. **点损失臂在 mu 上并不更好，但直方图明显更差、预测评分方差过宽。** 它们只约束 mu，q 的形状由初始化与优化路径决定。需要分布或阈值读数时（如 RPS、阈值风险），应使用分布训练臂；只看 mu 时，除 RANK 外各臂相当。
3. **所有臂共享两个局限。** 一是 RPS 的一半以上是投票常数，即标注分歧，建模无法消除。二是分布臂对单张图离散的预测只有弱相关（Spearman 约 0.25–0.34），并向平均离散收缩。
4. **不支持把分布改善改称为选图改进**（docs/08 决策矩阵第六行）。点损失臂与分布臂在分布读数上的差别，没有转化为 DEV 上的选图差别（V81_02、V81_03）。

## 4. [未验证假设]

- 6 票图的离散更高，是数据采集规则（例如对争议样本补票）造成的，还是图像本身的属性：manifest 没有记录，未验证。
- J 读数中的 S_k 未知，因此只能给出模型之间的差，不能给出绝对的后验误差。
- 更强的视觉适配（C1）能否改善分布臂的离散收缩，没有测试。
