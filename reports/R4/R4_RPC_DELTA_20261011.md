# R4-T0 — what VCS inherits from RPC and related work, and what is left to the authors — 2026-10-11

Package `r4/package_r4_20261010` (docs/03 §2, docs/06 [L1–L4]).  Server-side mapping only; whether any item becomes a claimed contribution is the
authors' decision after their own literature check.  The original S / J / mixture reference are unchanged.

Notation: M = (P+Q)/2, η = (p−q)/(p+q), S = E_M η², J(T) = E_P(T − T²/2) + E_Q(−T − T²/2), T ∈ [−1, 1].

## 1. Inherited or directly identical (state as such)
| item | relation | source |
|---|---|---|
| Objective | Balanced RPC F_{1,1,1}(T) = E_P T − E_Q T − ½E_P T² − ½E_Q T² **equals J**. | Tsai et al., ICLR 2021 [L1] |
| Optimal critic | RPC optimum T* = (p − αq)/(βp + γq); at α = β = γ = 1, T* = η. | [L1] |
| Gap | F(T*) − F(T) = ½∫(βp + γq)(T − T*)²; balanced case: S − J(T) = E_M (T − η)² (completed square). | [L1] + direct algebra |
| Mixture-ratio least squares | RuLSIF with α = ½: p / (½p + ½q) = 1 + η; mixture denominator + squared loss is prior structure. | Yamada et al. [L2] |
| Loss / link view | JS (logistic) and squared fits target the same balanced posterior; finite-class differences are loss/link effects, not a new estimand. | Reid & Williamson [L3] |
| Sparse pairs | Learning with fewer tuples (incomplete U-statistics) is studied; "sparse negative pairs + theory" is not new by itself. | Clémençon, Colin & Bellet [L4] |
| Concentration | Bounded-difference / Hoeffding tools for a fixed critic on independent units are standard. | standard |

**Numerical check (server, 2026-10-11):** both our implementations are balanced RPC on the same output tensor.
- `vcs_estim.objectives.vcs_loss = −F_{1,1,1}` on empirical means (value to 1e-12, autograd gradient to 1e-14).
- `vcs_vl.pairlaw.padded_batch_loss("vcs") = mean(1 − F_{1,1,1})` per image; `padded_j = F_{1,1,1}` (same tolerances, with padded variable-size scenes).
- Negative controls: γ = 0.6 and the matched-JS loss do not match.
- Test: `tests/test_r4_rpc_identity.py`; package checks: 38 / 38 pass.

## 2. Candidate contributions (authors to confirm priority and strength)
- The link from the bounded mixture-reference target S to a Cauchy–Schwarz-type quantity (CS = 2 log((1+S)/(1−S)) on valid S) and its reading as QMI.
- A systematic same-target benchmark with an oracle S: P85 / P86 ladders, P108 plug-in vs J, P134 contamination.  It now uses the corrected common
  readout (R4-01): JS's posterior MSE is ≤ VCS's in 42 of 45 ladder cells (generator × I × construction), and the common-J seed spread is comparable
  (JS smaller in 24 / 45).
- Concrete visual uses: VL3 given-box fine-tuning (VCS ≈ softmax, +0.01 [−0.35, +0.36]); Table C proposals (softmax leads, −2.05 [−2.93, −1.16]).

## 3. Open (this round; not a contribution until shown)
- Error and compute budget when negative pairs share base samples, critics are learned, and data are image-structured.  To count, this must go beyond
  instantiating the standard Hoeffding decomposition and delete-one variance (R4-T1 / T2).
- The proposal-reference Q_ν for detection candidates (R4-VL1): the same S / J on another reference law.  It is not the original conditional QMI.

## 4. Not to be written
"JS is theoretically at least as accurate"; "different losses cannot change the ranking"; "the S − J identity is specific to squared fitting";
"T ≥ 0 means a semantic match probability of one half"; "more budget necessarily reverses the ordering"; "the 1/n + 1/m independent-sample rate is a
first finding"; "J_recal ×1.33 means 33 % more real information".  Unbalanced / native RPC changes the target and is not a same-S repeat baseline.
