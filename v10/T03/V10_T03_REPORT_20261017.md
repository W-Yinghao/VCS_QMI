## 术语

| 术语 | 本报告中的含义 |
|:---|:---|
| 方法 | MF：每侧 Linear + softmax 特征 a(x)、b(y)（主表 K = 16），T = a(x)ᵀ W b(y)，W ∈ [−1, 1]^(K×K)。MF_VCS_perm1：每步 1 个均匀无固定点排列作负样本，特征与 W 由 AdamW 更新；MF_VCS_M0：完整 U 矩目标，特征与 W 由 AdamW 更新；MF_VCS_M1：完整 U 矩目标，W 每步由头 solver 求解（相对零头 gap 规则与 cap），特征由 AdamW 更新。MLP：两侧 one-hot 拼接的三层 MLP，T = tanh f；MLP_VCS_perm1 / perm8：每步 1 / 8 个均匀无固定点排列（生成器按单元记录核对） |
| S | 包生成器给出的总体真值。对任一 critic 表 T，S − J_pop(T) = E_M(T − η)² ≥ 0，所以 S 是 J_pop 的最大值，在 T = η 处取到 |
| p、q、M、η | p 为联合分布 P_XY 的单元概率，q 为 Q = P_X P_Y；M = (P + Q)/2；η = (p − q)/(p + q) |
| J(T) | E_P T − E_Q T − (E_P T² + E_Q T²)/2；J_pop 为总体值 |
| 完整经验 U-J | 用样本内全部 i ≠ j 配对作负参考 Q̂_U 的经验 J；负值保留 |
| EVAL / CAL / FIT U-J | 同一冻结 critic 在 EVAL（8192 个观测）/ CAL（2048）/ FIT（4096）样本上的完整经验 U-J |
| 误差 e、偏差、sd、RMSE | 每个重复的 e = EVAL U-J − S；偏差 = e 的均值；sd = e 的样本标准差；RMSE = √(e² 的均值) |
| 数据重复 | 一个 data root seed 生成的一整套独立 FIT/CAL/EVAL；主表每格 10 个，算法 seed 固定 |
| 算法重复 | 同一套数据只换算法 seed（初始化与排列流），只用于 §6 |
| 总体逼近误差 | E_M(T − η)²，evaluator 枚举全部 m² 个单元计算 |
| EVAL 抽样误差 | EVAL U-J − J_pop(T)；于是 e = EVAL 抽样误差 − 总体逼近误差 |
| 头 gap | MF 固定特征经验头问题（FIT 全批、U 模式、ridge 0、特征取所选 checkpoint）在 W 处的 Frank–Wolfe gap，是头部次优值的上界；G(0) 为 W = 0 时的 gap；fp64 polish 给出次优值下界 |
| 排列条件方差 | 固定所选 critic 与同一份基础样本，用 512 个均匀无固定点排列（同一数据上各方法共用的排列流）各算一次 perm1 估计所得的方差 |
| 饱和表 | 只用 FIT 计数构造的全表 T*（决定 §9.5 公式，分母为零取零），作为 FIT 全表函数类的经验最优参考 |
| 区间 | 偏差：95% t 区间；sd：由方差 95% χ² 区间开方；RMSE：百分位 bootstrap（B = 2000，seed 10191，按重复重采样）。“含 0”= 区间包含 0 |

## 1 结论摘要

- **测量对象**：包生成器的 12 个离散合成条件（two_block、diagonal_mixture × m = 8、32 × ρ = 0、0.25、0.75）上，5 种 critic 训练方法（MF_VCS_perm1、MF_VCS_M0、MF_VCS_M1、MLP_VCS_perm1、MLP_VCS_perm8）所选冻结 critic 的 EVAL U-J 相对总体真值 S 的误差。主表每格 R = 10 个数据重复（data root 2026101700–2026101709，算法 seed 1001）；另有固定首套数据的算法重复（seed 1002、1003）与容量诊断（K 8、32）。网格 1212 个单元（CAL 252、主 600、算法 120、容量 240）与 smoke 7 个单元全部 COMPLETE，评估全部 PASS，真值隔离拒绝 0 次。
- **精度**：每格只有 R = 10 个数据重复，偏差的 t 区间（自由度 9）、sd 的 χ² 区间和 RMSE 的 bootstrap 区间都较宽；R = 10 时百分位 bootstrap 只是粗略范围（小样本下通常偏窄）。区间逐格给出，未做多重比较校正。以下差异只描述本合成网格在固定训练规则下的测量，不是方法优劣结论（决定 §5：“必需基线补齐之前不发布方法优劣、强基线优势或新颖性比较结论”）。
- **ρ = 0（S = 0）的 20 格**：|偏差| ≤ 2.91e-4，RMSE ≤ 5.88e-4；18/20 格偏差区间含 0，其余 2 格（two_block m8 ρ0 MF_VCS_M1；diagonal_mixture m8 ρ0 MLP_VCS_perm8）偏差为负。125/200 个 ρ = 0 主单元与 0/400 个 ρ > 0 主单元的 EVAL U-J 为负，全部保留（决定 §9.5：“主 EVAL U-J 的负数保留，不截成零”）。
- **two_block、ρ > 0**：K16 MF 三法 RMSE 1.16e-3–3.72e-3，MLP 两法 2.71e-3–9.26e-3。ρ = 0.75 的 10/10 格偏差区间含 0；ρ = 0.25 的 10/10 格偏差为负且区间不含 0（S = 0.01587）。
- **diagonal_mixture、ρ > 0**：全部 20 格偏差为负且区间不含 0。K16 MF 三法偏差 -2.47e-1 至 -5.76e-3（相对 S 为 -62% 至 -9%），MLP 两法 -2.25e-2 至 -4.19e-3（-20% 至 -1%）。MF 的偏差主要是总体逼近误差：E_M(T − η)² 均值 / |偏差| 在 9 组为 0.98–1.02，在 diagonal_mixture m8 ρ0.25 的 3 组为 0.71–0.80（差额为同号的 EVAL 抽样误差均值，§5.2）。这 12 个 MF 组的 CAL 选模中 12/12 选中学习率网格上端 1e-3 与最后一个 checkpoint（2000 步），正式重复自身 CAL 选中最后 checkpoint 的为 115/120：选择落在固定步数与学习率网格的边界，这些 MF 数值是本训练规则下的结果，不是 K16 MF 函数类可达到的最小误差。
- **方法配对**（同一数据重复上的平方误差差 e_a² − e_b²，t 区间；负 = a 的平方误差较小）：MF_VCS_M0 − MF_VCS_perm1：9 个条件含 0，3 个为负、0 个为正；MF_VCS_M1 − MF_VCS_M0：9 个条件含 0，0 个为负、3 个为正；MLP_VCS_perm8 − MLP_VCS_perm1：10 个条件含 0，1 个为负、1 个为正；MF_VCS_M0 − MLP_VCS_perm1：7 个条件含 0，2 个为负、3 个为正。条件与数值见 §4.2。
- **误差分解**：E_M(T − η)² = S − J_pop(T) 在 13409 个评估表上成立（最大 |残差| 2.4e-16 ≤ 2e-13）。EVAL 抽样误差的均值区间含 0 的有 48/60 格；不含 0 的 12 格分布在 4 个条件中，其中 two_block m32 ρ0.75、diagonal_mixture m8 ρ0.25 的 5 个方法全部同号——同一数据重复的各方法共用同一 EVAL 样本，抽样误差在方法间相关，这些格不是独立事件。perm1 均值相对完整 U-J 的 z 值（1920 个）均值 0.024、sd 1.004，|z| > 3 的 5 个（标准正态期望 5.2 个）；若改用单个 perm1 排列读数，其在 EVAL 上的排列条件 sd 为同格 EVAL 抽样 sd 的 0.61–2.00 倍（主读数用完整 U-J，无此项）。同一冻结 critic 的 |EVAL U − V| 最大 1.50e-4，不超过同格 e 的 sd 的 3.0%。所选 checkpoint 处 MF_VCS_M1 的头 gap 均值低于 MF_VCS_M0 的条件为 9/12。
- **饱和表**（FIT 全表函数类的经验最优参考，非训练所得）：m = 32 时 EVAL U-J − S 均值 -8.14e-2 至 -5.25e-2，同一表的 FIT U-J − S 为 4.88e-2 至 6.94e-2（FIT 上偏高、EVAL 上偏低）；m = 8 时 EVAL 均值 -5.09e-3 至 -4.19e-4。1219 个单元记录中的饱和表按（数据 root，条件）归并为 133 张，同组副本完全一致（冲突 0）。
- **算法波动与容量**：固定首套数据、R = 3 个算法 seed 的 sd 大于同格数据重复 sd 的有 13/60 格（两者分表，不合并）。固定训练规则下的容量响应（与 K16 配对的平方误差差，负 = 该 K 的平方误差较小）：diagonal_mixture 的 6 组中 K32 有 3 组为负、0 组为正，K8 有 5 组为正、0 组为负；two_block 的 12 个对比中 12 个含 0（§7）。
- **成本**：网格 2 个作业（CAL、正式）共 1505 s 墙钟（0.418 h），分配 13.38 CPU-h；单元墙钟合计 10.68 进程小时，为 smoke 投影（7.70–7.88）的 1.35–1.39 倍；低于第一阶段数量级换算到本网格的 79.6–576.4 CPU-h，未触发超预算规则（§2.4）。

- 区间以 10 个数据重复为单位逐格计算，未做多重比较校正；§6 的算法重复只有 3 个 seed、只在一套数据上。
- diagonal_mixture ρ > 0 的 MF 选择落在学习率与步数网格边界（§1、§3）；更大学习率或更长训练下的结果未测量，网格按决定 §9.2 冻结，未作事后扩展。
- M1 的同输入 fp64 诊断在 69016 个触发步中有 6845 步（9.9%）停止判断与 fp32 不一致（§5.3）；按决定 §2.3 这只是诊断，训练仍用 fp32，其对所选 critic 的影响未单独测量。
- 本报告只含合成真值实验；自然配准（BF、EPFL）的结果不在其中。
