# 1. 本轮目标与边界

本轮不继续用更多近似平局的表格代替创新定位，也不因 RPC 与基本目标重合而推倒已有实验。目标是完成一条清楚的工作链：

**已有结果可复核 → 基础目标归属准确 → 实际配对估计具有可检查的误差含义 → VL 在真实候选分布上的用途得到验证。**

论文保留 V6。合作者原始混合参考 $M=(P+Q)/2$、有界目标 $S$ 和二次泛函 $J$ 不改。新统计工作是原计划“谨慎处理乘积边缘样本/U-statistics”的研究接续，不是已经确定的新定理。[O §11、§17]

本包沿用最新讨论的四个问题：哪些是已有结果；哪些能构成新增贡献；VL 是否需要重设计；已有实验怎样保留/增改。具体参数与任务顺序属本轮建议 [D]，不归为合作者原文。

# 4. 第二阶段：RPC 定位与一个有边界的统计研究

## R4-T0：两页以内完成创新对照

必须逐项区分三类：

**继承/直接恒等：** 平衡 RPC 的目标、最优 critic、完成平方 gap、混合后验坐标；标准独立样本浓缩工具。

**本文已有贡献候选：** 混合参考 CS 的联系、相同目标的系统基准、具体视觉用途。候选的首次性与强度由合作者和完整原文对照确认，不能由服务器命名决定。

**本轮待研究：** 对共享基础样本、已学习 critic、分层视觉数据，如何正确估计误差和计算预算；必须比“套用现成 U-statistic”更明确才可成为新增主贡献。

公开 RPC 原文与一般 incomplete-U 研究都放入对照 [L1,L4]。仅将 U-statistic、交叉拟合或 bootstrap 换名，不算新方法。

数值检查先完成：同一 $T$、样本和权重下 $J=F_{1,1,1}$；同一参数化的自动微分一致。非平衡/原生 RPC 的比较可以另研究，但会改变目标，不能当作相同 S 的重复 baseline。

## R4-T1：冻结目标后，再决定是否值得增加训练

最小问题：固定表示与固定 critic，在**基础样本独立、负 pair 共享基础样本**时，如何区分：

1. 独立图片/观测抽样；
2. 给定图片后的配对抽样；
3. critic 初始化与学习数据变化；
4. $J(T)$ 与最优值 $S$ 的差距。

先采用独立 FIT/CAL 与 EVAL 的单次 split。不要首轮就把重叠训练集的 K-fold 分数当作独立样本汇总。数学起点和保守界见数学规范；首轮交付“假设—推导—实现—已有文献”四列，不把这些标准推导标成已证明的新颖性。

## R4-T2：最小统计验证

先有限状态分布精确枚举，再复用现有 Gaussian/非线性生成器。建议固定三个依赖区间：独立、可辨弱信号、较强信号；$n=32,128,512$。固定 critic 使用零函数、已知最优函数和一个规定的有误差函数，避免一开始就把训练问题混入置信区间验证。

每格做 500 次独立 EVAL 抽样，报告 Monte Carlo 区间。500 是本轮资源规模建议，不是保证；在原始记录里写实际次数。

| 读数方案 | 必要评价 |
|---|---|
| 全交叉 pair，错误的 pair-IID SE（负对照） | 对同一固定 $J(T)$ 的覆盖和宽度 |
| 全交叉 pair，U-statistic/delete-one 单位方差 | 非退化情况下的近似覆盖 |
| 不重叠双观测块 | 与独立块的有限样本界核对 |
| 原始图片/观测层面的有界界 | 保守性、覆盖和可用下界，不掩盖宽度 |
| 有限负 pair | 条件配对方差、总方差、真实成本 |

**两种覆盖率分开：** $J(T)$ 的双侧覆盖；利用 $J(T)\le S$ 的单侧 LCB 覆盖。近似 $J(T)$ 的区间不是 S 的双侧置信区间。独立性下零/最优 critic 可能退化，普通正态近似不默认有效。

若固定 critic 层面实现与理论不一致，先修，不增加模型/数据。通过后，最多在一个已有神经/核 critic 条件上重用或补拟合，比较同一公共读数下的估计方法，而非强迫 VCS-only。

# 5. 第三阶段：两个小型估计确认

## R4-E0：P134 同目标重汇总（先只读）

读取 51 个文件中选定方法的 `posterior.posterior_mse` 和 common J；三种负配对构造分表。对每个 seed、污染类型、比例计算绝对误差、相对自身清洁基线的增量，以及 VCS-JS 的配对差。差值是主读数，比值只有分母足够远离零才给出。

## R4-E1：求解方式检查（有条件的小型拟合）

先核对已有 checkpoint 能否恢复。选择一个有 oracle 的已有条件；同一 FIT/CAL、同一函数类、同一总计算上限，从相同初始化比较直接 VCS、直接 JS、JS 前半程后转 J、JS 前半程后继续 JS。两个后半程控制须共享完全相同的起点；优化器状态保留/重置作为统一约定，不选择性处理。

主评价为独立后验 MSE/common J；训练风险和饱和只用于解释。多预算曲线不预设越久越好。N 的变化另列，不和更新次数一起改变。warm start 不自动命名新算法，若只改善训练风险不改善 EVAL，则不能宣称解决了估计问题。

新污染复验和核扩展，只有在现有表解释仍不足时选择一项，不同时开 d×N×污染×多骨干大网格。具体模板见修复规范。

# 6. 第四阶段：VL 的问题重定义与下一次完整实验

VL3 与 Table C 都保留：前者是给定标注候选的学习结果，后者是检测器候选的实际任务结果。不能再用前者的 +0.01 点覆盖后者的 −2.05 点，也不能因后者失利否定前者发生过的学习。

## R4-VL0：只读诊断，不重新训小头

先使用两数据集 RefCOCOg、RefCOCO+ 的 SigLIP 2 B/16，三目标各三个原种子，共 18 个已存在 checkpoint。选择这两个数据集和统一 Base 主干是公开结果之后的探索设计，不作为独立确认。

通过已有分数或必要的冻结前向，分别隔离：候选数量、正框质量、干扰类型。实际全部 proposals 的主评价始终保留。使用真值选择最接近框或剔除真目标的诊断，显式标为 oracle-assisted；不能把它当作测试推理算法。详见 VL 规范。

## R4-VL1：proposal-aware 完整微调计划

默认继续使用 RefCOCOg、RefCOCO+，同一个 SigLIP 2 B/16 起点，VCS/平衡 JS/候选 softmax，各三 seed。**预计 18 个新增选定训练单元，不含搜索成本；不是现在直接提交的 18 个作业。** 兼容的原标注候选训练控制从 VL3 复用；若新实现改变了共同 recipe，原控制不能复用，先说明新增控制与预算。

训练侧使用同一干净、query-independent detector 的 proposals。只调用 FIT/CAL 图片，所有方法共享 detector、候选与裁剪。主训练使用全部冻结候选的精确损失，完整更新图像/文本两塔；不可把可变参数的特征缓存当作端到端训练。

微调 10 epochs 为初始日程，沿用现有 10-epoch 基础协议的 optimizer/transform/有效图像 batch；先测显存和 crop 曝光。全候选过大时先请求确认一个明确的候选抽样法，不能静默截取后仍叫相同全候选目标。

**变化不只是添加“负样本”。** 若 Q 使用所有 detector proposals，通常不再等于正关系的边缘乘积。建议先使用明确的 proposal-reference $Q_\nu$，保留合法重叠，详见 VL 规范。它是同一个 S/J 在另一参照分布上的应用，不伪称原条件 QMI 完全不变。

主结果是全部实际候选上的 image-macro Acc@IoU 0.5；给定框、候选覆盖、共同风险和 margin 是辅助。VCS 相对 softmax 的变化与三方法共同适配收益都报告。原始预训练模型、原始 VL3 checkpoint 和 clean detector ceiling 常驻表中。

## 6.2 基线公平性的有限补充

softmax、VCS、JS 分别允许相同 CAL 搜索机会，记录实际搜索次数与总曝光；先证明是否确有遗漏的参数影响，不要求强行统一最佳温度。跨图 InfoNCE 是一个有价值的补充臂，但其 Q 与图内任务不同，另行标记；不把图内 softmax 自动贬为弱基线。

代表性 baseline 复现有偏差时，先核查权重、数据、候选、预处理和指标，保留已知条件。不得只因某外部模型太差就删除记录，或给 ours 真框而让别人检测后直接排名。
